## model

```text
model/2026-05-20T12:12:59.080Z

这是一道典型的导数与函数性质综合题，其核心考点在于**函数的对称结构挖掘**以及**零点分布的解析分析**。本题的精妙之处在于，题干给出的函数 $f(x)$ 隐藏了一个关于 $x \to \frac{1}{x}$ 的对称关系。

以下是详细的深度解析。

---

### 【元解析与特征挖掘】

**1. 结构分量分析**
函数 $f(x) = (x-1)\ln x - a(x+1)$ 包含两个主要部分：
- $(x-1)\ln x$：这是一个经典的“同号”结构，在 $x=1$ 时为 $0$，且在 $(0,1)$ 和 $(1, +\infty)$ 上均恒正。
- $a(x+1)$：一个线性扰动项。

**2. 指纹特征识别**
观察表达式 $\ln x$ 与 $(x-1), (x+1)$ 的组合。在处理涉及 $\ln x$ 的问题时，常考虑 $x \to \frac{1}{x}$ 的变换，因为 $\ln(\frac{1}{x}) = -\ln x$。
我们预演一下 $f(\frac{1}{x})$ 的形式：
$$f\left(\frac{1}{x}\right) = \left(\frac{1}{x}-1\right)\ln\left(\frac{1}{x}\right) - a\left(\frac{1}{x}+1\right) = \frac{1-x}{x}(-\ln x) - a\frac{1+x}{x} = \frac{(x-1)\ln x - a(x+1)}{x} = \frac{f(x)}{x}$$
**结论：** $f(x)$ 满足关系式 $f(\frac{1}{x}) = \frac{f(x)}{x}$。这意味着若 $x_0$ 是 $f(x)$ 的零点，那么 $\frac{1}{x_0}$ 必然也是零点。

---

### 【常规解法】

#### 第一步：确定参数 $a$ 的范围与零点分布
首先分析 $f(x)$ 的单调性：
$$f'(x) = \ln x + (x-1) \cdot \frac{1}{x} - a = \ln x + 1 - \frac{1}{x} - a$$
$$f''(x) = \frac{1}{x} + \frac{1}{x^2} = \frac{x+1}{x^2} > 0 \quad (x \in (0, +\infty))$$
由于 $f''(x) > 0$， $f'(x)$ 在 $(0, +\infty)$ 上严格单调递增。
又 $\lim_{x \to 0^+} f'(x) = -\infty$，$\lim_{x \to +\infty} f'(x) = +\infty$，故 $f'(x)$ 有唯一零点 $x_0$。
$f(x)$ 在 $(0, x_0)$ 递减，在 $(x_0, +\infty)$ 递增。

要使 $f(x)$ 有且仅有两个零点，必须满足 $f(x_0) < 0$。
注意到 $f(1) = -2a$。
- 若 $a=0$，$f(x) = (x-1)\ln x \ge 0$，仅有一个零点 $x=1$（不符）。
- 若 $a < 0$，$f(1) > 0$，且 $f'(x) = \ln x + 1 - \frac{1}{x} + |a|$。由于 $x_0$ 满足 $f'(x_0)=0 \implies \ln x_0 + 1 - \frac{1}{x_0} = -|a| < 0$，则 $x_0 < 1$。此时 $f(x_0) = -2\ln x_0 - x_0 + \frac{1}{x_0} + 2|a|$。令 $g(t) = -2\ln t - t + \frac{1}{t}$，其 $g'(t) < 0$ 且 $g(1)=0$，故 $t < 1 \implies g(t) > 0$。因此 $f(x_0) > 0$，无零点（不符）。
- **因此必有 $a > 0$**。此时 $f(1) = -2a < 0$，而 $\lim_{x \to 0^+} f(x) = +\infty, \lim_{x \to +\infty} f(x) = +\infty$。
根据零点存在性定理，一个零点 $x_1 \in (0, 1)$，另一个零点 $x_2 \in (1, +\infty)$。

#### 第二步：目标表达式变形
我们需要证明 $\frac{1}{\ln x_1 - a} + \frac{1}{\ln x_2 - a} > 0$。
由 $f(x_i) = 0$ 可得：
$$(x_i-1)\ln x_i = a(x_i+1) \implies a = \frac{x_i-1}{x_i+1} \ln x_i$$
将 $a$ 代入分母：
$$\ln x_i - a = \ln x_i - \frac{x_i-1}{x_i+1} \ln x_i = \ln x_i \left( 1 - \frac{x_i-1}{x_i+1} \right) = \frac{2 \ln x_i}{x_i+1}$$
目标式转化为：
$$\frac{x_1+1}{2 \ln x_1} + \frac{x_2+1}{2 \ln x_2} > 0$$

#### 第三步：利用对称性证明
由前文挖掘的特征 $f(\frac{1}{x}) = \frac{f(x)}{x}$ 知，若 $x_1$ 是零点，则 $\frac{1}{x_1}$ 也是零点。
既然 $f(x)$ 仅有两个零点 $x_1, x_2$，且 $x_1 \in (0,1), x_2 \in (1, +\infty)$，必有：
$$x_2 = \frac{1}{x_1}$$
将 $x_1 = \frac{1}{x_2}$ 代入目标式：
$$\frac{1}{2} \left( \frac{x_2+1}{\ln x_2} + \frac{\frac{1}{x_2}+1}{\ln(\frac{1}{x_2})} \right) = \frac{1}{2} \left( \frac{x_2+1}{\ln x_2} - \frac{\frac{1+x_2}{x_2}}{\ln x_2} \right)$$
$$= \frac{1}{2} \cdot \frac{(x_2+1) - \frac{x_2+1}{x_2}}{\ln x_2} = \frac{1}{2} \cdot \frac{(x_2+1)(1 - \frac{1}{x_2})}{\ln x_2}$$
$$= \frac{1}{2} \cdot \frac{(x_2+1)(\frac{x_2-1}{x_2})}{\ln x_2} = \frac{x_2^2-1}{2 x_2 \ln x_2}$$
因为 $x_2 > 1$，所以 $x_2^2-1 > 0, x_2 > 0, \ln x_2 > 0$。
故 $\frac{x_2^2-1}{2 x_2 \ln x_2} > 0$，原不等式得证。$\square$

---

### 【进阶解法/技巧】

**高维视角：算子对称与对偶性**
在面对形如 $f(x) = (x-1)\ln x - a(x+1)$ 的函数时，只要观察到 $\ln x$ 的奇偶性（在对数尺度下）与 $\frac{x-1}{x+1}$ 的反比例性质，可以迅速建立 $x \to 1/x$ 的映射。

**秒杀路径：**
1. **识别对称性** $\to$ $f(1/x) = f(x)/x$ $\implies$ $x_1 x_2 = 1$。
2. **参数分离** $\to$ $\ln x - a = \frac{2\ln x}{x+1}$。
3. **构造函数** $\to$ 令 $h(x) = \frac{x+1}{\ln x}$，证明 $h(x) + h(1/x) > 0$。
   $$h(x) + h(1/x) = \frac{x+1}{\ln x} + \frac{1/x+1}{-\ln x} = \frac{x+1 - (1+1/x)}{\ln x} = \frac{x - 1/x}{\ln x} = \frac{x^2-1}{x \ln x}$$
   由于 $\frac{x^2-1}{x \ln x}$ 在 $x \in (0,1) \cup (1, +\infty)$ 上恒正（分子分母同号），结论直接成立。

---

### 【总结与反思】

#### 1. 认知模型提炼
本题属于**“隐藏对称性 $\to$ 根的乘积关系 $\to$ 表达式简化”**的模型。
- **核心指纹**：$(x-1)$ 与 $(x+1)$ 的共现，且伴随 $\ln x$。
- **关键技巧**：通过 $f(1/x)$ 建立 $x_1 x_2 = 1$ 的联系，将两个变量的求和问题转化为单变量的性质问题。

#### 2. 陷阱点提醒
- **参数 $a$ 的符号**：很多学生会忽略证明 $a > 0$，导致在讨论 $\ln x_i - a$ 的符号时出现逻辑漏洞。
- **零点唯一性**：必须通过 $f''(x)$ 证明单调区间，确保 $x_1, x_2$ 确实是唯一的且分别位于 $1$ 的两侧。

#### 3. 迁移场景
此类方法可迁移至以下题型：
- 涉及 $\frac{x-1}{x+1}$ 或 $\frac{x^2-1}{x^2+1}$ 的不等式证明。
- 含有 $e^x$ 与 $e^{-x}$ 对称结构的函数零点问题。
- 凡是出现 $\ln x$ 且定义域为 $(0, +\infty)$ 且结构具有某种“反转”潜质的压轴题。
```
