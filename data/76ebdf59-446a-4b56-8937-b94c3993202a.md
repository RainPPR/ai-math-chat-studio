## 【常规解法】

**Setting Up Coordinates**

Place the prism in 3D space with:
- $A = (0, 0, 0)$, $B = (2, 0, 0)$
- $\angle BAD = 60°$ and $AD = 2$, so $D = (2\cos 60°, 2\sin 60°, 0) = (1, \sqrt{3}, 0)$
- $C = B + D - A = (3, \sqrt{3}, 0)$ (parallelogram property)
- Height $= 2$, so $D_1 = (1, \sqrt{3}, 2)$

The face $BCC_1B_1$ lies in the plane through $B$ with normal $\vec{BC} \times \vec{BB_1}$:

$$\text{Plane equation: } \sqrt{3}\,x - y - 2\sqrt{3} = 0$$

**Key Distance Calculation**

Distance from sphere center $D_1 = (1, \sqrt{3}, 2)$ to the face plane:

$$d = \frac{|\sqrt{3}\cdot 1 - \sqrt{3} - 2\sqrt{3}|}{\sqrt{3 + 1}} = \frac{2\sqrt{3}}{2} = \sqrt{3}$$

Since $d = \sqrt{3} < R = \sqrt{5}$, the sphere intersects the plane in a **circle of radius**:

$$r = \sqrt{R^2 - d^2} = \sqrt{5 - 3} = \sqrt{2}$$

**Parameterizing the Face**

The face $BCC_1B_1$ is a $2 \times 2$ square. Parameterize it as:

$$P(s, t) = (2+s,\; s\sqrt{3},\; 2t), \quad s \in [0,1],\; t \in [0,1]$$

Substituting into the sphere $(x-1)^2 + (y-\sqrt{3})^2 + (z-2)^2 = 5$:

$$(1+s)^2 + 3(s-1)^2 + 4(t-1)^2 = 5$$

Expanding and simplifying:

$$\boxed{(s - \tfrac{1}{2})^2 + (t - 1)^2 = \tfrac{1}{2}}$$

This is a **circle** in parameter space with center $\left(\frac{1}{2}, 1\right)$ and radius $\frac{\sqrt{2}}{2}$.

**Identifying the Intersection**

The center $\left(\frac{1}{2}, 1\right)$ lies **exactly on the boundary** of the parameter rectangle $[0,1]\times[0,1]$ (on edge $t=1$, corresponding to edge $B_1C_1$).

Checking the radial extent: $s = \frac{1}{2} \pm \frac{\sqrt{2}}{2} \approx 0.293, 0.707 \in [0,1]$ ✓

Both endpoints lie within the rectangle, so the intersection is a **semicircle**.

**Computing the Arc Length**

The parameter-space semicircle has radius $\frac{\sqrt{2}}{2}$. Since $|{\partial P}/{\partial s}| = |{\partial P}/{\partial t}| = 2$, the 3D metric scales parameter distances by factor $2$.

The 3D radius $= 2 \times \frac{\sqrt{2}}{2} = \sqrt{2}$, consistent with $r = \sqrt{5-3} = \sqrt{2}$. ✓

**Arc length** $= \pi r = \pi\sqrt{2}$

$$\boxed{\pi\sqrt{2}}$$

## 【进阶解法/技巧】

**Geometric Insight**

The face $BCC_1B_1$ is a $2\times 2$ square (perpendicular sides $BC = 2$, $BB_1 = 2$).

The critical observation is that the **projection of $D_1$ onto the face plane lands exactly at the midpoint of edge $B_1C_1$**:

$$P_0 = D_1 + \sqrt{3}\cdot\frac{(\sqrt{3},-1,0)}{2} = \left(\frac{5}{2},\;\frac{\sqrt{3}}{2},\;2\right) = \text{midpoint of } B_1C_1$$

Since the circle center sits **on the boundary edge** of the square face, exactly half the circle (a semicircle) lies inside the face.

**Vertex Distance Check** (confirms the semicircle picture):

| Vertex | $D_1 = (1,\sqrt{3},2)$ | Distance | Inside? |
|--------|------------------------|----------|---------|
| $B_1 = (2,0,2)$ | $(1,-\sqrt{3},0)$ | $2$ | ✅ $< \sqrt{5}$ |
| $C_1 = (3,\sqrt{3},2)$ | $(2,0,0)$ | $2$ | ✅ $< \sqrt{5}$ |
| $B = (2,0,0)$ | $(1,-\sqrt{3},-2)$ | $2\sqrt{2}$ | ❌ $> \sqrt{5}$ |
| $C = (3,\sqrt{3},0)$ | $(2,0,-2)$ | $2\sqrt{2}$ | ❌ $> \sqrt{5}$ |

Both vertices on edge $B_1C_1$ are **inside** the sphere, while vertices on edge $BC$ are **outside**. The intersection curve connects two points on $B_1C_1$, forming a semicircle of radius $\sqrt{2}$.

**Direct 3D parametrization** confirms: with $\theta \in [\pi, 2\pi]$:

$$\frac{dP}{d\theta} = \left(-\tfrac{\sqrt{2}}{2}\sin\theta,\; -\tfrac{\sqrt{6}}{2}\sin\theta,\; \sqrt{2}\cos\theta\right)$$

$$\left|\frac{dP}{d\theta}\right|^2 = \tfrac{1}{2}\sin^2\theta + \tfrac{3}{2}\sin^2\theta + 2\cos^2\theta = 2\sin^2\theta + 2\cos^2\theta = 2$$

$$\text{Length} = \int_{\pi}^{2\pi} \sqrt{2}\; d\theta = \pi\sqrt{2} \quad \checkmark$$

## 【总结与反思】

**核心思想**：球面与平面的交线是圆；球面与平面内的矩形区域的交线是圆弧。关键步骤是：

1. **计算球心到平面距离** $d$，得圆半径 $r = \sqrt{R^2 - d^2}$
2. **确定圆心在矩形内的位置** — 若圆心在边界上，则交线为**半圆**
3. **结合数形一体**，检查矩形四顶点与球心的距离关系，快速判断交线形状

**陷阱点**：
- 易混淆"棱长"（所有棱的统称）——需确认底边与侧棱都为 2
- 投影点位置必须精确判断：是面内某点还是恰好在边上的点
- 参数化后记得**考虑度量缩放因子**，否则会算错弧长

**迁移场景**：此"球面—矩形面"交弧长问题的解法可推广至：球面与任意平面多边形区域相交，其交线是圆弧段，弧长 $= r \cdot \alpha$（$\alpha$ 为圆心角）。

$$\boxed{\pi\sqrt{2}}$$
