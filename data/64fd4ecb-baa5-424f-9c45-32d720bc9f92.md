这是一道典型的三角函数方程组问题。其核心在于利用**互余关系**（Complementary Angle Relationship）将双变量问题转化为单变量问题，并敏锐地识别出结果处于**极值状态**这一关键特征。

### 【元解析与特征挖掘】

1.  **结构分量分析**：
    *   已知条件 $\alpha + \beta = \dfrac{\pi}{2}$ 是一个强约束，直接揭示了 $\sin\beta = \cos\alpha$ 且 $\cos\beta = \sin\alpha$。
    *   目标方程 $3\sin\alpha - \sin\beta = \sqrt{10}$ 经过代换后将变为 $3\sin\alpha - \cos\alpha = \sqrt{10}$。
2.  **指纹识别（Feature Identification）**：
    *   观察方程 $3\sin\alpha - \cos\alpha = \sqrt{10}$，其形式为 $a\sin\theta + b\cos\theta = c$。
    *   计算辅助角公式的幅值：$\sqrt{a^2 + b^2} = \sqrt{3^2 + (-1)^2} = \sqrt{10}$。
    *   **关键洞察**：等号右侧恰好等于幅值 $\sqrt{10}$。这意味着该函数达到了它的**最大值**。在数学竞赛或高考压轴题中，这种“恰好相等”的结构通常意味着解的唯一性，且可以通过向量共线或极值条件快速秒杀。

---

### 【常规解法：代数推导路径】

**步骤 1：利用互余关系化简**
由 $\alpha + \beta = \dfrac{\pi}{2}$ 可得：
$$\sin\beta = \sin\left(\frac{\pi}{2} - \alpha\right) = \cos\alpha$$
将其代入原方程 $3\sin\alpha - \sin\beta = \sqrt{10}$，得：
$$3\sin\alpha - \cos\alpha = \sqrt{10}$$

**步骤 2：辅助角公式求解**
对方程左边进行辅助角变换，提取 $\sqrt{3^2 + (-1)^2} = \sqrt{10}$：
$$\sqrt{10} \left( \frac{3}{\sqrt{10}}\sin\alpha - \frac{1}{\sqrt{10}}\cos\alpha \right) = \sqrt{10}$$
$$\text{令 } \cos\phi = \frac{3}{\sqrt{10}}, \sin\phi = \frac{1}{\sqrt{10}} \quad (\phi \in (0, \frac{\pi}{2}))$$
则原式变为：
$$\sin(\alpha - \phi) = 1$$

**步骤 3：确定三角函数值**
由于 $\sin(\alpha - \phi) = 1$，则 $\alpha - \phi = \frac{\pi}{2} + 2k\pi$。
由此可得：
$$\sin\alpha = \sin\left(\frac{\pi}{2} + \phi\right) = \cos\phi = \frac{3}{\sqrt{10}} = \frac{3\sqrt{10}}{10}$$
$$\cos\alpha = \cos\left(\frac{\pi}{2} + \phi\right) = -\sin\phi = -\frac{1}{\sqrt{10}} = -\frac{\sqrt{10}}{10}$$

**步骤 4：求解 $\beta$ 相关值及倍角**
利用 $\sin\beta = \cos\alpha$ 和 $\cos\beta = \sin\alpha$：
$$\sin\beta = -\frac{\sqrt{10}}{10}, \quad \cos\beta = \frac{3\sqrt{10}}{10}$$
最后计算 $\cos 2\beta$：
$$\cos 2\beta = 1 - 2\sin^2\beta = 1 - 2\left(-\frac{1}{\sqrt{10}}\right)^2 = 1 - \frac{2}{10} = \frac{8}{10} = \frac{4}{5}$$

### 【进阶解法：极值与向量视角】

对于资深学习者，可以跳过繁琐的辅助角计算，直接使用**柯西不等式**或**向量投影**思想。

**1. 柯西不等式视角**：
考虑形式 $(3, -1) \cdot (\sin\alpha, \cos\alpha) = 3\sin\alpha - \cos\alpha$。
根据柯西不等式：
$$(3\sin\alpha - \cos\alpha)^2 \le (3^2 + (-1)^2)(\sin^2\alpha + \cos^2\alpha) = 10 \cdot 1 = 10$$
即 $-\sqrt{10} \le 3\sin\alpha - \cos\alpha \le \sqrt{10}$。
由于等号成立，必须满足**等号成立条件（分量成比例）**：
$$\frac{\sin\alpha}{3} = \frac{\cos\alpha}{-1} = \lambda$$
代入 $\sin^2\alpha + \cos^2\alpha = 1$：
$$(3\lambda)^2 + (-\lambda)^2 = 1 \implies 10\lambda^2 = 1 \implies \lambda = \pm \frac{1}{\sqrt{10}}$$
因为 $3\sin\alpha - \cos\alpha = \sqrt{10} > 0$，故 $\lambda$ 必须为正值 $\frac{1}{\sqrt{10}}$。
直接得出：
$$\sin\alpha = \frac{3}{\sqrt{10}}, \quad \cos\alpha = -\frac{1}{\sqrt{10}}$$

**结论汇总**：
$$\sin\alpha = \frac{3\sqrt{10}}{10}, \quad \cos\alpha = -\frac{\sqrt{10}}{10}, \quad \sin\beta = -\frac{\sqrt{10}}{10}, \quad \cos\beta = \frac{3\sqrt{10}}{10}, \quad \cos 2\beta = \frac{4}{5}$$
