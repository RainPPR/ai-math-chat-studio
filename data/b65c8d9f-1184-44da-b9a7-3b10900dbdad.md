```text
model/2026-08-04T12:26:45.999Z

你好！这道题目非常有代表性，它考察的是遗传学中一个非常经典且进阶的模型——**“淘汰隐性个体”的种群动态演变**。

很多同学在面对这类题目时，容易把“随机交配（自由交配）”和“连续自交”混淆。其实，这两者的核心区别在于：**随机交配改变的是基因频率（$p, q$），而自交改变的是基因型频率（$\text{AA}, \text{Aa}, \text{aa}$），且不改变基因频率。**

为了让你彻底理解，我将把这个问题拆解为两个独立的专项分析，并在计算前先为你推导相关的“二级结论（快捷公式）”。

---

### 核心概念设定
*   **亲代 ($G_0$)**：全部为 $\text{Aa}$。
*   **淘汰规则**：每一代交配产生后代后，立即将所有表型为隐性的个体 ($\text{aa}$) 剔除，剩余的个体进入下一轮交配。
*   **目标**：计算特定世代中 $\text{Aa}$ 的基因型频率。

---

### 第一部分：随机交配 + 淘汰隐性个体（自由交配模型）

#### 1. 逻辑推演
在随机交配中，个体的结合是随机的，只要我们知道当前群体的基因频率 $p(\text{A})$ 和 $q(\text{a})$，后代的基因型比例就遵循哈代-温伯格定律：$p^2 \text{AA} : 2pq \text{Aa} : q^2 \text{aa}$。但由于 $\text{aa}$ 被淘汰，每一代的基因频率都会发生改变。

*   **第一代 ($G_1$)**：
    $\text{Aa} \times \text{Aa} \rightarrow 1\text{AA} : 2\text{Aa} : 1\text{aa}$
    淘汰 $\text{aa}$ $\rightarrow$ 剩余 $1\text{AA} : 2\text{Aa}$。
    此时 $\text{Aa}$ 的基因型频率为 $\frac{2}{1+2} = \frac{2}{3}$。
    **此时基因频率**：$q_1(\text{a}) = \frac{1}{2} \times \frac{2}{3} = \frac{1}{3}$，$p_1(\text{A}) = \frac{2}{3}$。

*   **第二代 ($G_2$)**：
    $G_1$ 随机交配，后代比例为：$p_1^2 \text{AA} : 2p_1q_1 \text{Aa} : q_1^2 \text{aa} = (\frac{2}{3})^2 \text{AA} : 2(\frac{2}{3})(\frac{1}{3}) \text{Aa} : (\frac{1}{3})^2 \text{aa} = \frac{4}{9} \text{AA} : \frac{4}{9} \text{Aa} : \frac{1}{9} \text{aa}$。
    淘汰 $\text{aa}$ $\rightarrow$ 剩余 $\frac{4}{9} \text{AA} : \frac{4}{9} \text{Aa}$，简化为 $1\text{AA} : 1\text{Aa}$。
    此时 $\text{Aa}$ 的基因型频率为 $\frac{1}{1+1} = \frac{1}{2}$。
    **此时基因频率**：$q_2(\text{a}) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$，$p_2(\text{A}) = \frac{3}{4}$。

*   **第三代 ($G_3$)**：
    $G_2$ 随机交配，后代比例为：$p_2^2 \text{AA} : 2p_2q_2 \text{Aa} : q_2^2 \text{aa} = (\frac{3}{4})^2 \text{AA} : 2(\frac{3}{4})(\frac{1}{4}) \text{Aa} : (\frac{1}{4})^2 \text{aa} = \frac{9}{16} \text{AA} : \frac{6}{16} \text{Aa} : \frac{1}{16} \text{aa}$。
    淘汰 $\text{aa}$ $\rightarrow$ 剩余 $\frac{9}{16} \text{AA} : \frac{6}{16} \text{Aa}$，简化为 $3\text{AA} : 2\text{Aa}$。
    此时 $\text{Aa}$ 的基因型频率为 $\frac{2}{3+2} = \frac{2}{5}$。

#### 2. 二级结论（淘隐自由交配公式）
观察上述结果，$\text{AA}$ 的频率分别为：$G_1: \frac{1}{3}, G_2: \frac{2}{4} (\text{即}\frac{1}{2}), G_3: \frac{3}{5}$。
我们可以发现一个规律：在随机交配并逐代淘汰 $\text{aa}$ 后，$n$ 代显性个体中 $\text{AA}$ 的频率为 $\frac{n}{n+2}$。
那么 $\text{Aa}$ 的频率即为 $1 - \frac{n}{n+2} = \frac{2}{n+2}$。

**结论：第三代 $\text{Aa}$ 的基因型频率为 $\frac{2}{3+2} = \frac{2}{5}$。**

---

### 第二部分：连续自交 + 淘汰隐性个体（自交模型）

#### 1. 逻辑推演
自交与随机交配最大的不同是：$\text{AA}$ 个体自交永远产生 $\text{AA}$，而 $\text{Aa}$ 个体自交每次都会产生 $\frac{1}{4}$ 的 $\text{aa}$。

*   **第一代 ($G_1$)**：
    $\text{Aa} \otimes \text{Aa} \rightarrow 1\text{AA} : 2\text{Aa} : 1\text{aa}$
    淘汰 $\text{aa}$ $\rightarrow$ 剩余 $1\text{AA} : 2\text{Aa}$。
    此时 $\text{Aa}$ 的基因型频率为 $\frac{2}{1+2} = \frac{2}{3}$。

*   **第二代 ($G_2$)**：
    现在的群体由 $\frac{1}{3} \text{AA}$ 和 $\frac{2}{3} \text{Aa}$ 组成，分别自交：
    - $\frac{1}{3} \text{AA} \otimes \text{AA} \rightarrow \frac{1}{3} \text{AA}$
    - $\frac{2}{3} \text{Aa} \otimes \text{Aa} \rightarrow \frac{2}{3} \times (\frac{1}{4} \text{AA} : \frac{1}{2} \text{Aa} : \frac{1}{4} \text{aa}) = \frac{1}{6} \text{AA} : \frac{1}{3} \text{Aa} : \frac{1}{6} \text{aa}$
    
    汇总所有后代：
    $\text{AA} = \frac{1}{3} + \frac{1}{6} = \frac{1}{2}$
    $\text{Aa} = \frac{1}{3}$
    $\text{aa} = \frac{1}{6}$
    
    淘汰 $\text{aa}$（淘汰掉 $\frac{1}{6}$ 的个体），剩余总量为 $1 - \frac{1}{6} = \frac{5}{6}$。
    此时 $\text{Aa}$ 的基因型频率为 $\frac{1/3}{5/6} = \frac{1}{3} \times \frac{6}{5} = \frac{2}{5}$。

#### 2. 二级结论（淘隐自交公式）
在连续自交并淘汰 $\text{aa}$ 的模型中，$n$ 代后显性个体中 $\text{AA}$ 的频率为 $\frac{2^n-1}{2^n+1}$。
那么 $\text{Aa}$ 的频率即为 $1 - \frac{2^n-1}{2^n+1} = \frac{2}{2^n+1}$。

**证明（简述）**：
自交每代杂合子减半，但由于 $\text{aa}$ 被剔除，分母在缩小。通过递推可得上述公式。
代入 $n=2$：$\text{Aa}$ 频率 $= \frac{2}{2^2+1} = \frac{2}{5}$。

**结论：第二代 $\text{Aa}$ 的基因型频率为 $\frac{2}{5}$。**

---

### 总结与对比

|  mating 方式 | 淘汰 $\text{aa}$ 后 $n$ 代 $\text{Aa}$ 频率公式 | 本题计算结果 | 核心逻辑 |
| :--- | :--- | :--- | :--- |
| **随机交配** | $\frac{2}{n+2}$ | $G_3 \rightarrow \frac{2}{5}$ | 基因频率 $q$ 逐代递减 ($\frac{1}{2} \rightarrow \frac{1}{3} \rightarrow \frac{1}{4} \rightarrow \frac{1}{5}$) |
| **连续自交** | $\frac{2}{2^n+1}$ | $G_2 \rightarrow \frac{2}{5}$ | 杂合子因自交而迅速丢失，但淘汰 $\text{aa}$ 减缓了丢失速度 |

**专家提醒：**
在这道题中，巧合的是随机交配的第三代和连续自交的第二代结果相同（都是 $\frac{2}{5}$），但在生物学本质上，随机交配是通过“基因库”的整体漂移来改变频率，而自交是通过“纯合化”来改变频率。在考试中，请务必先分清交配方式，再选择推演路径！
```
