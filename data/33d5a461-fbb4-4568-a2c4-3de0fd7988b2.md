这是一道典型的三角恒等变换问题。题目给出了 $\sin\alpha$ 与 $\cos\alpha$ 的线性组合，要求求解 $\tan 2\alpha$。

### 🧠 元解析与特征挖掘 (Meta-Analysis)

在进入具体计算前，我们先对题干进行“指纹”识别：

1.  **结构分析**：已知条件 $\sin\alpha + 2\cos\alpha = \frac{\sqrt{10}}{2}$ 属于 $a\sin\alpha + b\cos\alpha = c$ 形式。这种结构的本质是**辅助角公式**的逆向应用，或者可以看作单位圆与一条直线的交点问题。
2.  **目标分析**：目标是 $\tan 2\alpha$。根据倍角公式 $\tan 2\alpha = \frac{2\tan\alpha}{1-\tan^2\alpha}$，我们发现 $\tan 2\alpha$ 仅取决于 $\tan\alpha$ 的值。
3.  **核心博弈**：
    *   **路径 A（常规）**：利用辅助角公式求出 $\alpha$ 的范围或 $\sin\alpha, \cos\alpha$ 的具体值 $\to$ 求 $\tan\alpha \to$ 求 $\tan 2\alpha$。
    *   **路径 B（代数）**：通过平方消除根号，构造关于 $\cos\alpha$ 或 $\sin\alpha$ 的一元二次方程。
    *   **路径 C（高维/同构）**：直接将原式“正切化”，构造关于 $\tan\alpha$ 的方程，直接跳过对 $\sin\alpha$ 和 $\cos\alpha$ 的单独求解。

---

### 🛠️ 常规解法：辅助角法与代数推导

**步骤 1：利用辅助角公式化简**
左边 $\sin\alpha + 2\cos\alpha$ 可以写成：
$$\sqrt{1^2+2^2} \sin(\alpha + \phi) = \sqrt{5}\sin(\alpha + \phi)$$
其中 $\tan\phi = \frac{2}{1} = 2$。

代入原式得：
$$\sqrt{5}\sin(\alpha + \phi) = \frac{\sqrt{10}}{2} \implies \sin(\alpha + \phi) = \frac{\sqrt{10}}{2\sqrt{5}} = \frac{\sqrt{2}}{2}$$

**步骤 2：确定 $\alpha + \phi$ 的取值**
由此可知 $\alpha + \phi = \frac{\pi}{4} + 2k\pi$ 或 $\alpha + \phi = \frac{3\pi}{4} + 2k\pi$。
这意味着 $\tan(\alpha + \phi) = \pm 1$。

**步骤 3：求解 $\tan\alpha$**
利用正切的和角公式 $\tan(\alpha + \phi) = \frac{\tan\alpha + \tan\phi}{1 - \tan\alpha\tan\phi}$，且已知 $\tan\phi = 2$：

*   **情况 1**：$\frac{\tan\alpha + 2}{1 - 2\tan\alpha} = 1 \implies \tan\alpha + 2 = 1 - 2\tan\alpha \implies 3\tan\alpha = -1 \implies \tan\alpha = -\frac{1}{3}$
*   **情况 2**：$\frac{\tan\alpha + 2}{1 - 2\tan\alpha} = -1 \implies \tan\alpha + 2 = -1 + 2\tan\alpha \implies \tan\alpha = 3$

**步骤 4：计算 $\tan 2\alpha$**
无论 $\tan\alpha = 3$ 还是 $\tan\alpha = -\frac{1}{3}$：
$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$$
*   若 $\tan\alpha = 3$，则 $\tan 2\alpha = \frac{2 \times 3}{1 - 3^2} = \frac{6}{-8} = -\frac{3}{4}$
*   若 $\tan\alpha = -\frac{1}{3}$，则 $\tan 2\alpha = \frac{2 \times (-1/3)}{1 - (-1/3)^2} = \frac{-2/3}{8/9} = -\frac{2}{3} \times \frac{9}{8} = -\frac{3}{4}$

**结论**：$\tan 2\alpha = -\frac{3}{4}$。

### 🚀 进阶解法：正切同构法 (The Elegant Way)

如果我们直接将原式 $\sin\alpha + 2\cos\alpha = \frac{\sqrt{10}}{2}$ 进行“正切化”处理，可以极大简化计算量。

**1. 构造 $\tan\alpha$ 方程**
将原式两边同时除以 $\cos\alpha$（假设 $\cos\alpha \neq 0$）：
$$\tan\alpha + 2 = \frac{\sqrt{10}}{2\cos\alpha}$$

**2. 利用平方关系消除 $\cos\alpha$**
两边平方：
$$(\tan\alpha + 2)^2 = \frac{10}{4\cos^2\alpha}$$
利用恒等式 $\frac{1}{\cos^2\alpha} = 1 + \tan^2\alpha$：
$$(\tan\alpha + 2)^2 = \frac{5}{2}(1 + \tan^2\alpha)$$

**3. 求解二次方程**
令 $t = \tan\alpha$，则有：
$$t^2 + 4t + 4 = 2.5 + 2.5t^2$$
$$1.5t^2 - 4t - 1.5 = 0$$
两边同乘 2 得：
$$3t^2 - 8t - 3 = 0$$
因式分解得：
$$(3t + 1)(t - 3) = 0$$
解得 $t = 3$ 或 $t = -\frac{1}{3}$。

**4. 快速得出结论**
注意到这两个根 $t_1, t_2$ 满足 $t_1 \cdot t_2 = -1$，这意味着 $\tan\alpha$ 的两个可能值代表两条相互垂直的直线。对于 $\tan 2\alpha$ 而言，由于 $\tan 2\alpha = \frac{2t}{1-t^2}$，且满足 $f(t) = f(-1/t)$，因此结果必然唯一。
$$\tan 2\alpha = \frac{2 \times 3}{1 - 9} = -\frac{3}{4}$$

### 📝 总结与反思 (Cognitive Reflection)

#### 1. 知识模型提炼
本题的本质是**从线性组合到倍角函数**的映射。
*   **模型 A $\to$ B**：$a\sin\alpha + b\cos\alpha = c \xrightarrow{\text{辅助角}} \sin(\alpha + \phi) = \frac{c}{\sqrt{a^2+b^2}}$
*   **模型 A $\to$ C**：$a\sin\alpha + b\cos\alpha = c \xrightarrow{\text{正切化}} (a\tan\alpha + b)^2 = \frac{c^2}{k}(1+\tan^2\alpha)$

#### 2. 陷阱与注意点
*   **多值性 $\to$ 单值性**：在本题中，$\tan\alpha$ 有两个解，但 $\tan 2\alpha$ 只有一个解。在考场上，如果算出一个 $\tan\alpha$ 就直接计算 $\tan 2\alpha$，虽然结果正确，但在严谨的解答题中可能会被扣除“讨论不充分”的分数。
*   **除法前提**：在进行 $\tan\alpha$ 替换时，必须隐含或注明 $\cos\alpha \neq 0$。本题中若 $\cos\alpha = 0$，则 $\sin\alpha = \pm 1$，代入原式 $\pm 1 + 0 = \frac{\sqrt{10}}{2}$ 不成立，故 $\cos\alpha \neq 0$ 成立。

#### 3. 迁移场景
当你看到 $\sin\alpha$ 和 $\cos\alpha$ 的一次线性组合，且目标是 $\tan\alpha$ 或其倍角时，**优先考虑“正切化”**。这种方法将三角函数问题转化为代数方程问题，避免了处理 $\arcsin$ 或 $\arccos$ 等反三角函数带来的角度区间混乱，是处理高考压轴三角题的高效路径。
