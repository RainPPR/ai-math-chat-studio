### 【常规解法】

我们先进行**结构特征挖掘**：函数包含 $\sin x$、$\cos x$ 以及它们的乘积 $\sin x\cos x$。这类“一次式 + 乘积式”的结构，天然适配换元 $t = \sin x - \cos x$（或 $\sin x + \cos x$），因为 $t^2$ 可直接解出 $\sin x\cos x$。

**步骤 1：换元降维**

令

$$ t = \sin x - \cos x = \sqrt{2}\sin\left(x - \frac{\pi}{4}\right) $$

由正弦函数值域可知，$t$ 的取值范围为闭区间

$$ t \in [-\sqrt{2}, \sqrt{2}] $$

**步骤 2：表达乘积项**

对 $t$ 平方：

$$ t^2 = (\sin x - \cos x)^2 = 1 - 2\sin x\cos x $$

从而解出

$$ \sin x\cos x = \frac{1 - t^2}{2} $$

**步骤 3：原函数化为二次函数**

代入 $f(x)$ 得

$$ f(x) = t + \frac{1 - t^2}{2} = -\frac{1}{2}t^2 + t + \frac{1}{2} $$

将其配方，凸显几何直观：

$$ f(x) = 1 - \frac{1}{2}(t - 1)^2 $$

**步骤 4：闭区间上的最值分析**

二次函数 $g(t) = 1 - \frac{1}{2}(t-1)^2$ 开口向下，对称轴 $t = 1$ 位于区间 $[-\sqrt{2}, \sqrt{2}]$ 内部。

- **最大值**：当 $t = 1$ 时，

  $$ g(1) = 1 $$

  此时对应 $x = \frac{\pi}{2} + 2k\pi$（$k \in \mathbb{Z}$），验证 $f\left(\frac{\pi}{2}\right) = 1 - 0 + 0 = 1$，成立。

- **最小值**：比较区间端点离对称轴的距离。
  
  $|-\sqrt{2} - 1| = 1 + \sqrt{2}$，而 $|\sqrt{2} - 1| = \sqrt{2} - 1$，前者更远，故 $t = -\sqrt{2}$ 时取最小：

  $$ g(-\sqrt{2}) = 1 - \frac{1}{2}(-\sqrt{2} - 1)^2 = 1 - \frac{1}{2}(3 + 2\sqrt{2}) = -\frac{1}{2} - \sqrt{2} $$

  此时对应 $x = -\frac{\pi}{4} + 2k\pi$，代入原式亦吻合。

因此，函数的值域为

$$ \boxed{\left[-\frac{1}{2} - \sqrt{2},\ 1\right]} $$

---

### 【进阶解法/技巧】

**1. 导数验证法（逻辑证伪路径）**

若采用暴力算力，可直接求导：

$$ f'(x) = \cos x + \sin x + \cos 2x = (\cos x + \sin x) + (\cos^2 x - \sin^2 x) = (\cos x + \sin x)(1 + \cos x - \sin x) $$

令 $f'(x) = 0$，得

- $\cos x + \sin x = 0 \implies x = -\frac{\pi}{4} + k\pi$
- $\cos x - \sin x = -1 \implies \sqrt{2}\cos\left(x + \frac{\pi}{4}\right) = -1$，解得 $x = \frac{\pi}{2} + 2k\pi$ 或 $x = \pi + 2k\pi$（需检验）

代入计算函数值，同样得到极大 $1$、极小 $-\frac{1}{2}-\sqrt{2}$。此方法计算琐碎，但可作为考场上的交叉验证。

**2. 结构同构视角**

观察到 $f(x) = (\sin x - \cos x) + \frac{1}{2}\cdot 2\sin x\cos x$，而 $2\sin x\cos x = 1 - (\sin x - \cos x)^2$，这本质上就是“一元二次型”的隐变量替换。在高维认知中，所有 $a\sin x + b\cos x + c\sin x\cos x$ 均可归入同一schema，无需重复推导。

### 【总结与反思】

**解题逻辑模板**

1. **识别指纹**：题目中同时出现 $\sin x \pm \cos x$ 与 $\sin x\cos x$ → 触发“平方关系”预警。
2. **换元降维**：设 $t = \sin x \pm \cos x$，将三角问题转化为代数二次函数在闭区间上的最值。
3. **边界校验**：务必确认 $t$ 的取值范围（由辅助角公式得 $[-\sqrt{2}, \sqrt{2}]$），不可默认 $t \in \mathbb{R}$。
4. **配方求极**：利用顶点与端点比较，零误差输出值域。

**陷阱点**

- 换元后忽略 $t$ 的有界性，误将二次函数定义域当作全体实数，导致值域错误扩大。
- 若选择 $u = \sin x + \cos x$，则 $\sin x - \cos x = \pm\sqrt{1-u^2}$，会引入符号讨论，增加复杂度，故优先选与一次项匹配的换元。

**知识迁移**

此模型可无缝迁移至：
- 解析几何中参数方程 $x=\cos\theta, y=\sin\theta$ 下的二元函数极值；
- 不等式证明中的“三角代换”降次；
- 甚至概率论中某些周期随机变量的期望计算。

掌握这一“母题”，便能以不变应万变，在压轴题中迅速建立解题坐标系。 🔍
