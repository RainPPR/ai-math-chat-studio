这道题目是一道典型的涉及**整函数（取整函数）的最值问题**。这类题的核心在于如何处理整函数 $[x]$ 的跳跃性，通过将实数域上的问题转化为周期区间内的分段函数问题来求解。

### 一、 元解析与特征挖掘（Feature Mining）

1.  **周期性识别**：观察函数 $f(x) = |x-[x+a]| + |x-[x-a]|$。注意到 $[x+a]$ 是周期为 $1$ 的函数，且 $x$ 也是周期为 $1$ 的函数，因此 $f(x)$ 是一个周期为 $1$ 的周期函数。这意味着我们只需要在区间 $[0, 1)$ 上讨论其值。
2.  **变量转化**：利用整函数的性质 $x = [x] + \{x\}$，其中 $0 \le \{x\} < 1$。
    设 $x = n + t$，其中 $n \in \mathbb{Z}, t \in [0, 1)$。
    代入函数：
    $$[x+a] = [n+t+a] = n + [t+a]$$
    $$[x-a] = [n+t-a] = n + [t-a]$$
    则
    $$f(x) = |(n+t) - (n+[t+a])| + |(n+t) - (n+[t-a])| = |t-[t+a]| + |t-[t-a]|$$
    现在问题转化为：对于 $t \in [0, 1)$，求 $g(t) = |t-[t+a]| + |t-[t-a]|$ 的最大值。
3.  **分段策略**：函数 $[t+a]$ 和 $[t-a]$ 的取值取决于 $t$ 是否跨越整数。
    - $[t+a]$：当 $t < 1-a$ 时为 $0$；当 $t \ge 1-a$ 时为 $1$。
    - $[t-a]$：当 $t < a$ 时为 $-1$；当 $t \ge a$ 时为 $0$。

---

### 二、 常规解法（The Ground Solution）

根据 $a$ 与 $1-a$ 的大小关系，对区间 $[0, 1)$ 进行分段讨论。

#### 情况一：当 $a < 1-a$（即 $a < \frac{1}{2}$）
此时临界点顺序为 $0 < a < 1-a$，区间分为：
1. **$0 \le t < a$ 时**：
   $[t+a]=0, [t-a]=-1 \implies g(t) = |t-0| + |t-(-1)| = 2t+1$。
   在该区间内单调递增，上界趋于 $2a+1$。
2. **$a \le t < 1-a$ 时**：
   $[t+a]=0, [t-a]=0 \implies g(t) = |t-0| + |t-0| = 2t$。
   在该区间内单调递增，上界趋于 $2(1-a) = 2-2a$。
3. **$1-a \le t < 1$ 时**：
   $[t+a]=1, [t-a]=0 \implies g(t) = |t-1| + |t-0| = (1-t)+t = 1$。
   在该区间内恒等于数 $1$。

由于 $a < \frac{1}{2}$，则 $2a+1 < 2$ 且 $2-2a > 1$。比较 $2a+1$ 与 $2-2a$：
$2a+1 > 2-2a \iff 4a > 1 \iff a > \frac{1}{2}$。
故在 $a < \frac{1}{2}$ 时，最大值为 $M(a) = 2-2a$。

#### 情况二：当 $a \ge 1-a$（即 $a \ge \frac{1}{2}$）
此时临界点顺序为 $0 < 1-a \le a$，区间分为：
1. **$0 \le t < 1-a$ 时**：
   $[t+a]=0, [t-a]=-1 \implies g(t) = 2t+1$。
   在该区间内单调递增，上界趋于 $2(1-a)+1 = 3-2a$。
2. **$1-a \le t < a$ 时**：
   $[t+a]=1, [t-a]=-1 \implies g(t) = |t-1| + |t+1| = (1-t)+(t+1) = 2$。
   在该区间内恒等于数 $2$。
3. **$a \le t < 1$ 时**：
   $[t+a]=1, [t-a]=0 \implies g(t) = |t-1| + |t| = 1$。
   在该区间内恒等于数 $1$。

由于 $a \ge \frac{1}{2}$，则 $3-2a \le 2$。
故在 $a \ge \frac{1}{2}$ 时，最大值为 $M(a) = 2$。

### 三、 进阶解法/技巧（High-Level Strategy）

**几何直观法**：
$f(x) = |x-[x+a]| + |x-[x-a]|$ 的几何意义是：数轴上点 $x$ 到两个整数点 $A=[x+a]$ 和 $B=[x-a]$ 的距离之和。

- 注意到 $A$ 和 $B$ 的距离 $d = [x+a] - [x-a]$。
- 根据整函数的性质，$[x+a] - [x-a]$ 只能取 $\lfloor a \rfloor$ 或 $\lceil a \rceil$。
- 因为 $a \in (0,1)$，所以 $\lfloor a \rfloor = 0$，$\lceil a \rceil = 1$。
- 当距离为 $0$ 时（即 $A=B$），$f(x) = 2|x-A|$。由于 $x$ 到整数 $A$ 的最大距离接近 $1$，故 $f(x)$ 最大接近 $2$。
- 当距离为 $1$ 时（即 $A=B+1$），$f(x) = |x-(B+1)| + |x-B|$。根据三角形不等式性质，当 $x$ 在 $B$ 和 $B+1$ 之间时，距离之和恒为 $1$；当 $x$ 在之外时，距离之和大于 $1$。

然而，我们需要找的是全局最大值。当 $a$ 较小时，$A$ 和 $B$ 容易重合，$x$ 远离它们一个时会产生接近 $2$ 的值；当 $a$ 较大时，$A$ 和 $B$ 强制分开，$x$ 落在它们中间时距离之和被锁定在 $2$。这种直观完美揭示了分段讨论的本质。

---

### 四、 总结与反思（Cognitive Reflection）

**1. 题型模型**：
本题属于**“周期整函数最值问题”**。其标准逻辑模板为：
**识别周期性 $\to$ 转化为局部分数部分 $\{x\}$ $\to$ 确定临界点分段 $\to$ 讨论单调性求最值。**

**2. 陷阱点提醒**：
- 忽略 $a$ 与 $1-a$ 的关系，会导致分段讨论逻辑错误。
- 在处理绝对值符号和整函数的临界点时，必须注意边界的开闭性（虽然本题中最大值出现在临界点处或其极限处）。

**3. 结论汇总**：
$$M(a) = \begin{cases} 2-2a, & 0 < a < \frac{1}{2} \\ 2, & \frac{1}{2} \le a < 1 \end{cases}$$
亦也可以表示为 $M(a) = \max(2, 2-2a)$。
