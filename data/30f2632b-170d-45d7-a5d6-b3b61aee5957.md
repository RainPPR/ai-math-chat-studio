【常规解法】

首先，观察函数解析式并做结构变形：

$$ f(x) = 2\sin x + \sin 2x = 2\sin x + 2\sin x \cos x = 2\sin x (1 + \cos x) $$

由于 $f(-x) = -f(x)$，函数为奇函数；且周期由 $\sin x$ 与 $\sin 2x$ 的公共周期确定为 $2\pi$。因此只需在 $x \in [0, \pi]$ 上寻找最大值，最小值由对称性取负即可。注意在 $[0, \pi]$ 内 $\sin x \ge 0$ 且 $1+\cos x \ge 0$，故 $f(x) \ge 0$。

1. **求导并因式分解**

$$ f'(x) = 2\cos x + 2\cos 2x = 2\cos x + 2(2\cos^2 x - 1) = 4\cos^2 x + 2\cos x - 2 $$

提取公因子并十字相乘：

$$ f'(x) = 2(2\cos^2 x + \cos x - 1) = 2(2\cos x - 1)(\cos x + 1) $$

2. **临界点与单调性分析**

在 $x \in [0, \pi]$ 上，$\cos x \in [-1, 1]$，$\cos x + 1 \ge 0$ 恒成立。令 $f'(x) = 0$ 得：

- $\cos x = \frac{1}{2} \Rightarrow x = \frac{\pi}{3}$
- $\cos x = -1 \Rightarrow x = \pi$（区间端点）

当 $x \in [0, \frac{\pi}{3})$ 时，$\cos x > \frac{1}{2}$，故 $2\cos x - 1 > 0$，从而 $f'(x) > 0$，函数单调递增；

当 $x \in (\frac{\pi}{3}, \pi]$ 时，$\cos x < \frac{1}{2}$ 且 $\cos x > -1$，故 $2\cos x - 1 < 0$，从而 $f'(x) < 0$，函数单调递减。

3. **极值与端点计算**

$$ f(0) = 0, \quad f(\pi) = 0 $$

$$ f\left(\frac{\pi}{3}\right) = 2\sin\frac{\pi}{3} + \sin\frac{2\pi}{3} = 2 \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{2} $$

因此，在 $[0, \pi]$ 上最大值为 $\frac{3\sqrt{3}}{2}$。由奇函数性质，全局最小值为 $-\frac{3\sqrt{3}}{2}$。

4. **逻辑检验（特殊值验证）**

取 $x = \frac{\pi}{2}$，$f = 2 > 0$ 且 $2 < \frac{3\sqrt{3}}{2} \approx 2.598$，符合单调递减区间预期；取 $x = \frac{\pi}{6}$，$f = 2\cdot\frac12 + \sin\frac{\pi}{3} = 1 + \frac{\sqrt3}{2} \approx 1.866 < 2.598$，符合递增未到顶。无矛盾。

结论：**值域为 $\left[ -\frac{3\sqrt{3}}{2}, \frac{3\sqrt{3}}{2} \right]$**。

【进阶解法/技巧】 ✨

上述导数法直观且不易错，但我们可以展现更具“数学美感”的代数放缩路径。

**路径 A：换元 + 加权 AM-GM 不等式**

在 $x \in [0, \pi]$ 上，设 $t = \cos x \in [-1, 1]$，则 $\sin x = \sqrt{1 - t^2}$，于是

$$ f(x) = 2\sqrt{1 - t^2}(1 + t) \quad \text{where } 1+t \ge 0 $$

为求最大值，对非负数平方：

$$ [f(x)]^2 = 4(1 - t^2)(1 + t)^2 = 4(1 - t)(1 + t)^3 $$

令 $a = 1 - t \ge 0$，$b = 1 + t \ge 0$，则 $a + b = 2$ 为定值。目标式化为

$$ [f(x)]^2 = 4 a b^3 $$

对正数 $a, b$ 应用加权算术-几何平均不等式：

$$ \frac{a + \frac{b}{3} + \frac{b}{3} + \frac{b}{3}}{4} \ge \sqrt[4]{a \cdot \left(\frac{b}{3}\right)^3} $$

即

$$ \frac{a + b}{4} = \frac{2}{4} = \frac{1}{2} \ge \sqrt[4]{\frac{a b^3}{27}} $$

两边四次方得 $a b^3 \le 27 \cdot \left(\frac{1}{2}\right)^4 = \frac{27}{16}$，等号成立当且仅当 $a = \frac{b}{3}$。

代回 $a = 1 - t, b = 1 + t$，解得 $1 - t = \frac{1 + t}{3} \Rightarrow 3 - 3t = 1 + t \Rightarrow t = \frac{1}{2}$，即 $\cos x = \frac{1}{2}$。此时

$$ [f(x)]^2 \le 4 \cdot \frac{27}{16} = \frac{27}{4} \Rightarrow f(x) \le \frac{3\sqrt{3}}{2} $$

完美吻合基准路径结果，且全程未涉求导。

**路径 B：半角参数化（几何直观）**

利用 $1 + \cos x = 2\cos^2\frac{x}{2}$，$\sin x = 2\sin\frac{x}{2}\cos\frac{x}{2}$，得

$$ f(x) = 8 \sin\frac{x}{2} \cos^3\frac{x}{2} $$

在 $[0, \pi]$ 上令 $u = \cos\frac{x}{2} \ge 0, v = \sin\frac{x}{2} \ge 0$，满足 $u^2 + v^2 = 1$。则 $f = 8 v u^3$。考察 $(f/8)^2 = v^2 u^6$，设 $A = v^2, B = u^2$，$A + B = 1$，求 $A B^3$ 最大，同路径 A 的 AM-GM，得 $B = \frac{3}{4}, A = \frac{1}{4}$ 即 $\cos^2\frac{x}{2} = \frac{3}{4} \Rightarrow \cos x = 2B - 1 = \frac{1}{2}$。此视角将三角极值转化为单位圆上的代数幂积，便于与解析几何关联。

**优劣对比**

- **基准导数法**：普适性强，逻辑直接，考场容错高。
- **不等式法**：计算量小、揭示结构，但需敏锐察觉 $a+b$ 为常数及加权分配，对代数嗅觉要求高。
- **半角法**：桥梁作用明显，在涉及高次齐次式时易迁移至拉格朗日乘子法。

【总结与反思】 🔍

1. **题型母题模型**
   形如 $f(x) = a\sin x + b\sin 2x$ 的问题，核心指纹是 **“正弦二倍角可拆解”**。统一手法：

   $$ a\sin x + b\sin 2x = \sin x \, (a + 2b\cos x) $$

   进而利用 $t = \cos x$ 化为关于 $t$ 的代数函数（注意 $\sin x$ 符号分段），或整体利用奇偶性缩小区间。

2. **解题逻辑模板**
   - **步骤一**：判别奇偶、周期，锁定单调区间或非负区间。
   - **步骤二**：优先因式分解，暴露乘积结构。
   - **步骤三**：选择路径——若表达式含 $(1\pm\cos x)$ 与 $\sin x$，立即联想半角或 $t=\cos x$ 换元；若求极值，导数总是保底。
   - **步骤四**：若采用平方或绝对值，必须确认符号避免增根。

3. **陷阱与易错点**
   - 直接对 $f(x)$ 平方而不分区间，会混淆正负导致值域对称误判（虽本题奇函数对称，但一般函数会出错）。
   - 导数展开时 $\cos 2x$ 公式选用错误，如误为 $1 - 2\sin^2 x$ 可能增加复杂度，但结果应一致。
   - AM-GM 应用时忽略等号条件，需验证 $a,b$ 能否取到。

4. **知识迁移联想**
   该极值结构 $a b^3$ 在 $a+b=\text{const}$ 下的最大值，恰是概率论中 Beta 分布模（mode）的离散映射；在解析几何中，类似 $x^3 y$ 在 $x^2+y^2=1$ 下的极值对应椭圆的切线斜率优化。建立此种 **“三角—代数—几何”** 的认知 Schema，能让你在压轴题中以高维视角降维打击。

最终答案：**值域为 $\left[ -\frac{3\sqrt{3}}{2}, \frac{3\sqrt{3}}{2} \right]$**。
