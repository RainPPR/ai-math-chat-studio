```text
model/2026-04-19T12:35:20.065Z

这是一道典型的**解析几何与函数单调性**结合的综合题。题目要求寻找一个参数 $a$ 的取值范围，使得两条不同的曲线存在一条共同的切线。

这类问题的核心在于将“几何上的共切线”转化为“代数上的方程组”，并通过消元将问题转化为对一个单变量函数的极值分析。

---

### 🛠️ 元解析与特征挖掘 (Meta-Analysis)

1.  **结构分量识别**：
    *   曲线 $C_1: f(x) = x^3 - x$ 是一个三次函数（奇函数，关于原点对称）。
    *   曲线 $C_2: g(x) = x^2 + a$ 是一个二次函数（偶函数，顶点在 $(0, a)$）。
2.  **共切线特征**：
    一条直线 $L: y = kx + b$ 若是 $C_1$ 在 $x_1$ 处的切线且是 $C_2$ 在 $x_2$ 处的切线，必须满足：
    *   **斜率一致**：$f'(x_1) = g'(x_2) = k$
    *   **切点在直线上**：直线 $L$ 的截距 $b$ 在两处必须相等。
3.  **逻辑路径**：
    $\text{切线方程} \implies \text{建立 } \{x_1, x_2, a\} \text{ 的关系式} \implies \text{消元得到 } a = h(x_1) \implies \text{研究 } h(x_1) \text{ 的值域}$。

---

### 📝 基准推导 (The Ground Solution)

#### 第一步：建立切线方程
对于 $f(x) = x^3 - x$，其导数为 $f'(x) = 3x^2 - 1$。
在 $x_1$ 处的切线方程为：
$$y - (x_1^3 - x_1) = (3x_1^2 - 1)(x - x_1)$$
整理得：
$$y = (3x_1^2 - 1)x - 2x_1^3 \quad \text{—— (1)}$$

对于 $g(x) = x^2 + a$，其导数为 $g'(x) = 2x$。
在 $x_2$ 处的切线方程为：
$$y - (x_2^2 + a) = 2x_2(x - x_2)$$
整理得：
$$y = 2x_2 x + a - x_2^2 \quad \text{—— (2)}$$

#### 第二步：利用共切线条件消元
由于 (1) 和 (2) 表示同一条直线，其斜率和截距必须分别相等：
1.  **斜率相等**：$3x_1^2 - 1 = 2x_2 \implies x_2 = \frac{3x_1^2 - 1}{2}$
2.  **截距相等**：$-2x_1^3 = a - x_2^2$

将 $x_2$ 的表达式代入截距等式中，解出 $a$：
$$a = x_2^2 - 2x_1^3 = \left( \frac{3x_1^2 - 1}{2} \right)^2 - 2x_1^3$$
展开并简化：
$$a = \frac{9x_1^4 - 6x_1^2 + 1}{4} - 2x_1^3 = \frac{9}{4}x_1^4 - 2x_1^3 - \frac{3}{2}x_1^2 + \frac{1}{4}$$

#### 第三步：分析 $a$ 的取值范围
令 $h(t) = \frac{9}{4}t^4 - 2t^3 - \frac{3}{2}t^2 + \frac{1}{4}$，其中 $t = x_1 \in \mathbb{R}$。我们需要求 $h(t)$ 的值域。
对 $h(t)$ 求导：
$$h'(t) = 9t^3 - 6t^2 - 3t = 3t(3t^2 - 2t - 1) = 3t(3t + 1)(t - 1)$$

令 $h'(t) = 0$，得到驻点：
$$t_1 = 0, \quad t_2 = 1, \quad t_3 = -\frac{1}{3}$$

计算这些驻点对应的函数值：
*   当 $t = 0$ 时，$h(0) = \frac{1}{4}$
*   当 $t = 1$ 时，$h(1) = \frac{9}{4} - 2 - \frac{3}{2} + \frac{1}{4} = \frac{10}{4} - \frac{7}{2} = 2.5 - 3.5 = -1$
*   当 $t = -\frac{1}{3}$ 时：
    $$h\left(-\frac{1}{3}\right) = \frac{9}{4}\left(\frac{1}{81}\right) - 2\left(-\frac{1}{27}\right) - \frac{3}{2}\left(\frac{1}{9}\right) + \frac{1}{4} = \frac{1}{36} + \frac{2}{27} - \frac{1}{6} + \frac{1}{4}$$
    通分得 $\frac{3 + 8 - 18 + 27}{108} = \frac{20}{108} = \frac{5}{27}$

由于 $h(t)$ 是一个首项系数为正的四次多项式，当 $t \to \pm\infty$ 时，$h(t) \to +\infty$。
因此，该函数的最小值为所有驻点值中的最小值：
$$\min \{ \frac{1}{4}, -1, \frac{5}{27} \} = -1$$

**结论**：$a$ 的取值范围是 $[-1, +\infty)$。

### 🚀 进阶解法/技巧 (High-Level View)

在竞赛或高阶考试中，我们可以通过**参数化映射**快速审视本题：

1.  **切线簇视角**：
    $f(x) = x^3 - x$ 的切线族由 $x_1$ 参数化，其截距函数 $b(x_1) = -2x_1^3$ 覆盖全实数 $\mathbb{R}$。
    $g(x) = x^2 + a$ 的切线族由 $x_2$ 参数化，其截距函数 $b(x_2) = a - x_2^2$ 的最大值为 $a$。

2.  **动态平衡分析**：
    要使共切线存在，必须满足 $b(x_1) = b(x_2)$ 且 $k(x_1) = k(x_2)$。
    这意味着 $a$ 必须足够大，使得 $g(x)$ 的切线簇能够“触碰到” $f(x)$ 的切线簇。
    从 $a = x_2^2 - 2x_1^3$ 可以看出，当 $x_1 \to \infty$ 时，$a \to -\infty$（但这取决于 $x_2$ 的增长速度）。
    事实上，由于 $x_2 \approx \frac{3}{2}x_1^2$，所以 $x_2^2 \approx \frac{9}{4}x_1^4$，四次项决定了 $a$ 最终趋向正无穷。

### 💡 总结与反思 (Cognitive Reflection)

#### 1. 核心思想总结
本题的逻辑链条是：
**几何共切 $\xrightarrow{导数}$ 线性方程组 $\xrightarrow{消元}$ 单变量极值 $\xrightarrow{求导}$ 范围**。

#### 2. 易错点提醒
*   **截距计算**：在求切线方程时，很多同学容易在整理 $y = kx + b$ 时出现符号错误。建议使用 $b = f(x_1) - f'(x_1)x_1$ 这一统一公式。
*   **驻点漏检**：四次函数的极值点可能多达三个，必须全部计算并对比，不能仅看端点。
*   **范围闭合性**：因为 $h(t)$ 在 $t=1$ 处取得最小值且连续，所以 $a$ 的范围包含 $-1$，即闭区间。

#### 3. 迁移场景
如果将 $g(x) = x^2 + a$ 替换为 $g(x) = e^x + a$，解题逻辑完全一致：
1.  $3x_1^2 - 1 = e^{x_2}$
2.  $-2x_1^3 = a - x_2 e^{x_2}$
3.  利用 $x_2 = \ln(3x_1^2 - 1)$ 消元，研究 $a$ 关于 $x_1$ 的函数。

**最终答案**：
$$a \in [-1, +\infty)$$
```
