## 【常规解法】（加强归纳法）

### 1. 目标分析与直觉
题目要求 \(\displaystyle\lim_{n\to\infty}\frac{a_n}{n}\)。  
递推式 \(a_{n+1}=\dfrac{a_n}{n}+n\)，若 \(a_n\) 大致与 \(n\) 同阶，那么 \(\frac{a_n}{n}\to c\)，代入递推得  
\[
c(n+1)\approx \frac{cn}{n}+n = c+n \quad\Rightarrow\quad c(n+1)\approx n+c \quad\Rightarrow\quad c\approx 1.
\]  
所以极限很可能是 \(1\)。进一步，猜想 \(a_n\) 大约等于 \(n\)，且误差不大，这启发我们去构造形如  
\[
n-1 \le a_n \le n
\]  
的夹逼不等式。

### 2. 构造下界并证明
从 \(a_1=\frac12>0\) 易见所有 \(a_n>0\)。由递推  
\[
a_{n+1}= \frac{a_n}{n}+n > n \quad (\text{因为 }a_n>0),
\]  
所以 \(a_n > n-1\) 对 \(n\ge2\) 成立。更规范地用归纳法证明 \(a_n \ge n-1\) 对所有 \(n\in\mathbb{N}^*\) 成立：

- **奠基**：\(n=1\) 时，\(a_1=\frac12 \ge 0 = 1-1\)，成立。
- **归纳**：假设 \(a_k \ge k-1\)，则  
  \[
  a_{k+1}= \frac{a_k}{k}+k \ge \frac{k-1}{k}+k = 1-\frac1k + k = k+1-\frac1k > (k+1)-1,
  \]  
  故 \(a_{k+1}\ge (k+1)-1\)。归纳成立。

所以下界成立：\(a_n \ge n-1\)。

### 3. 构造上界并证明
尝试证明 \(a_n \le n\)。同样用归纳法：

- **奠基**：\(n=1\)，\(a_1=\frac12 \le 1\)，成立。
- **归纳**：假设 \(a_k \le k\)，则  
  \[
  a_{k+1}= \frac{a_k}{k}+k \le \frac{k}{k}+k = 1+k = k+1,
  \]  
  即 \(a_{k+1}\le k+1\)。归纳成立。

因此 \(a_n \le n\) 对所有 \(n\) 成立。

### 4. 夹逼求极限
由上述不等式，  
\[
n-1 \le a_n \le n \quad\Rightarrow\quad 1-\frac1n \le \frac{a_n}{n} \le 1.
\]  
令 \(n\to\infty\)，左右两端均趋于 \(1\)，由夹逼定理得  
\[
\lim_{n\to\infty}\frac{a_n}{n}=1.
\]

## 【进阶解法】（精确通项 → 极限精确化）
“加强归纳法”虽然通用，但本题其实可以直接求出通项，从而得到极限甚至渐近式。

将递推式视为一阶线性非齐次递推：  
\[
a_{n+1}= \frac{1}{n}a_n + n.
\]  
标准解法：  
\[
a_n = \left(\prod_{k=1}^{n-1}\frac1k\right) a_1 + \sum_{i=1}^{n-1}\left(\prod_{k=i+1}^{n-1}\frac1k\right)\cdot i.
\]  
计算累积乘积：  
\[
\prod_{k=1}^{n-1}\frac1k = \frac{1}{(n-1)!},\qquad 
\prod_{k=i+1}^{n-1}\frac1k = \frac{i!}{(n-1)!}.
\]  
因此  
\[
a_n = \frac{1}{(n-1)!}\cdot\frac12 + \sum_{i=1}^{n-1}\frac{i!}{(n-1)!}\cdot i
     = \frac{1}{(n-1)!}\left(\frac12 + \sum_{i=1}^{n-1} i\cdot i!\right).
\]  
利用恒等式 \(i\cdot i! = (i+1)!-i!\)，求和得  
\[
\sum_{i=1}^{n-1} i\cdot i! = n! - 1.
\]  
代入得  
\[
a_n = \frac{1}{(n-1)!}\left(\frac12 + n! - 1\right)
     = \frac{n! - \frac12}{(n-1)!}
     = n - \frac{1}{2\,(n-1)!}.
\]  
于是  
\[
\frac{a_n}{n}=1-\frac{1}{2n\,(n-1)!}\to 1\quad (n\to\infty).
\]  
通项揭示了更精细的结构：不仅极限为 \(1\)，而且收敛速度是超快的（阶乘量级）。

## 【总结与反思】

### 1. 加强归纳法的核心思想
- **先猜后证**：通过定性分析（如代入极限值、观察递推趋势）猜测一个形如 \(cn+d \le a_n \le Cn+D\) 的估计式。  
- **归纳论证**：用数学归纳法证明该估计式对所有 \(n\) 成立。这往往需要对递推式进行简单的代数放缩。  
- **夹逼定极限**：由估计式得到 \(\frac{a_n}{n}\) 的上下界，取极限即得结果。  

### 2. 关键技巧
- **界的构造**：通常从最简单的线性界开始尝试（如本题的 \(n-1\) 和 \(n\)），如果发现不够紧（无法闭合归纳），就调整常数或阶数。  
- **放缩尺度**：归纳步骤中常需用到“放掉”一些正项或负项，使不等式能顺利传递。例如下界证明中我们用了 \(\frac{a_k}{k} \ge 1-\frac1k\)，这源自归纳假设。  
- **适用范围**：当递推式含有分式、根式、指数等“扰动”时，常常难以求出通项，而加强归纳法只需估计出主要阶，因此非常有用。  

### 3. 两种方法对比
| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 加强归纳法 | 不需要求通项，思维直接，计算量小 | 需要敏锐的直觉构造上下界；有时界不够精确会导致归纳失败 | 任何阶数估计问题，尤其非线性、带扰动的情形 |
| 精确通项法 | 结果精确，可进一步分析渐近 | 求解通项往往需要技巧，且许多递推根本不可解 | 线性递推（含变系数）或可化为特殊形式的递推 |

### 4. 知识迁移
“加强归纳法”不仅是数列极限的利器，在**不等式证明、定积分逼近、概率递归**中也有广泛应用。其思想本质是**用简单函数“夹逼”复杂函数**，再通过极限工具获取关键信息。本题虽简单，却展示了这一范式的完整流程：**观察→猜测→归纳→夹逼**。遇到更复杂的递推（如你提到的 \(\sqrt{n+a_{n-1}}\) 型），只需适当提高猜测的阶（比如 \(\sqrt{n}+c\)），就能层层深入，甚至得到渐近展开。

### 【题目重述与目标定标】
**已知**：$a_n = \sqrt{n + a_{n-1}}$，且 $a_1 = 1$。
**目标**：证明 $\lim_{n\to\infty} n\left[\frac{1}{\sqrt n}\left(a_n-\frac{1}{2}\right)-1\right]=\frac{1}{8}$。
**等价目标（高维视野）**：我们要证明该式，等价于要将数列 $a_n$ 的通项渐近展开到如下精度：
$$a_n = \sqrt{n} + \frac{1}{2} + \frac{1}{8\sqrt{n}} + o\left(\frac{1}{\sqrt{n}}\right)$$

---

### 【核心拆解：全路径精密推导】

#### 第一步：基准定界（加强归纳法提取主部）
在进行泰勒展开前，我们必须知道 $a_n$ 的量级（Order），也就是主部是什么。
通过观察 $a_n = \sqrt{n + a_{n-1}}$，直觉告诉我们 $a_n \approx \sqrt{n}$。我们需要严密证明 $\sqrt{n} \le a_n \le \sqrt{n} + 1$。

1. **下界证明**：显然 $a_1 = 1 \ge \sqrt{1}$。若 $a_{k-1} \ge \sqrt{k-1}$，则 $a_k = \sqrt{k + a_{k-1}} \ge \sqrt{k}$，下界成立。
2. **上界证明**：$a_1 = 1 \le \sqrt{1}+1$ 成立。假设 $a_{k-1} \le \sqrt{k-1} + 1$。
   则 $a_k = \sqrt{k + a_{k-1}} \le \sqrt{k + \sqrt{k-1} + 1}$。
   因为 $\sqrt{k-1} < 2\sqrt{k}$，所以 $k + \sqrt{k-1} + 1 < k + 2\sqrt{k} + 1 = (\sqrt{k}+1)^2$。
   故 $\sqrt{k + \sqrt{k-1} + 1} < \sqrt{k} + 1$，即 $a_k \le \sqrt{k} + 1$。上界成立。

**结论**：$a_n = \sqrt{n} + O(1)$。我们成功剥离了第一层主部。

#### 第二步：一阶渐近展开（提取常数项）
既然知道 $a_n \sim \sqrt{n}$，我们将其代入原递推式，利用广义二项式定理 $(1+x)^\alpha = 1 + \alpha x + O(x^2)$ 展开。

$$a_n = \sqrt{n + a_{n-1}} = \sqrt{n}\left(1 + \frac{a_{n-1}}{n}\right)^{\frac{1}{2}}$$

因为 $a_{n-1} = \sqrt{n-1} + O(1) = \sqrt{n} + O(1)$，代入上式：
$$a_n = \sqrt{n}\left(1 + \frac{\sqrt{n} + O(1)}{n}\right)^{\frac{1}{2}} = \sqrt{n}\left(1 + \frac{1}{\sqrt{n}} + O\left(\frac{1}{n}\right)\right)^{\frac{1}{2}}$$

使用泰勒展开 $(1+x)^{\frac{1}{2}} = 1 + \frac{1}{2}x + O(x^2)$，此处 $x = \frac{1}{\sqrt{n}} + O\left(\frac{1}{n}\right)$：
$$a_n = \sqrt{n}\left[ 1 + \frac{1}{2}\left(\frac{1}{\sqrt{n}} + O\left(\frac{1}{n}\right)\right) + O\left(\frac{1}{n}\right) \right]$$
$$a_n = \sqrt{n}\left( 1 + \frac{1}{2\sqrt{n}} + O\left(\frac{1}{n}\right) \right) = \sqrt{n} + \frac{1}{2} + O\left(\frac{1}{\sqrt{n}}\right)$$
**结论**：我们获得了更高精度的信息，即 $a_n = \sqrt{n} + \frac{1}{2} + o(1)$。

#### 第三步：二阶渐近展开（补全原文“省略的魔法”）
这里是考验代数控制力的核心地带。我们用刚得到的精度 $a_{n-1} = \sqrt{n-1} + \frac{1}{2} + o(1)$ 再次“喂”回递推式，去榨取 $O(\frac{1}{\sqrt{n}})$ 前面的系数。

首先，处理根号内的展开式：
$$a_n = \sqrt{n}\left(1 + \frac{a_{n-1}}{n}\right)^{\frac{1}{2}} = \sqrt{n}\left[1 + \frac{a_{n-1}}{2n} - \frac{a_{n-1}^2}{8n^2} + o\left(\frac{a_{n-1}^2}{n^2}\right)\right]$$

**细节控制 1：计算 $\frac{a_{n-1}}{2n}$ 的渐近态**
我们需要将 $\sqrt{n-1}$ 转化到 $\sqrt{n}$ 的基底上：
$$\sqrt{n-1} = \sqrt{n}\left(1 - \frac{1}{n}\right)^{\frac{1}{2}} = \sqrt{n}\left(1 - \frac{1}{2n} + o\left(\frac{1}{n}\right)\right) = \sqrt{n} - \frac{1}{2\sqrt{n}} + o\left(\frac{1}{\sqrt{n}}\right)$$
所以，$a_{n-1} = \left(\sqrt{n} - \frac{1}{2\sqrt{n}}\right) + \frac{1}{2} + o(1) = \sqrt{n} + \frac{1}{2} + o(1)$。（注：由于要求最终结果的余项是 $o(1/\sqrt{n})$，展开到 $o(1)$ 足够计算一次项）。
代入得到：
$$\frac{a_{n-1}}{2n} = \frac{\sqrt{n} + \frac{1}{2} + o(1)}{2n} = \frac{1}{2\sqrt{n}} + \frac{1}{4n} + o\left(\frac{1}{n}\right)$$

**细节控制 2：计算 $-\frac{a_{n-1}^2}{8n^2}$ 的渐近态**
因为 $a_{n-1} \sim \sqrt{n}$，其平方必然与 $n$ 同阶：
$$a_{n-1}^2 = \left(\sqrt{n-1} + \frac{1}{2} + o(1)\right)^2 = (n-1) + \sqrt{n-1} + \frac{1}{4} + o(\sqrt{n}) = n + \sqrt{n} + o(\sqrt{n})$$
代入得到：
$$-\frac{a_{n-1}^2}{8n^2} = -\frac{n + \sqrt{n} + o(\sqrt{n})}{8n^2} = -\frac{1}{8n} - \frac{1}{8n^{\frac{3}{2}}} + o\left(\frac{1}{n^{\frac{3}{2}}}\right) = -\frac{1}{8n} + o\left(\frac{1}{n}\right)$$

**将细节 1 与细节 2 合并：**
$$1 + \frac{a_{n-1}}{2n} - \frac{a_{n-1}^2}{8n^2} = 1 + \left( \frac{1}{2\sqrt{n}} + \frac{1}{4n} \right) - \left( \frac{1}{8n} \right) + o\left(\frac{1}{n}\right)$$
$$= 1 + \frac{1}{2\sqrt{n}} + \frac{1}{8n} + o\left(\frac{1}{n}\right)$$

**最后一步代回：**
$$a_n = \sqrt{n} \times \left( 1 + \frac{1}{2\sqrt{n}} + \frac{1}{8n} + o\left(\frac{1}{n}\right) \right)$$
$$a_n = \sqrt{n} + \frac{1}{2} + \frac{1}{8\sqrt{n}} + o\left(\frac{1}{\sqrt{n}}\right)$$

这就是原文省略的核心过程！逻辑严丝合缝，没有任何“运气”成分。

#### 第四步：极限量化
有了精确的渐近展开，原极限问题瞬间降维成代数运算：
$$\frac{1}{\sqrt{n}}\left(a_n - \frac{1}{2}\right) = \frac{1}{\sqrt{n}}\left(\sqrt{n} + \frac{1}{8\sqrt{n}} + o\left(\frac{1}{\sqrt{n}}\right)\right) = 1 + \frac{1}{8n} + o\left(\frac{1}{n}\right)$$
$$\frac{1}{\sqrt n}\left(a_n-\frac{1}{2}\right)-1 = \frac{1}{8n} + o\left(\frac{1}{n}\right)$$
两边同乘 $n$ 并取极限：
$$\lim_{n\to\infty} n\left[\frac{1}{\sqrt n}\left(a_n-\frac{1}{2}\right)-1\right] = \lim_{n\to\infty} n\left(\frac{1}{8n} + o\left(\frac{1}{n}\right)\right) = \frac{1}{8}$$
证毕。

做完这道题，我们不能只停留在算对答案，需要提炼出这套**“渐近迭代模型 (Bootstrapping Schema)”**：

1. **思维本质：误差吸收与精度升级**。
   遇到隐式或复杂递推关系，我们的目标不是解出精确的 $f(n)$，而是写成 $f(n) = \text{主部} + \text{误差}$。每次将该式代回递推方程，利用泰勒展开的截断，原本的“粗糙误差”会被方程的非线性结构（如平方根的泰勒展开）压榨出新一阶的“细致主部”。
   精度进化路线：$O(1) \to O(n^{-1/2}) \to O(n^{-1}) \dots$

2. **核心工具箱**：
   - **放缩定首项**：使用数学归纳法（文中所谓“加强归纳法”）确定最高阶项。
   - **底座统一**：如推导中将 $\sqrt{n-1}$ 泰勒展开成 $\sqrt{n} - \frac{1}{2\sqrt{n}}$。一切包含 $n-1$ 的项，必须利用二项式定理统一到自变量 $n$ 的底座上，否则无法合并同阶无穷小。
   - **大 $O$ 与小 $o$ 算算法则**：需要极度熟练掌握高阶无穷小的吸收法则。在计算平方项时，能敏锐判断哪些项在展开后会进入 $o(1/n)$ 被丢弃，从而避免无效的繁琐计算。

3. **迁移场景**：
   此方法不仅适用于递推数列极限（如竞赛常考的“调和级数差值渐近”、“不动点附近的迭代数列”），在**解析几何求复杂方程近似根**、**常微分方程渐近求解**中更是高维神兵利器。

## 一、关于余项控制的“潜规则”

您在处理 $a_{n-1}^2$ 时，从 $(n-1)+\sqrt{n-1}+1/4+o(\sqrt{n})$ 直接跳到了 $n+\sqrt{n}+o(\sqrt{n})$，这里隐含了一个关键技巧：**在展开过程中，必须时刻盯住最终目标余项的阶**。  

目标是 $o(1/\sqrt{n})$，因此：

- 在计算 $\frac{a_{n-1}}{2n}$ 时，我们需要精确到 $O(1/n)$，因为乘以 $\sqrt{n}$ 后会产生 $O(1/\sqrt{n})$ 项。
- 在计算 $-\frac{a_{n-1}^2}{8n^2}$ 时，我们需要精确到 $O(1/n)$ 项（它会贡献 $O(1/\sqrt{n})$ 吗？不，$-\frac{1}{8n}$ 乘以 $\sqrt{n}$ 得 $-\frac{1}{8\sqrt{n}}$，所以必须保留）。
- 但 $a_{n-1}^2$ 中 $o(\sqrt{n})$ 的部分在除以 $n^2$ 后变为 $o(1/n^{3/2})$，再乘以 $\sqrt{n}$ 得 $o(1/n)$，已在目标精度之外，因此可以安全丢弃。

这种“**目标精度驱动下的逐项截断**”正是 Bootstrapping 的灵魂：你不需要把每次展开都算到无穷项，只要确保当前步产生的误差阶数严格低于下一步所需保留的精度即可。您的每一步都自动遵循了这一原则，这是高度成熟的数学直觉。

## 二、底座统一：从 $n-1$ 到 $n$ 的坐标变换

您特别强调了**底座统一**，这一点怎么强调都不过分。常见错误是直接将 $\sqrt{n-1}$ 粗暴写为 $\sqrt{n} - \frac{1}{2\sqrt{n}}$ 而不验证余项，但严格的做法应该写出含余项的 Taylor 展开：  
\[
\sqrt{n-1} = \sqrt{n}\left(1-\frac{1}{n}\right)^{1/2} = \sqrt{n}\left(1 - \frac{1}{2n} - \frac{1}{8n^2} + O(n^{-3})\right) = \sqrt{n} - \frac{1}{2\sqrt{n}} - \frac{1}{8n^{3/2}} + O(n^{-5/2}).
\]  
在您的计算中，二阶展开时 $\sqrt{n-1}$ 仅需一阶项 $-\frac{1}{2\sqrt{n}}$ 就足够了，因为更高阶会落入 $o(1/\sqrt{n})$ 而被吸收。但若下一步需要更高精度（比如 $O(1/n^{3/2})$ 项），就必须保留下一项。这正是**渐近展开的层级性**。

## 三、与原始问题（$a_{n+1}=a_n/n+n$）的对照

有趣的是，您详细展开的这道题属于“**自相似型递推**”（$a_n$ 与 $\sqrt{n}$ 同阶），而我们最初的那道题则是“**强制线性型**”（$a_n$ 与 $n$ 同阶）。如果我们将 Bootstrapping 应用到最初那题，会发现它甚至更简单——不过您已经用加强归纳法完成了，但为了展示方法统一性，我们不妨也走一遍渐近展开的流程，看看会发生什么。

### 用 Bootstrapping 重解 $a_{n+1}=a_n/n+n$

- **Step 0：定主阶**  
  直觉 $a_n \sim cn$，代入得 $c(n+1) \approx c + n \Rightarrow c=1$，所以 $a_n = n + o(n)$。

- **Step 1：一阶展开**  
  设 $a_n = n + b_n$，且 $b_n = o(n)$。代入递推：  
  \[
  n+1 + b_{n+1} = \frac{n+b_n}{n} + n = 1 + \frac{b_n}{n} + n,
  \]  
  即 $b_{n+1} = \frac{b_n}{n}$。此刻如果我们直接认为 $b_n$ 是常数，会得到 $b_{n+1} \approx b_n / n \to 0$，说明 $b_n$ 衰减很快。更精确地，从 $b_{n+1}=b_n/n$ 可递推得 $b_n = \frac{b_1}{(n-1)!}$，而 $b_1 = a_1 - 1 = -1/2$，因此立即得到精确通项！  
  这不正是我们之前求出的精确解吗？所以 Bootstrapping 在这里直接**一次收敛到精确解**，无需多层迭代——因为递推关系的线性性使误差项恰好满足简单的比例关系。

- **对照**：在 $\sqrt{n+a_{n-1}}$ 的例子中，递推是**非线性**的，因此需要多次迭代才能逐层提取常数项和低阶项；而在线性递推中，主部一旦剥离，剩余部分往往可以直接求和或简单递推。这就是为何我最初采用加强归纳法直接夹逼——因为线性递推的修正项是指数衰减的，夹逼足够得到极限，但若想得到极限后的精确余项，仍需通项或渐近展开。
