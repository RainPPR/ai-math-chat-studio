### 元解析与特征挖掘

题干提供了三个核心“指纹”特征：
1. **偶函数**：$f(-x) = f(x)$，这意味函数图象关于 $y$ 轴对称。
2. **递推关系**：$f(x) + f(x-2) = 0 \Rightarrow f(x) = -f(x-2)$。将其平移可得 $f(x+2) = -f(x)$。这说明相邻长度为 2 的区间上，函数值变号（中心对称特征）。
3. **局部解析式**：在 $x \in \left[\dfrac{3}{2}, 3\right]$ 上，$f(x) = x^2 + ax + b$。这是一个二次多项式。

**特征碰撞与升维洞察**：
由 $f(x+2) = -f(x)$ 连续推导两次，可得 $f(x+4) = f(x)$，即函数具备 **周期 $T=4$**。
结合全局周期 $T=4$ 和全局偶函数对称性 $f(-x)=f(x)$，将这两个几何操作复合：向左平移 4 再关于 $y$ 轴对称，等价于 $f(4-x) = f(x)$。这在全域上等价于**函数图象关于直线 $x=2$ 轴对称**。
同理，平移反号特征结合偶函数特征，复合出 $f(2-x) = -f(x)$，说明**函数图象关于点 $(1,0)$ 中心对称**。

这些密集的全局对称性，在已知的局部区间 $\left[\dfrac{3}{2}, 3\right]$ 上必然投影出极强的**内部自洽约束**。这就是解题的破局点。

### 【常规解法】代数映射与重叠区间比对

这是考场上最稳妥、逻辑最严密的算力解法。

**第一步：提取全局关系式**
由 $f(x) = -f(x-2)$，将 $x$ 替换为 $2-x$，得：
$$f(2-x) = -f(-x)$$
因为 $f(x)$ 是偶函数，即 $f(-x) = f(x)$，代入上式得：
$$f(2-x) = -f(x) \quad \cdots \cdots \text{①}$$
同时，由 $f(x+2) = -f(x)$ 平移得 $f(x+4) = f(x)$，所以：
$$f(4-x) = f(-x) = f(x) \quad \cdots \cdots \text{②}$$

**第二步：利用重叠区间投影求参数 $a$**
观察关系式 ②：$f(4-x) = f(x)$。
当 $x \in \left[\dfrac{3}{2}, \dfrac{5}{2}\right]$ 时，$4-x \in \left[\dfrac{3}{2}, \dfrac{5}{2}\right]$。这两个集合有公共子区间。
既然原区间同为已知解析式的定义域 $\left[\dfrac{3}{2}, 3\right]$ 的子集，必满足多项式相等：
$$(4-x)^2 + a(4-x) + b = x^2 + ax + b$$
展开并化简，得：
$$16 - 8x + x^2 + 4a - ax = x^2 + ax$$
$$(-8 - 2a)x + 16 + 4a = 0$$
由于该等式对区间 $\left[\dfrac{3}{2}, \dfrac{5}{2}\right]$ 内的**任意** $x$ 恒成立，一次项系数与常数项必同时为零：
$$\begin{cases} -8 - 2a = 0 \\ 16 + 4a = 0 \end{cases} \Rightarrow a = -4$$

**第三步：利用特征点求参数 $b$**
由关系式 ①：$f(2-x) = -f(x)$。
令 $x=1$，则 $f(1) = -f(1)$，即 $f(1) = 0$。
此时再令 $x=3$，由 ① 式得 $f(-1) = -f(3)$。
又因为 $f(x)$ 是偶函数，$f(-1) = f(1) = 0$，故可得极其关键的边界点约束：
$$f(3) = 0$$
已知 $x=3$ 落在已知解析式的定义域 $\left[\dfrac{3}{2}, 3\right]$ 内，代入 $f(3) = 3^2 + 3a + b = 0$。
$$9 + 3a + b = 0 \Rightarrow b = -9 - 3a$$
代入 $a = -4$，得：
$$b = -9 - 3(-4) = 3$$

### 【进阶解法 / 技巧】几何对称性投影的降维打击

如果掌握了更高维的数学直觉，我们完全可以规避多项式同项展开对比的繁琐，直接由“形”入“数”秒杀。

**1. 轴对称投影极速求 $a$：**
如前所析，全局复合性质直接给出 $f(4-x) = f(x)$。这说明函数有一根**对称轴 $x=2$**。
已知在 $x \in \left[\dfrac{3}{2}, 3\right]$ 内，函数是一段抛物线。因为有无数个点关于 $x=2$ 对称且函数值相等，那么这段二次曲线本身的对称轴必定与全局对称轴重合，即必为 $x=2$。
根据二次函数 $f(x) = x^2 + ax + b$ 的对称轴公式 $x = -\dfrac{a}{2}$：
$$-\frac{a}{2} = 2 \quad \Rightarrow \quad a = -4$$
直观且无损代数变形精度。

**2. 中心对称零点极速求 $b$：**
复合关系同样直接指出 $f(2-x) = -f(x)$。这说明函数有一个**对称中心 $(1,0)$**。
周期延拓 $T=4$ 的中心也产生连锁零点投影，由此可迅速推断图象必过 $(1,0)$ 及平移后的 $(3,0)$。
既然 $x=3$ 恰为给定区间的端点闭点，直接代入其穿轴特征即可：
$$f(3) = 0 \Rightarrow 9 - 12 + b = 0 \Rightarrow b = 3$$
整个过程无需展开一个多项式，直击几何骨架。

### 【总结与反思】解法模型与元认知提炼

在本题中，我们见证了一场从局部代数式反推全局结构的精彩博弈。这类题目的核心数学模型可以提炼为：

**“复合对称变换 $\to$ 全局几何群生成 $\to$ 局部区间投影 $\to$ 多项式不变性约束”**

1. **寻找分包轨道**：看到 $f(x+\Delta x) = \pm f(x)$ 形式，首要本能就是将其迭代，推导出周期性 $f(x+T) = f(x)$；若再交织奇偶性，必定打包产生新的对称轴或对称中心。识别到周期 arrayOf 轨道是简算先决条件。
2. **重叠区间的降比效应（核武器）**：一般题中给出的区间长度往往“刚好卡在”对称变换的重合阈值处。当把 $f(g(x))$ 与 $f(x)$ 两个关系作用于同一区间时：若 $x$ 与 $g(x)$ 不重合，只能写作分立函数；若 $x$ 与 $g(x)$ 存在重叠且在给定解析域内时，这就是“连续等同”——这强制约束了局部解析式本身必定内蕴全套对称性。抛物线的轴必须心悦诚服地与它对齐。
3. **零点引信（控制制标点）**：中心对称特征点（形如 $f(a)= -f(a) \Rightarrow f(a)=0$）是抽象命题的一把万能钥匙。局部多项式解参过满（待定个数不足）时可优先做端点与中心求值挖桩。

**隐患避坑提示**：
- 常规解法中，在展开 $(4-x)^2 + \dots = x^2 + \dots$ 时极易因符号出错导致系数全盘崩盘。在心算或手写右边时不妨用“重心比对法”：中间 $x$ 项系数对称严阵以 $z$ 归位补能，严保搬移多异号正尘。
- 需严验参数路段合法性（如重叠区间交集不为空，点必避免落到奇断。本例中 $x=3$ 在闭端确实合法，解法无懈可击）。
