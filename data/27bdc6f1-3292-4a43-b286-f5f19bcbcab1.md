### 🧠 深度解析与严密推导

#### 🔴 第2题 解析

**【问题分析】**
本题的核心在于从两个质点的**振动图像（$y-t$ 图像）**中提取周期 $T$ 和各自的初相位，并利用题干中“先后经过 $A$、$B$”这一关键信息（确定波的传播方向为 $A \rightarrow B$），构建空间距离 $L$ 与相位差的关系模型，进而求解波长和波速的多解问题。

**【符号定义与建模】**
设波的角频率为 $\omega$，周期为 $T$。设 $A$、$B$ 两质点的振动方程分别为 $y_A = A_0 \sin(\omega t + \phi_A)$ 和 $y_B = A_0 \sin(\omega t + \phi_B)$，其中振幅 $A_0 = 6\text{cm}$。

**【逐步推导】**
**第一步：分析图像，确定周期与振动方程**
观察图1（质点 $A$）：
- $t=0$ 时，质点位于波峰（$y = 6\text{cm}$）。
- 相邻两次经过平衡位置的时间间隔为 $1.8\text{s} - 0.6\text{s} = 1.2\text{s}$，这对应半个周期 $\frac{T}{2}$。
- 因此，周期 $T = 2.4\text{s}$，角频率 $\omega = \frac{2\pi}{T} = \frac{5\pi}{6}\text{ rad/s}$。
- 质点 $A$ 的振动方程为：$$y_A = 6\cos\left(\frac{5\pi}{6}t\right) = 6\sin\left(\frac{5\pi}{6}t + \frac{\pi}{2}\right)\text{ cm}$$

观察图2（质点 $B$）：
- $t=0$ 时，$y_B = -3\text{cm}$，且图像斜率为正（向 $y$ 轴正方向运动）。
- 代入一般方程 $y_B = 6\sin(\phi_B) = -3$，解得 $\sin(\phi_B) = -\frac{1}{2}$。结合速度方向向上（$\cos\phi_B > 0$），可知初相位 $\phi_B = -\frac{\pi}{6}$。
- 质点 $B$ 的振动方程为：$$y_B = 6\sin\left(\frac{5\pi}{6}t - \frac{\pi}{6}\right)\text{ cm}$$

**第二步：逐项验证选项**
**检验选项 A：** 
$C$ 点表示质点 $B$ 经过平衡位置且向 $y$ 轴负方向运动，此时对应的相位应为 $\pi$。
令 $\frac{5\pi}{6}t_C - \frac{\pi}{6} = \pi$，解得：
$$ \frac{5\pi}{6}t_C = \frac{7\pi}{6} \implies t_C = 1.4\text{s} $$
并非 $2.4\text{s}$，**故 A 错误**。

**检验选项 B：**
将 $t = 0.6\text{s}$ 代入 $B$ 的振动方程：
$$ y_B = 6\sin\left(\frac{5\pi}{6} \times 0.6 - \frac{\pi}{6}\right) = 6\sin\left(\frac{\pi}{2} - \frac{\pi}{6}\right) = 6\sin\left(\frac{\pi}{3}\right) = 6 \times \frac{\sqrt{3}}{2} = 3\sqrt{3}\text{ cm} $$
并非 $3\sqrt{2}\text{cm}$，**故 B 错误**。

**检验选项 C 与 D（重点：波的空间周期性）：**
题干指出波“先后经过” $A$、$B$，意味着波由 $A$ 传向 $B$，因此 $A$ 的相位始终超前于 $B$。
计算 $A$、$B$ 的相位差 $\Delta \phi$：
$$ \Delta \phi = \phi_A - \phi_B = \frac{\pi}{2} - \left(-\frac{\pi}{6}\right) = \frac{2\pi}{3} $$
根据波动理论，空间距离 $L$ 与相位差的关系为：
$$ \Delta \phi = \frac{2\pi}{\lambda}L = 2n\pi + \frac{2\pi}{3} \quad (n = 0, 1, 2, \dots) $$
将 $L = 4\text{m}$ 代入：
$$ \frac{2\pi}{\lambda} \times 4 = 2\pi\left(n + \frac{1}{3}\right) \implies \lambda = \frac{4}{n + \frac{1}{3}} = \frac{12}{3n + 1}\text{ m} $$
- **看选项 C**：若 $\lambda = 1.4\text{m} = \frac{7}{5}\text{m}$，则 $\frac{12}{3n+1} = \frac{7}{5} \implies 21n + 7 = 60 \implies n = \frac{53}{21}$（非整数），**故 C 错误**。
- **看选项 D**：波速 $v = \frac{\lambda}{T}$。
$$ v = \frac{\frac{12}{3n+1}}{2.4} = \frac{5}{3n+1}\text{ m/s} $$
若 $v = 1.25\text{m/s} = \frac{5}{4}\text{m/s}$，则：
$$ \frac{5}{3n+1} = \frac{5}{4} \implies 3n+1 = 4 \implies n = 1 $$
因为存在合法的整数解 $n=1$，所以该波速是可能的。**故 D 正确**。

**【第2题结论】 最终正确答案为 D。**

#### 🔵 第7题 解析

**【问题分析】**
这是一道经典的**波动图像（$y-x$ 图像）**与质点振动结合的问题。核心切入点是“质点位移方向与波传播方向的互推”（即同侧法或上下坡法），以及利用特殊质点 $Q$ 的状态变化推算波的周期 $T$。

**【符号定义与建模】**
从图中可直接读出：波长 $\lambda = 6\text{m} - 2\text{m} = 4\text{m}$，振幅 $A_0 = 0.2\text{m}$。

**【逐步推导】**
**第一步：判定波的传播方向（验证 A）**
在 $t=0.5\text{s}$ 时，质点 $Q$（$x=4\text{m}$）位于平衡位置，且**沿 $y$ 轴负方向运动**。
根据“上下坡法”（质点运动方向与波形斜率的关系：$v_y = -v_{\text{波}} \times \text{斜率}$）：
此时 $Q$ 点所处的波形斜率为负（从波峰下落至波谷的过程中），且 $v_y < 0$。
必然有 $v_{\text{波}} < 0$，即**波沿 $x$ 轴负方向传播**。
**故 A 正确**。

**第二步：计算周期与波速（验证 B）**
已知 $t=0.5\text{s}$ 时，$Q$ 在平衡位置向下运动。
它要“第一次到达波峰”，必须经历：向下到波谷 $\left(\frac{T}{4}\right)$ $\rightarrow$ 回到平衡位置 $\left(\frac{T}{4}\right)$ $\rightarrow$ 到达波峰 $\left(\frac{T}{4}\right)$。
这一过程总耗时为 $\Delta t = \frac{3}{4}T$。
由题意，该事件发生在 $t=1.25\text{s}$，因此经历的时间为：
$$ \Delta t = 1.25\text{s} - 0.5\text{s} = 0.75\text{s} $$
$$ \frac{3}{4}T = 0.75\text{s} \implies T = 1.0\text{s} $$
由此求得波速：
$$ v = \frac{\lambda}{T} = \frac{4\text{m}}{1.0\text{s}} = 4\text{m/s} $$
而选项 B 称波速为 $2\text{m/s}$，**故 B 错误**。

**第三步：推导质点 $P$ 的振动方程（验证 C）**
周期 $T=1.0\text{s}$，故角频率 $\omega = \frac{2\pi}{T} = 2\pi \text{ rad/s}$。
设质点 $P$ 的振动方程为 $y_P = 0.2\sin(2\pi t + \phi_0)$。
在 $t=0.5\text{s}$ 时，从图像可知质点 $P$ 位于波峰，即 $y_P = 0.2\text{m}$。代入方程：
$$ 0.2 = 0.2\sin(2\pi \times 0.5 + \phi_0) \implies \sin(\pi + \phi_0) = 1 $$
这就要求：
$$ \pi + \phi_0 = 2k\pi + \frac{\pi}{2} \implies \phi_0 = 2k\pi - \frac{\pi}{2} $$
取 $k=1$，可得初相位 $\phi_0 = \frac{3\pi}{2}$。
因此质点 $P$ 的振动方程为：
$$ y_P = 0.2\sin\left(2\pi t + \frac{3\pi}{2}\right)\text{ m} $$
这与选项 C 完全一致，**故 C 正确**。

**第四步：分析特定时刻的质点运动状态（验证 D）**
考查 $t=5.1\text{s}$ 时刻质点 $P$、$Q$ 的运动方向。
因为周期 $T=1.0\text{s}$，我们可以将时间 $t$ 减去整数个周期来寻找等效状态：
$$ \Delta t_{\text{相对}} = 5.1\text{s} - 0.5\text{s} = 4.6\text{s} = 4T + 0.6T $$
这意味着 $t=5.1\text{s}$ 时刻的状态，等效于 $t=0.5\text{s}$ 时刻的状态向后演化了 **$0.6$个周期**。
- **对于质点 $P$**：$t=0.5\text{s}$ 时位于波峰。经过 $0.5T$ 它到达波谷；再经过额外的 $0.1T$，它正在**从波谷向平衡位置移动**，即沿 $y$ 轴**正方向**运动。
- **对于质点 $Q$**：$t=0.5\text{s}$ 时位于平衡位置向下运动。经过 $0.5T$ 它回到平衡位置，且速度反向（向上）；再经过额外的 $0.1T$，它正在**向波峰移动**，即沿 $y$ 轴**正方向**运动。
综上，$t=5.1\text{s}$ 时刻，两个质点都在沿 $y$ 轴正方向运动。
选项 D 说均沿负方向运动，**故 D 错误**。

**【第7题结论】 最终正确答案为 A 和 C。** (注：若题目为单选，可能手写笔迹标注的 AC 意图指代多选题的答案，本解析证实 A 和 C 皆在物理定律下绝对成立)。

### 问题分析
从两质点的振动图像提取周期与初相位，根据波传播方向与相位差的关系（波多解问题）计算波长与波速的可能值。

- 振幅 \(A_0 = 6\,\text{cm}\)，周期 \(T\)，角频率 \(\omega=\dfrac{2\pi}{T}\)。
- 设质点 \(A,B\) 的振动方程分别为
  \[
  y_A = A_0\sin(\omega t + \phi_A),\quad y_B = A_0\sin(\omega t + \phi_B).
  \]

### 逐步推导

#### 1. 确定周期与振动方程
由题图1（\(A\) 点振动图像）：
- \(t=0\) 时 \(y_A = +6\,\text{cm}\)（波峰），故 \(\sin\phi_A = 1\)，可取 \(\phi_A = \dfrac{\pi}{2}\)。
- 相邻两次通过平衡位置的时间为 \(1.8\,\text{s} - 0.6\,\text{s} = 1.2\,\text{s}\)，对应 \(\dfrac{T}{2}\)，所以
  \[
  T = 2.4\,\text{s},\quad \omega = \frac{2\pi}{T} = \frac{5\pi}{6}\,\text{rad/s}.
  \]
- 因此
  \[
  y_A = 6\sin\!\left(\frac{5\pi}{6}t + \frac{\pi}{2}\right)\,\text{cm} = 6\cos\!\left(\frac{5\pi}{6}t\right)\,\text{cm}.
  \]

由题图2（\(B\) 点振动图像）：
- \(t=0\) 时 \(y_B = -3\,\text{cm}\)，且图像斜率为正（朝 \(y\) 正方向运动）。
  \[
  6\sin\phi_B = -3 \;\Rightarrow\; \sin\phi_B = -\frac12,\quad \cos\phi_B > 0 \;\Rightarrow\; \phi_B = -\frac{\pi}{6}.
  \]
- 故
  \[
  y_B = 6\sin\!\left(\frac{5\pi}{6}t - \frac{\pi}{6}\right)\,\text{cm}.
  \]

#### 2. 逐项验证选项

**A 选项**  
\(C\) 点对应 \(B\) 质点正通过平衡位置向 \(y\) 负方向运动，此时相位应为 \(\pi\)。
\[
\frac{5\pi}{6}t_C - \frac{\pi}{6} = \pi \;\Rightarrow\; t_C = \frac{7\pi/6}{5\pi/6} = \frac{7}{5}=1.4\,\text{s},
\]
并非 \(2.4\,\text{s}\)，A 错误。

**B 选项**  
代入 \(t=0.6\,\text{s}\)：
\[
y_B(0.6) = 6\sin\!\left(\frac{5\pi}{6}\times 0.6 - \frac{\pi}{6}\right) = 6\sin\!\left(\frac{\pi}{2} - \frac{\pi}{6}\right) = 6\sin\frac{\pi}{3}=3\sqrt{3}\,\text{cm},
\]
与 \(3\sqrt{2}\,\text{cm}\) 不符，B 错误。

**C、D 选项（波的多解性）**  
波先后经过 \(A\to B\)，故 \(A\) 相位超前 \(B\)。相位差
\[
\Delta\phi = \phi_A - \phi_B = \frac{\pi}{2} - \left(-\frac{\pi}{6}\right) = \frac{2\pi}{3}.
\]
考虑空间周期性（\(n=0,1,2,\dots\)）：
\[
\frac{2\pi}{\lambda}L = \Delta\phi + 2n\pi \;\Rightarrow\; \frac{2\pi}{\lambda}\cdot 4 = 2n\pi + \frac{2\pi}{3}
\;\Rightarrow\; \lambda = \frac{12}{3n+1}\,\text{m}.
\]
波速
\[
v = \frac{\lambda}{T} = \frac{12/(3n+1)}{2.4} = \frac{5}{3n+1}\,\text{m/s}.
\]

## 第7题 详细解析

### 问题分析
由波形图及质点运动方向判断波传播方向；利用质点 \(Q\) 的状态变化求周期；再根据振动规律写出质点方程并判断某时刻运动方向。

### 符号定义与建模
- 波长 \(\lambda = 4\,\text{m}\)，振幅 \(A = 0.2\,\text{m}\)。
- 周期 \(T\)，角频率 \(\omega = \dfrac{2\pi}{T}\)，波速 \(v = \dfrac{\lambda}{T}\)。

### 逐步推导

#### 1. 波传播方向（A 选项）
\(t=0.5\,\text{s}\) 时，质点 \(Q\) 位于平衡位置且沿 \(y\) 轴负方向运动。由“上下坡法”或“同侧法”：波向左传播时，平衡位置质点向下运动。因此波沿 \(x\) 轴 **负方向** 传播，A 正确。

#### 2. 周期与波速（B 选项）
质点 \(Q\) 从平衡位置向下运动到第一次到达波峰，需经历 \(\dfrac{3}{4}T\)。
\[
\Delta t = 1.25\,\text{s} - 0.5\,\text{s} = 0.75\,\text{s} = \frac{3}{4}T \;\Rightarrow\; T = 1.0\,\text{s}.
\]
波速
\[
v = \frac{\lambda}{T} = \frac{4}{1.0} = 4\,\text{m/s},
\]
非 \(2\,\text{m/s}\)，B 错误。

#### 3. 质点 \(P\) 的振动方程（C 选项）
周期 \(T = 1.0\,\text{s}\)，\(\omega = 2\pi\,\text{rad/s}\)。设
\[
y_P = 0.2\sin(2\pi t + \phi_0)\,\text{m}.
\]
\(t=0.5\,\text{s}\) 时 \(P\) 位于波峰（\(y=0.2\)）：
\[
0.2 = 0.2\sin(\pi + \phi_0) \;\Rightarrow\; \sin(\pi+\phi_0)=1 \;\Rightarrow\; \pi+\phi_0 = \frac{\pi}{2}+2k\pi.
\]
取 \(k=1\) 得 \(\phi_0 = \dfrac{3\pi}{2}\)（也可以取 \(k=0\) 得 \(-\dfrac{\pi}{2}\)，但两种形式等价，通常取主值范围）。
故
\[
y_P = 0.2\sin\!\left(2\pi t + \frac{3\pi}{2}\right)\,\text{m},
\]
与选项 C 一致，C 正确。

#### 4. \(t=5.1\,\text{s}\) 时质点运动方向（D 选项）
相对参考时刻 \(t_0=0.5\,\text{s}\)，时间差
\[
\Delta t' = 5.1 - 0.5 = 4.6\,\text{s} = 4T + 0.6T.
\]
等效经过 \(0.6T\)：
- **质点 \(P\)**：初始波峰，经 \(0.5T\) 到达波谷，再经 \(0.1T\) 从波谷向平衡位置运动，即 **向 \(y\) 正方向**。
- **质点 \(Q\)**：初始平衡位置向下，经 \(0.5T\) 回到平衡位置（速度向上），再经 \(0.1T\) 继续向上，即 **向 \(y\) 正方向**。
因此 \(P,Q\) 均沿 \(y\) 轴正方向运动，D 错误。

### 结论
**正确答案为 A、C**（若为多选题，选 A、C；若为单选题，则原题可能设有多选说明，此处按正确物理分析给出双选）。
