## 【Meta-分析：结构透视】

首先审视函数的代数指纹：
$$
f(x) = (x-2)e^x - a(x - \ln x), \quad x > 0
$$
其导数具有高度结构化的因式分解：
$$
f'(x) = (x-1)e^x - a + \frac{a}{x} = (x-1)\left(e^x - \frac{a}{x}\right) = \frac{(x-1)(xe^x - a)}{x}
$$
这揭示了**两类临界点的博弈**：
- **定点** $x=1$；
- **动点** $x_0$ 满足 $x_0 e^{x_0} = a$（由 $g(x)=xe^x$ 在 $x>0$ 严格递增，此根若存在则唯一）。

题设仅给定 $a < e$，需以 $a=0$ 与 $a=-e$ 为分水岭，对定义域 $(0,+\infty)$ 作**全区间单调性+极值符号**的精细扫描。

---

## 【常规解法：基准路径】

**Step 1：边界与导数形态的统一刻画**

$$
\lim_{x \to 0^+} f(x) = \begin{cases} +\infty, & a < 0 \\ -2, & a = 0 \\ -\infty, & a > 0 \end{cases}, \qquad \lim_{x \to +\infty} f(x) = +\infty
$$

$f'(x)$ 的符号完全由 $(x-1)$ 与 $\left(xe^x - a\right)$ 决定。

---

### 情形一：$a \leq 0$

此时 $e^x - \frac{a}{x} > 0$ 对所有 $x>0$ 恒成立，故
$$
f'(x) < 0 \ (0<x<1), \quad f'(x) > 0 \ (x>1)
$$
$x=1$ 为**唯一极小值点**，$f(1) = -e - a$。

- **若 $a < -e$**：$f(1) = -e - a > 0$，极小值恒正，结合两端趋向 $+\infty$，函数无零点。
- **若 $a = -e$**：$f(1) = 0$ 且为唯一极小值，故恰有 **1 个零点**（$x=1$ 为二重零点）。
- **若 $-e < a < 0$**：$f(1) < 0$，函数在 $(0,1)$ 上由 $+\infty$ 递减穿越 $x$ 轴，在 $(1,+\infty)$ 上由负递增再次穿越，恰有 **2 个零点**。
- **若 $a = 0$**：$f(x)=(x-2)e^x$，在 $(0,1)$ 上恒负（从 $-2$ 递减至 $-e$），在 $(1,+\infty)$ 上严格递增至 $+\infty$，恰有 **1 个零点** $x=2$。

---

### 情形二：$0 < a < e$

此时 $a>0$，方程 $xe^x = a$ 在 $(0,1)$ 内存在唯一根 $x_0$（因 $g(0^+)=0,\ g(1)=e>a$），且易知 $x_0 < 1$。

导数符号表如下：

| 区间 | $(0, x_0)$ | $(x_0, 1)$ | $(1, +\infty)$ |
| :---: | :---: | :---: | :---: |
| $x-1$ | $-$ | $-$ | $+$ |
| $xe^x-a$ | $-$ | $+$ | $+$ |
| $f'(x)$ | $+$ | $-$ | $+$ |
| $f(x)$ | $\nearrow$ | $\searrow$ | $\nearrow$ |

$x_0$ 为**极大值点**，$1$ 为**极小值点**。

**计算关键极值符号：**
利用 $a = x_0 e^{x_0}$，将极大值化为
$$
f(x_0) = (x_0-2)e^{x_0} - ax_0 + a\ln x_0 = a\underbrace{\left(1 - x_0 - \frac{2}{x_0} + \ln x_0\right)}_{\triangleq \varphi(x_0)}
$$
构造辅助函数 $\varphi(t) = 1 - t - \frac{2}{t} + \ln t\ (0<t<1)$，求导得：
$$
\varphi'(t) = -1 + \frac{2}{t^2} + \frac{1}{t} = \frac{(2-t)(1+t)}{t^2} > 0 \quad (0<t<1)
$$
故 $\varphi(t)$ 在 $(0,1)$ 上严格递增，且
$$
\lim_{t\to 1^-}\varphi(t) = 1-1-2+0 = -2 \implies \varphi(t) < -2 < 0
$$
因此 **$f(x_0) = a\varphi(x_0) < 0$ 恒成立**。

再算极小值 $f(1) = -e - a < 0$。

**零点判定：**
- 在 $(0,1)$ 上，$f(x)$ 自 $-\infty$ 递增至一个负的极大值，再递减至负的极小值，**无零点**。
- 在 $(1,+\infty)$ 上，$f(x)$ 自 $f(1)<0$ 严格递增趋向 $+\infty$，由零点存在定理恰有 **1 个零点**。

---

## 【进阶视角：解法对撞与统一】

### 1. 结构因式化的威力
导数的因式分解 $f'(x)=(x-1)\left(e^x-\frac{a}{x}\right)$ 将问题转化为对不等式 $xe^x \lesseqgtr a$ 的分析。这比一般移项构造更直接地暴露了**“定点 $x=1$”与“Lambert 型曲线 $xe^x=a$”的交叠**。

### 2. 参数 $a$ 的“相变”图景
可将零点问题视为水平线 $y=a$ 与曲线 $y= \frac{(x-2)e^x}{x-\ln x}$ 的交点问题（尽管分求导较繁，但定性有效）。真正决定零点个数突变的是**极值点是否为 0**，这恰好产生 $a=-e$ 与 $a=0$ 两个临界点。在此框架下，结论呈现出清晰的“相变”特征：
- $a<-e$：零交点（全正）
- $a=-e$：相切（1 交点）
- $-e<a<0$：双峰穿轴（2 交点）
- $0\leq a<e$：右支单穿（1 交点）

### 3. 符号判定的放缩技巧
判定极大值 $f(x_0)<0$ 时，不必硬解 $x_0$，而是利用 $a=x_0 e^{x_0}$ 进行**代换降维**，将问题转化为单变量函数 $\varphi(t)$ 的符号分析，体现了**参变分离后的函数化思想**。

## 【总结与反思】

### 核心结论
$$
\boxed{
N(a) = 
\begin{cases}
0, & a < -e \\[6pt]
1, & a = -e \ \text{或} \ 0 \leq a < e \\[6pt]
2, & -e < a < 0
\end{cases}
}
$$
其中 $N(a)$ 表示零点个数。

### 认知模型提炼
1. **导数因式优先**：遇到含参函数零点问题，首要任务是看导数是否具有 $(x-x_0)(\text{单调函数}(x,a))$ 的结构，此结构可直接锁定单调区间的分界。
2. **极值符号定乾坤**：零点个数本质上由**极值点函数值的符号**决定。本题中 $f(x_0)<0$ 是 $(0,1)$ 无零点的核心判据；$f(1)\lesseqgtr 0$ 是 $a \leq 0$ 情形的核心判据。
3. **参数边界的联想**：
   - $a=0$ 时函数退化为 $(x-2)e^x$，提供了一种**退化检验**。
   - $a=-e$ 时 $f(1)=0$ 且 $f'(1)=0$，恰好是**二重零点/切点**的典型场景。

### 陷阱与迁移
- **陷阱**：易忽略 $a=0$ 虽使 $f'(x)=(x-1)e^x$ 仅有一个显式零点，但本质上是“动点 $x_0$”趋于边界 $0$ 的极限情况，属于**边界退化**。
- **迁移**：此类“导数含参并可因式分解”的模型常出现在高考压轴与竞赛一试中，如 $f(x)=e^x-ax^2$ 型问题。通法是固定一个结构单调的因子（如 $e^x-a/x$ 或 $xe^x-a$），再利用其单调性讨论参数的临界值。
