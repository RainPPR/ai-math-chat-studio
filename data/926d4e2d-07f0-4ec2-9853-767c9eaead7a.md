## 1. 基础定义与同角三角函数关系

### 1.1 任意角的三角函数定义（单位圆定义）
设 $\alpha$ 是一个任意角，其终边与单位圆交于点 $P(x, y)$，则：

$$\sin \alpha = y, \quad \cos \alpha = x, \quad \tan \alpha = \frac{y}{x} \quad (x \neq 0)$$

### 1.2 倒数与商数关系
* **倒数关系**（高阶复习必备）：

$$\csc \alpha = \frac{1}{\sin \alpha}, \quad \sec \alpha = \frac{1}{\cos \alpha}, \quad \cot \alpha = \frac{1}{\tan \alpha}$$

* **商数关系**：

$$\tan \alpha = \frac{\sin \alpha}{\cos \alpha}, \quad \cot \alpha = \frac{\cos \alpha}{\sin \alpha}$$

### 1.3 平方关系（勾股恒等式）及其二级变式
* **一级公式**：

$$\sin^2 \alpha + \cos^2 \alpha = 1$$

$$1 + \tan^2 \alpha = \sec^2 \alpha$$

$$1 + \cot^2 \alpha = \csc^2 \alpha$$

* **考场高频变形（“1”的妙用）**：
    
    1. **解方程常用**：$(\sin \alpha \pm \cos \alpha)^2 = 1 \pm 2\sin \alpha \cos \alpha = 1 \pm \sin 2\alpha$
    
    2. **齐次式切化**：若已知 $\tan \alpha = t$，求 $\sin^2 \alpha + m \sin \alpha \cos \alpha + n \cos^2 \alpha$ 的值，可利用“分母为 1”进行转化：
    
    $$\frac{\sin^2 \alpha + m \sin \alpha \cos \alpha + n \cos^2 \alpha}{\sin^2 \alpha + \cos^2 \alpha} = \frac{\tan^2 \alpha + m \tan \alpha + n}{\tan^2 \alpha + 1}$$

## 2. 诱导公式的本质与广义表示

### 2.1 终极统一法则
所有诱导公式皆可归纳为：

$$f\left( k \cdot \frac{\pi}{2} \pm \alpha \right) \quad (k \in \mathbb{Z})$$

**口诀**：**“奇变偶不变，符号看象限”**。
* **奇变偶不变**：若 $k$ 为奇数，则函数名改变（$\sin \leftrightarrow \cos$, $\tan \leftrightarrow \cot$）；若 $k$ 为偶数，函数名保持不变。
* **符号看象限**：视 $\alpha$ 为锐角，判断原角 $k \cdot \frac{\pi}{2} \pm \alpha$ 所在象限，并在前面加上该象限内原三角函数值的正负号。

### 2.2 广义公式表（$k \in \mathbb{Z}$）

$$\sin(2k\pi + \alpha) = \sin \alpha, \quad \cos(2k\pi + \alpha) = \cos \alpha, \quad \tan(2k\pi + \alpha) = \tan \alpha$$

$$\sin(\pi - \alpha) = \sin \alpha, \quad \cos(\pi - \alpha) = -\cos \alpha, \quad \tan(\pi - \alpha) = -\tan \alpha$$

$$\sin(\pi + \alpha) = -\sin \alpha, \quad \cos(\pi + \alpha) = -\cos \alpha, \quad \tan(\pi + \alpha) = \tan \alpha$$

$$\sin\left(\frac{\pi}{2} - \alpha\right) = \cos \alpha, \quad \cos\left(\frac{\pi}{2} - \alpha\right) = \sin \alpha, \quad \tan\left(\frac{\pi}{2} - \alpha\right) = \cot \alpha$$

$$\sin\left(\frac{\pi}{2} + \alpha\right) = \cos \alpha, \quad \cos\left(\frac{\pi}{2} + \alpha\right) = -\sin \alpha, \quad \tan\left(\frac{\pi}{2} + \alpha\right) = -\cot \alpha$$

## 3. 和差角与多角展开公式

### 3.1 核心和差角公式

$$\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta$$

$$\cos(\alpha \pm \beta) = \cos \alpha \cos \beta \mp \sin \alpha \sin \beta$$

$$\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}$$

### 3.2 二级常用变形（高考秒杀级）
* **正切和差变形（极高频）**：

$$\tan \alpha \pm \tan \beta = \tan(\alpha \pm \beta)(1 \mp \tan \alpha \tan \beta)$$

$$\tan \alpha \tan \beta = 1 - \frac{\tan \alpha \pm \tan \beta}{\tan(\alpha \pm \beta)}$$

* **经典特殊角放缩与代换**：

$$\tan\left(\alpha \pm \frac{\pi}{4}\right) = \frac{\tan \alpha \pm 1}{1 \mp \tan \alpha}$$

$$\frac{1 + \sin 2\theta}{\cos 2\theta} = \tan\left(\theta + \frac{\pi}{4}\right), \quad \frac{1 - \sin 2\theta}{\cos 2\theta} = \tan\left(\frac{\pi}{4} - \theta\right)$$

### 3.3 三角和公式（三级结论）

$$\sin(\alpha + \beta + \gamma) = \sin \alpha \cos \beta \cos \gamma + \cos \alpha \sin \beta \cos \gamma + \cos \alpha \cos \beta \sin \gamma - \sin \alpha \sin \beta \sin \gamma$$

$$\cos(\alpha + \beta + \gamma) = \cos \alpha \cos \beta \cos \gamma - \sin \alpha \sin \beta \cos \gamma - \sin \alpha \cos \beta \sin \gamma - \cos \alpha \sin \beta \sin \gamma$$

$$\tan(\alpha + \beta + \gamma) = \frac{\tan \alpha + \tan \beta + \tan \gamma - \tan \alpha \tan \beta \tan \gamma}{1 - (\tan \alpha \tan \beta + \tan \beta \tan \gamma + \tan \gamma \tan \alpha)}$$

## 4. 倍角、半角与万能公式

### 4.1 二倍角公式

$$\sin 2\alpha = 2\sin \alpha \cos \alpha$$

$$\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$$

$$\tan 2\alpha = \frac{2\tan \alpha}{1 - \tan^2 \alpha}$$

### 4.2 三倍角公式（竞赛级，高考压轴防超纲）
* **正弦三倍角**（口诀：3 减 4 立方）：

$$\sin 3\alpha = 3\sin \alpha - 4\sin^3 \alpha$$

* **余弦三倍角**（口诀：4 立方减 3）：

$$\cos 3\alpha = 4\cos^3 \alpha - 3\cos \alpha$$

* **正切三倍角**：

$$\tan 3\alpha = \frac{3\tan \alpha - \tan^3 \alpha}{1 - 3\tan^2 \alpha} = \tan \alpha \cdot \tan\left(\frac{\pi}{3} - \alpha\right) \cdot \tan\left(\frac{\pi}{3} + \alpha\right)$$

### 4.3 降幂与升幂公式（微积分、积分最常用）
* **降幂恒等式**：

$$\sin^2 \alpha = \frac{1 - \cos 2\alpha}{2}, \quad \cos^2 \alpha = \frac{1 + \cos 2\alpha}{2}$$

$$\sin^3 \alpha = \frac{3\sin \alpha - \sin 3\alpha}{4}, \quad \cos^3 \alpha = \frac{3\cos \alpha + \cos 3\alpha}{4}$$

* **升幂（开方去根号）常用**：

$$1 + \cos \alpha = 2\cos^2 \frac{\alpha}{2}, \quad 1 - \cos \alpha = 2\sin^2 \frac{\alpha}{2}$$

### 4.4 半角公式（注意象限符号确定）

$$\sin \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{2}}$$

$$\cos \frac{\alpha}{2} = \pm \sqrt{\frac{1 + \cos \alpha}{2}}$$

$$\tan \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{1 + \cos \alpha}} = \frac{\sin \alpha}{1 + \cos \alpha} = \frac{1 - \cos \alpha}{\sin \alpha} = \csc \alpha - \cot \alpha$$

### 4.5 万能公式（用 $t = \tan \frac{\alpha}{2}$ 表达一切）
该公式是**有理化积分**与**超越方程代数化**的核心工具：

$$\sin \alpha = \frac{2t}{1 + t^2}, \quad \cos \alpha = \frac{1 - t^2}{1 + t^2}, \quad \tan \alpha = \frac{2t}{1 - t^2} \quad \left(t = \tan \frac{\alpha}{2}\right)$$

## 5. 积化和差与和差化积

### 5.1 积化和差（单体乘积 $\to$ 线性叠加）

$$\sin \theta \cos \phi = \frac{1}{2} [\sin(\theta + \phi) + \sin(\theta - \phi)]$$

$$\cos \theta \sin \phi = \frac{1}{2} [\sin(\theta + \phi) - \sin(\theta - \phi)]$$

$$\cos \theta \cos \phi = \frac{1}{2} [\cos(\theta + \phi) + \cos(\theta - \phi)]$$

$$\sin \theta \sin \phi = -\frac{1}{2} [\cos(\theta + \phi) - \cos(\theta - \phi)]$$

### 5.2 和差化积（线性叠加 $\to$ 因式乘积，便于寻找零点）

$$\sin x + \sin y = 2 \sin\frac{x + y}{2} \cos\frac{x - y}{2}$$

$$\sin x - \sin y = 2 \cos\frac{x + y}{2} \sin\frac{x - y}{2}$$

$$\cos x + \cos y = 2 \cos\frac{x + y}{2} \cos\frac{x - y}{2}$$

$$\cos x - \cos y = -2 \sin\frac{x + y}{2} \sin\frac{x - y}{2}$$

### 5.3 进阶二级结论（正切和差化积）

$$\tan x \pm \tan y = \frac{\sin(x \pm y)}{\cos x \cos y}$$

$$\cot x \pm \cot y = \pm \frac{\sin(y \pm x)}{\sin x \sin y}$$

## 6. 辅助角公式与结构同构变形

### 6.1 标准辅助角公式
对于任意实数 $a, b$ （不全为0）：

$$a\sin x + b\cos x = \sqrt{a^2 + b^2} \sin(x + \varphi)$$

其中辅助角 $\varphi$ 的取值由下列方程组唯一确定：

$$\cos \varphi = \frac{a}{\sqrt{a^2 + b^2}}, \quad \sin \varphi = \frac{b}{\sqrt{a^2 + b^2}}$$

### 6.2 常用特例（考场直接写出）

$$\sin x + \cos x = \sqrt{2}\sin\left(x + \frac{\pi}{4}\right) = \sqrt{2}\cos\left(x - \frac{\pi}{4}\right)$$

$$\sin x - \cos x = \sqrt{2}\sin\left(x - \frac{\pi}{4}\right) = -\sqrt{2}\cos\left(x + \frac{\pi}{4}\right)$$

$$\sqrt{3}\sin x \pm \cos x = 2\sin\left(x \pm \frac{\pi}{6}\right)$$

$$\sin x \pm \sqrt{3}\cos x = 2\sin\left(x \pm \frac{\pi}{3}\right)$$

### 6.3 整体代换同构（对称式压轴题黄金结论）
若令 $t = \sin x + \cos x \in [-\sqrt{2}, \sqrt{2}]$，则：

$$\sin x \cos x = \frac{t^2 - 1}{2}$$

$$\sin^3 x + \cos^3 x = (\sin x + \cos x)(1 - \sin x \cos x) = t\left(1 - \frac{t^2 - 1}{2}\right) = \frac{3t - t^3}{2}$$

$$\sin^4 x + \cos^4 x = 1 - 2\sin^2 x \cos^2 x = 1 - \frac{(t^2 - 1)^2}{2}$$

## 7. 三角形中的几何三角恒等式（解三角形二级与三级结论）

在 $\triangle ABC$ 中，记角 $A, B, C$ 对应的边长分别为 $a, b, c$，外接圆半径为 $R$，内切圆半径为 $r$，半周长 $s = \frac{a + b + c}{2}$。

### 7.1 解三角形四大基石定理
* **正弦定理**：

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$

* **余弦定理**：

$$a^2 = b^2 + c^2 - 2bc\cos A \iff \cos A = \frac{b^2 + c^2 - a^2}{2bc}$$

* **投影定理（第一余弦定理）**：

$$a = b\cos C + c\cos B, \quad b = c\cos A + a\cos C, \quad c = a\cos B + b\cos A$$

* **正切定理**（非考纲重点，但竞赛好用）：

$$\frac{a - b}{a + b} = \frac{\tan\frac{A - B}{2}}{\tan\frac{A + B}{2}}$$

### 7.2 面积公式的全维度呈现

$$S = \frac{1}{2}ah_a = \frac{1}{2}bc\sin A = \frac{abc}{4R} = rs = \sqrt{s(s - a)(s - b)(s - c)} \quad \text{（海伦公式）}$$

$$S = 2R^2 \sin A \sin B \sin C$$

### 7.3 三角形内角的经典恒等变形（二级结论）
由于 $A + B + C = \pi$：
* **和差互补变形**：

$$\sin(A + B) = \sin C, \quad \cos(A + B) = -\cos C, \quad \tan(A + B) = -\tan C$$

$$\sin\frac{A + B}{2} = \cos\frac{C}{2}, \quad \cos\frac{A + B}{2} = \sin\frac{C}{2}, \quad \tan\frac{A + B}{2} = \cot\frac{C}{2}$$

* **著名的三角求和恒等式（强力因式分解源泉）**：

$$\tan A + \tan B + \tan C = \tan A \tan B \tan C \quad \text{（仅在非直角三角形中）}$$

$$\cot \frac{A}{2} + \cot \frac{B}{2} + \cot \frac{C}{2} = \cot \frac{A}{2} \cot \frac{B}{2} \cot \frac{C}{2}$$

$$\tan\frac{A}{2}\tan\frac{B}{2} + \tan\frac{B}{2}\tan\frac{C}{2} + \tan\frac{C}{2}\tan\frac{A}{2} = 1$$

$$\sin 2A + \sin 2B + \sin 2C = 4\sin A \sin B \sin C$$

$$\cos 2A + \cos 2B + \cos 2C = -1 - 4\cos A \cos B \cos C$$

$$\sin A + \sin B + \sin C = 4\cos\frac{A}{2}\cos\frac{B}{2}\cos\frac{C}{2}$$

$$\cos A + \cos B + \cos C = 1 + 4\sin\frac{A}{2}\sin\frac{B}{2}\sin\frac{C}{2}$$

$$\sin^2 A + \sin^2 B + \sin^2 C = 2 + 2\cos A \cos B \cos C$$

$$\cos^2 A + \cos^2 B + \cos^2 C = 1 - 2\cos A \cos B \cos C$$

### 7.4 莫尔魏德公式（Mollweide's Formulas - 完美连接边与半角，三级结论）

$$\frac{a - b}{c} = \frac{\sin\frac{A - B}{2}}{\cos\frac{C}{2}}$$

$$\frac{a + b}{c} = \frac{\cos\frac{A - B}{2}}{\sin\frac{C}{2}}$$

### 7.5 三角形内角不等式性质（考场直接作为直觉，竞赛可写结论）
* **正/余弦最值**：

$$\sin A + \sin B + \sin C \le \frac{3\sqrt{3}}{2} \quad \text{（当且仅当 $\triangle ABC$ 为等边三角形时等号成立）}$$

$$\cos A + \cos B + \cos C \le \frac{3}{2} \quad \text{（当且仅当 $\triangle ABC$ 为等边三角形时等号成立）}$$

$$\sin \frac{A}{2} \sin \frac{B}{2} \sin \frac{C}{2} \le \frac{1}{8}$$

$$\cos A \cos B \cos C \le \frac{1}{8} \quad \text{（锐角三角形中）}$$

## 8. 高阶代数恒等式与三角级数（竞赛级）

### 8.1 欧拉公式与棣莫弗定理（复数域上的终极统一）
* **欧拉公式**：

$$e^{ix} = \cos x + i\sin x$$

* **棣莫弗定理**：

$$(\cos x + i\sin x)^n = \cos nx + i\sin nx \quad (n \in \mathbb{R})$$

由此派生出三角函数指数表达形式：

$$\sin x = \frac{e^{ix} - e^{-ix}}{2i}, \quad \cos x = \frac{e^{ix} + e^{-ix}}{2}$$

### 8.2 等差角三角级数求和（积化和差构造裂项裂项）
设公差为 $\alpha \neq 2k\pi$：

$$\sum_{k=1}^n \sin(x + k\alpha) = \sin(x + \alpha) + \sin(x + 2\alpha) + \dots + \sin(x + n\alpha) = \frac{\sin\frac{n\alpha}{2} \sin\left(x + \frac{(n+1)\alpha}{2}\right)}{\sin\frac{\alpha}{2}}$$

$$\sum_{k=1}^n \cos(x + k\alpha) = \cos(x + \alpha) + \cos(x + 2\alpha) + \dots + \cos(x + n\alpha) = \frac{\sin\frac{n\alpha}{2} \cos\left(x + \frac{(n+1)\alpha}{2}\right)}{\sin\frac{\alpha}{2}}$$

### 8.3 等比角余弦连乘积（二倍角公式递推）

$$\prod_{k=0}^{n-1} \cos(2^k \theta) = \cos\theta \cos2\theta \cos4\theta \dots \cos(2^{n-1}\theta) = \frac{\sin(2^n\theta)}{2^n\sin\theta}$$

### 8.4 经典奇数与偶数分母乘积（竞赛经典考题）

$$\prod_{k=1}^{n-1} \sin\frac{k\pi}{n} = \frac{n}{2^{n-1}}$$

$$\prod_{k=1}^{n} \cos\frac{k\pi}{2n+1} = \frac{1}{2^n}$$

## 9. 微积分、Taylor 展开与经典三角不等式（导数压轴级）

### 9.1 导数与积分基本表

$$(\sin x)' = \cos x, \quad (\cos x)' = -\sin x, \quad (\tan x)' = \sec^2 x = 1 + \tan^2 x$$

$$\int \sin x \, dx = -\cos x + C, \quad \int \cos x \, dx = \sin x + C, \quad \int \tan x \, dx = -\ln|\cos x| + C$$

### 9.2 Taylor 幂级数展开（强力估算与放缩构造来源）

$$\sin x = x - \frac{x^3}{6} + \frac{x^5}{120} - \dots + (-1)^n \frac{x^{2n+1}}{(2n+1)!} + o(x^{2n+1})$$

$$\cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \dots + (-1)^n \frac{x^{2n}}{(2n)!} + o(x^{2n})$$

$$\tan x = x + \frac{x^3}{3} + \frac{2x^5}{15} + \dots \quad \left(|x| < \frac{\pi}{2}\right)$$

### 9.3 核心导数放缩三角不等式（高考大题第一步突破）
* **基础放缩**（对所有 $x \ge 0$）：

$$x - \frac{x^3}{6} \le \sin x \le x$$

$$1 - \frac{x^2}{2} \le \cos x \le 1 - \frac{x^2}{2} + \frac{x^4}{24}$$

* **经典切线放缩**：
  当 $x \in \left(0, \frac{\pi}{2}\right)$ 时，有：

$$\sin x < x < \tan x$$

* **约旦不等式 (Jordan's Inequality)**：
  当 $x \in \left[0, \frac{\pi}{2}\right]$ 时：

$$\frac{2}{\pi}x \le \sin x \le x$$

* **库萨-惠更斯不等式 (Cusa-Huygens Inequality)**：
  当 $x \in \left(0, \frac{\pi}{2}\right)$ 时：

$$\frac{\sin x}{x} < \frac{2 + \cos x}{3}$$

## 10. 元认知总结：三角变形的考场直觉与思维模板

面对千变万化的三角小题或大题，请在大脑中安装以下三大**“解题过滤器”**：

### 核心思维 1：角度配凑法则（看角不看名）
三角恒等变形的第一步永远是**观察角的关系**。
* 若已知角为 $\alpha$ 和 $\beta$，欲求 $\theta$，寻找 $\theta$ 与 $\alpha, \beta$ 的线性代数关系：
  
  $$\theta = (\alpha + \theta) - \alpha, \quad 2\alpha = (\alpha + \beta) + (\alpha - \beta), \quad \alpha = \frac{\alpha + \beta}{2} + \frac{\alpha - \beta}{2}$$
  
* 看到 $2\theta$ 与 $\theta$ 并在，优先考虑**降幂**或**倍角展开**统一角度。

### 核心思维 2：函数名统一法则（名重于形）
* **“切化弦”**：遇到 $\tan, \cot, \sec, \csc$ 混杂的复杂分式或乘积式，通常全部转化为最基础的 $\sin, \cos$ 处理。
* **“弦化切”**：遇到齐次分式结构（如 $\frac{a\sin x + b\cos x}{c\sin x + d\cos x}$ 或二次齐次式），分子分母同除以 $\cos x$ 转化为 $\tan x$ 的单变量方程。

### 核心思维 3：结构同构法则
* 如果代数式中频繁出现 $\sin x \pm \cos x$ 与 $\sin x \cos x$，立刻令 $t = \sin x \pm \cos x$，利用 $t^2 = 1 \pm 2\sin x\cos x$ 将超越方程降维为**关于 $t$ 的一元二次方程**。
* 看到 $1 \pm \cos \theta$，自动在脑海中闪现半角公式进行“消元”或“去根号”操作。
