## user

```text
user/2026-07-09T09:37:21.706Z

地面 $MN$ 上紧密排列着 10 个完全相同的木板，一可视作质点的滑块以一定初速度冲上木板 1，滑块最终静止在木板 7 上。已知滑块质量 $m=5\text{kg}$，每个木板的质量 $M=1\text{kg}$，宽度 $d=9\text{m}$，滑块与木板间的动摩擦因数为 $\mu_1=0.4$，木板与地面 $MN$ 间动摩擦因数为 $\mu_2=0.2$，设最大静摩擦力等于滑动摩擦力，$g$ 取 $10\text{m/s}^2$，求：

(1) 滑块刚滑上木板 1 时的加速度大小 $a$；
(2) 滑块滑离木板 4 时的最大速度 $v_m$；
(3) 木板 3 右边缘与木板 10 左边缘的最远距离 $x_m$。
```

## model

```text
model/2026-07-09T09:51:45.197Z

### 问题分析

滑块以初速度 \(v_0\) 冲上木板 1，在滑行过程中受木板滑动摩擦力作用减速，木板则受滑块摩擦力和地面摩擦力。由于各时刻滑块所在木板不同，各木板与地面间的正压力（从而最大静摩擦力）也不同。计算表明，当滑块位于木板 1‑6 上时，滑块对木板的推力 \(f = \mu_1 mg = 20\ \mathrm{N}\) 不大于所有可能被带动木板与地面间总最大静摩擦力的最大值，通过静摩擦力的自动分配可使这些木板保持静止；但当滑块进入木板 7 时，木板 7‑10 的总最大静摩擦力仅为 \(12 + 2 \times 3 = 18\ \mathrm{N} < 20\ \mathrm{N}\)，因此这些木板会向右加速。滑块最终停在木板 7 上，意味着它在木板 7 上相对滑动的位移不超过板宽 \(d=9\ \mathrm{m}\)，从而对滑块进入木板 7 时的速度 \(v_7\) 有约束，并由此得出滑离木板 4 时的最大速度和木板 3 与木板 10 的最远距离。

基于上述分析，分阶段求解如下。

### 符号定义

- \(m = 5\ \mathrm{kg}\)，滑块质量；
- \(M = 1\ \mathrm{kg}\)，单个木板质量；
- \(d = 9\ \mathrm{m}\)，木板宽度；
- \(\mu_1 = 0.4\)，滑块与木板间动摩擦因数；
- \(\mu_2 = 0.2\)，木板与地面间动摩擦因数；
- \(g = 10\ \mathrm{m/s^2}\)；
- 摩擦力大小：\(f = \mu_1 mg = 20\ \mathrm{N}\)（滑块与木板间滑动摩擦力）；  
  木板与地面间滑动摩擦力：当滑块在木板上时为 \(\mu_2 (M+m)g = 12\ \mathrm{N}\)，无滑块时为 \(\mu_2 Mg = 2\ \mathrm{N}\)。

### (1) 滑块刚滑上木板 1 时的加速度

刚滑上时，滑块相对木板 1 向右运动，受滑动摩擦力向左，大小 \(f = 20\ \mathrm{N}\)。  
滑块水平方向只受此力，由牛顿第二定律  
\[
m a = f \quad\Rightarrow\quad a = \frac{f}{m} = \mu_1 g = 4\ \mathrm{m/s^2},
\]  
方向向左（与初速度相反）。

**答案**：\(a = 4\ \mathrm{m/s^2}\)。

### (2) 滑块滑离木板 4 时的最大速度 \(v_m\)

滑块在木板 1‑6 上滑行时，通过静摩擦力的适当分配，这些木板均可保持静止（平衡），故可视为滑块在固定木板上做匀减速运动，加速度恒为 \(a = -4\ \mathrm{m/s^2}\)。

设滑块滑离木板 4（即经过木板 1‑4，总位移 \(4d = 36\ \mathrm{m}\)）时的速度为 \(v_4\)，进入木板 7 左端时的速度为 \(v_7\)，由运动学公式：
\[
v_7^2 = v_0^2 - 2a\cdot 6d = v_0^2 - 2\cdot4\cdot54 = v_0^2 - 432,
\]  
\[
v_4^2 = v_0^2 - 2a\cdot 4d = v_0^2 - 2\cdot4\cdot36 = v_0^2 - 288,
\]  
因此
\[
v_4^2 = v_7^2 + 144 . \tag{1}
\]

滑块进入木板 7 后，木板 7‑10 会一起向右加速（原因见分析）。设木板 7‑10 整体质量为 \(4M = 4\ \mathrm{kg}\)，受地面摩擦力（向左）：
\[
f_{\text{地}} = \mu_2(M+m)g + 3\cdot\mu_2 M g = 12 + 2\times3 = 18\ \mathrm{N},
\]  
滑块对木板 7 的向右摩擦力 \(f = 20\ \mathrm{N}\)，故整体加速度
\[
a_M = \frac{f - f_{\text{地}}}{4M} = \frac{20-18}{4} = 0.5\ \mathrm{m/s^2} \quad(\text{向右}).
\]

滑块仍受滑动摩擦力向左，对地加速度 \(a_s = -4\ \mathrm{m/s^2}\)。  
滑块相对木板整体的加速度
\[
a_{\text{rel}} = a_s - a_M = -4 - 0.5 = -4.5\ \mathrm{m/s^2},
\]  
相对初速度 \(v_{\text{rel0}} = v_7\)（木板整体初速为 0）。  
经时间 \(t_1 = v_7/4.5\) 后二者共速，此过程中滑块相对木板位移（即滑块在木板 7 上的滑行距离）
\[
s_{\text{rel}} = \frac{v_7^2}{2|a_{\text{rel}}|} = \frac{v_7^2}{9}.
\]  
要求滑块不从木板 7 右端滑出，需 \(s_{\text{rel}} \le d = 9\ \mathrm{m}\)，故
\[
v_7^2 \le 81 \quad\Rightarrow\quad v_7 \le 9\ \mathrm{m/s}. \tag{2}
\]

由 (1) 知 \(v_4\) 随 \(v_7\) 增大而增大。取 \(v_7 = 9\ \mathrm{m/s}\) 时 \(v_4\) 最大：
\[
v_m = v_4\big|_{v_7=9} = \sqrt{9^2+144} = \sqrt{225}=15\ \mathrm{m/s}.
\]

**答案**：\(v_m = 15\ \mathrm{m/s}\)。

### (3) 木板 3 右边缘与木板 10 左边缘的最远距离 \(x_m\)

取(2)中临界情况 \(v_7=9\ \mathrm{m/s}\)（此时 \(s_{\text{rel}}=9\ \mathrm{m}\)，滑块恰停在木板 7 右端），此时木板 7‑10 整体的运动分两段：

1. **加速阶段**（相对滑动）  
   初速 0，末速 \(v = a_M t_1 = 0.5 \times \frac{9}{4.5} = 1\ \mathrm{m/s}\)，  
   位移 \(s_1 = \frac{v^2}{2a_M} = \frac{1^2}{2\times0.5} = 1\ \mathrm{m}\)（或直接用 \(s_1 = v^2 = 1\ \mathrm{m}\)）。

2. **减速阶段**（共速后）  
   滑块与木板整体质量 \(m+4M=9\ \mathrm{kg}\)，地面摩擦力
   \[
   f_{\text{总}} = \mu_2 (m+4M)g = 0.2\times9\times10 = 18\ \mathrm{N},
   \]  
   加速度 \(a' = -\frac{f_{\text{总}}}{9} = -2\ \mathrm{m/s^2}\)，初速 \(v=1\ \mathrm{m/s}\)，  
   位移 \(s_2 = \frac{v^2}{2|a'|} = \frac{1}{4} = 0.25\ \mathrm{m}\)。

故木板 7‑10 整体总位移
\[
s_{\text{total}} = s_1 + s_2 = 1.25\ \mathrm{m}.
\]

初始时木板紧密排列，各木板宽度 \(d=9\ \mathrm{m}\)。设木板 1 左端为坐标原点，则初始时木板 3 右边缘在 \(x=3d=27\ \mathrm{m}\)，木板 10 左边缘在 \(x=9d=81\ \mathrm{m}\)，相距
\[
\Delta x_0 = 81 - 27 = 54\ \mathrm{m}.
\]

运动过程中木板 1‑6 保持静止，故木板 3 右边缘位置不变；木板 7‑10 整体向右平移 \(s_{\text{total}}\)，因此木板 10 左边缘最终位置为 \(81 + s_{\text{total}}\)。最终静止时两者距离
\[
x_m = 54 + s_{\text{total}} = 54 + 1.25 = 55.25\ \mathrm{m} = \frac{221}{4}\ \mathrm{m}.
\]

此距离随 \(v_7\) 增大而增大，故取 \(v_7=9\ \mathrm{m/s}\) 时得最大值，即最远距离。

**答案**：\(x_m = 55.25\ \mathrm{m}\)（或 \(\dfrac{221}{4}\ \mathrm{m}\)）。
```
