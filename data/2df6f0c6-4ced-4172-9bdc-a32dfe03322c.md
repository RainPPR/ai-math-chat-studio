```text
(2023湖南,15,16分) 质量为 $M$ 的匀质凹槽放在光滑水平地面上，凹槽内有一个半椭圆形的光滑轨道，椭圆的半长轴和半短轴分别为 $a$ 和 $b$，长轴水平，短轴竖直。质量为 $m$ 的小球，初始时刻从椭圆轨道长轴的右端点由静止开始下滑。以初始时刻椭圆中心的位置为坐标原点，在竖直平面内建立固定于地面的直角坐标系 $x O y $，椭圆长轴位于 $x$ 轴上。整个过程凹槽不翻转，重力加速度为 $g$。

(1) 小球第一次运动到轨道最低点时,求凹槽的速度大小以及凹槽相对于初始时刻运动的距离;

(2) 在平面直角坐标系 $xOy$ 中, 求出小球运动的轨迹方程;

(3) 若  $ \frac{M}{m} = \frac{b}{a - b} $，求小球下降  $ h = \frac{b}{2} $ 高度时，小球相对于地面的速度大小（结果用 $a$、$b$ 及 $g$ 表示）。
```

## model

```text
model/2026-06-19T10:28:27.482Z

**预研分析与结构透视**

这是一道典型的**动量-能量耦合约束运动**问题。其核心数学结构可分解为三重视角的叠加：

1. **守恒律层面**：系统水平方向动量守恒（地面光滑，无水平外力），且机械能守恒（光滑轨道）。这直接意味着**系统质心在水平方向静止**。
2. **约束层面**：小球被限制在凹槽的椭圆轨道内，相对凹槽的几何约束由 $\frac{x_r^2}{a^2}+\frac{y^2}{b^2}=1$（$y\le 0$）描述。凹槽本身只做平动，因此竖直方向 $y$ 既是相对坐标也是绝对坐标。
3. **退化解构**：第三问给出的质量比条件 $\frac{M}{m}=\frac{b}{a-b}$，本质上是让地面系中小球轨迹的**二次型特征值相等**，从而将椭圆轨迹退化为**圆轨迹**。这是命题人埋下的几何“暗门”。

以下给出全路径的求解与对比。

---

### 【常规解法】

#### (1) 小球第一次到达最低点时凹槽的速度与位移

**步骤 1：建立运动学关系**

设凹槽中心的水平位移为 $s$（向右为正），小球相对凹槽中心的坐标为 $(x_r, y_r)$，则小球相对地面的坐标为
$$x = s + x_r, \quad y = y_r.$$
由于系统初始水平动量为零，且水平方向动量守恒，有
$$m\dot{x} + M\dot{s} = 0 \quad\Rightarrow\quad m(\dot{s} + \dot{x}_r) + M\dot{s} = 0.$$
解得凹槽速度与小球相对水平速度的耦合关系：
$$\dot{s} = -\frac{m}{m+M}\dot{x}_r \tag{1.1}$$
积分并利用初始条件 $s(0)=0,\; x_r(0)=a$，得
$$s = \frac{m(a-x_r)}{m+M}. \tag{1.2}$$

**步骤 2：求凹槽的位移**

小球第一次到达最低点时，$x_r = 0$。代入 (1.2)：
$$\boxed{s = \frac{ma}{m+M}}$$
此即凹槽相对于初始时刻运动的距离。

**步骤 3：由能量守恒求速度**

采用参数 $\theta$ 描述相对运动：$x_r = a\cos\theta,\; y = -b\sin\theta$（$\theta=0$ 对应初始右端点，$\theta=\frac{\pi}{2}$ 对应最低点）。

由 (1.1)，绝对水平速度
$$\dot{x} = \dot{s} + \dot{x}_r = \frac{M}{m+M}\dot{x}_r.$$
在最低点 $\theta=\frac{\pi}{2}$，相对速度沿水平方向，故 $\dot{y} = \dot{y}_r = 0$。

系统的总动能可表示为
$$T = \frac{1}{2} m(\dot{x}^2+\dot{y}^2) + \frac{1}{2} M\dot{s}^2 = \frac{1}{2}\cdot\frac{mM}{m+M}\dot{x}_r^2 + \frac{1}{2}m\dot{y}_r^2.$$
在最低点，$\dot{y}_r = 0$，且 $\dot{x}_r = -a\dot{\theta}$，因此
$$T = \frac{1}{2}\cdot\frac{mM}{m+M} a^2 \dot{\theta}^2.$$
由机械能守恒，势能减少量等于动能增量：
$$\frac{1}{2}\cdot\frac{mM}{m+M} a^2 \dot{\theta}^2 = mgb \quad\Rightarrow\quad \dot{\theta}^2 = \frac{2gb(m+M)}{Ma^2}.$$
凹槽速度 $V = \dot{s}$。在最低点，$V = \frac{ma}{m+M}|\dot{\theta}|$，代入得凹槽速度大小为
$$\boxed{V = \sqrt{\frac{2m^2 gb}{M(m+M)}} = m\sqrt{\frac{2gb}{M(m+M)}}}.$$

---

#### (2) 小球在固定坐标系 $xOy$ 中的轨迹方程

由 (1.2) 与 $x = s + x_r$，消去时间参数可得
$$x = \frac{ma}{m+M} + \frac{M}{m+M}x_r.$$
解出 $x_r$ 并结合约束 $y=y_r$ 与椭圆方程 $\frac{x_r^2}{a^2}+\frac{y^2}{b^2}=1\;(y\le 0)$，代入得
$$\frac{\left(x - \frac{ma}{m+M}\right)^2}{\left(\frac{Ma}{m+M}\right)^2} + \frac{y^2}{b^2} = 1, \quad y \le 0.$$
这是一个**中心在 $\left(\frac{ma}{m+M}, 0\right)$、水平半长轴为 $\frac{Ma}{m+M}$、竖直半短轴为 $b$ 的下半椭圆**。

$$\boxed{\frac{\left((m+M)x - ma\right)^2}{(Ma)^2} + \frac{y^2}{b^2} = 1 \quad (y \le 0)}$$

---

#### (3) 特定条件下的速度大小

当小球下降高度 $h=\frac{b}{2}$ 时，$y = -\frac{b}{2}$，对应参数 $\theta$ 满足
$$\sin\theta = \frac{1}{2} \quad\Rightarrow\quad \theta = \frac{\pi}{6}.$$
此时 $\cos\theta = \frac{\sqrt{3}}{2}$，$\sin\theta=\frac{1}{2}$，相对速度分量
$$\dot{x}_r = -a\sin\theta\,\dot{\theta} = -\frac{a}{2}\dot{\theta}, \quad \dot{y}_r = -b\cos\theta\,\dot{\theta} = -\frac{b\sqrt{3}}{2}\dot{\theta}.$$

小球绝对速度满足
$$v^2 = \dot{x}^2+\dot{y}^2 = \left(\frac{M}{m+M}\dot{x}_r\right)^2 + \dot{y}_r^2 = \frac{M^2 a^2}{4(m+M)^2}\dot{\theta}^2 + \frac{3b^2}{4}\dot{\theta}^2.$$
总能量守恒给出
$$\frac{1}{2}\left[\frac{mM}{m+M}\cdot\frac{a^2}{4} + \frac{3mb^2}{4}\right]\dot{\theta}^2 = \frac{mgb}{2},$$
即
$$\left[\frac{M a^2}{m+M} + 3b^2\right]\dot{\theta}^2 = 4gb. \tag{3.1}$$
题设条件为 $\frac{M}{m} = \frac{b}{a-b}$，等价于
$$\frac{M}{m+M} = \frac{b}{a}.$$
代入 (3.1) 左端第一项：$\frac{M a^2}{m+M} = a\cdot\frac{M a}{m+M} = ab$。
于是
$$(ab + 3b^2)\dot{\theta}^2 = 4gb \quad\Rightarrow\quad \dot{\theta}^2 = \frac{4g}{a+3b}.$$
同时，速度平方表达式利用同一条件化简为
$$v^2 = \left(\frac{b^2}{a^2}\cdot a^2 + 3b^2\right)\frac{\dot{\theta}^2}{4} = b^2\dot{\theta}^2 = \frac{4gb^2}{a+3b}.$$
故小球相对地面的速度大小为
$$\boxed{v = 2b\sqrt{\frac{g}{a+3b}}}.$$

---

### 【进阶解法 / 技巧】

#### (1) 质心系视角：轨迹的仿射不变性

由于地面光滑且系统初始水平动量为零，**质心水平位置固定不变**。设质心坐标 $X_{\mathrm{cm}}$，则
$$X_{\mathrm{cm}} = \frac{mx + Ms}{m+M} = \frac{ma}{m+M}.$$
小球相对质心的坐标 $(x', y')$ 满足
$$x' = x - X_{\mathrm{cm}} = \frac{M}{m+M}x_r, \quad y' = y = y_r.$$
代入椭圆约束立即得到质心系中更为“纯粹”的轨迹：
$$\frac{(x')^2}{\left(\frac{Ma}{m+M}\right)^2} + \frac{(y')^2}{b^2} = 1, \quad y' \le 0.$$
这说明：相对质心，小球仍在一个固定的半椭圆上运动，仅仅是水平轴按质量比缩放了 $\frac{M}{m+M}$ 倍。平移回地面系，便直接得到 (2) 的答案，而无需处理复杂的耦合项。

#### (2) 条件 (3) 的几何退化：从椭圆到圆

第三问的条件 $\frac{M}{m} = \frac{b}{a-b}$ 等价于
$$\frac{M}{m+M} = \frac{b}{a}.$$
将其代入质心系轨迹的半长轴，恰好得到
$$\frac{Ma}{m+M} = b.$$
于是质心系轨迹方程退化为
$$(x')^2 + (y')^2 = b^2, \quad y' \le 0,$$
即一个以质心为圆心、半径为 $b$ 的下半圆！

这意味着：在该特殊参数下，小球相对地面的运动被“圆化”了。此时用参数 $\theta$ 描写：
$$x' = b\cos\theta, \quad y = -b\sin\theta,$$
而绝对速度大小恰为 $v = b|\dot{\theta}|$（因为地面系与质心系在速度上是重合的）。

利用总动能表达式（常规解法中已推导）：
$$T = \frac{m}{2}\dot{\theta}^2\left[b^2 + b(a-b)\sin^2\theta\right].$$
当 $h=\frac{b}{2}$ 时 $\sin\theta=\frac{1}{2}$，结合能量守恒 $T = \frac{mgb}{2}$，直接解得
$$\dot{\theta}^2 = \frac{4g}{a+3b} \quad\Rightarrow\quad v = b|\dot{\theta}| = 2b\sqrt{\frac{g}{a+3b}}.$$
此方法绕开了凹槽速度 $V$ 的显式求解，直接利用几何退化将问题压缩为“圆周运动+能量守恒”，计算量显著减少，且物理图像极为优美。

### 【总结与反思】

1. **认知模型提炼**：本题属于**“双体动量守恒 + 曲线约束”**类问题。其标准认知路径为：
   - 先用动量守恒消去一个平动自由度，得到相对坐标的等效单自由度体系；
   - 再用机械能守恒建立广义坐标与速度的关系；
   - 最终通过“相对速度 → 绝对速度”的线性变换（本题中水平分量缩放 $\frac{M}{m+M}$）得到地面系结果。

2. **高维启示**：第三问的参数设计并非偶然。条件 $\frac{M}{m}=\frac{b}{a-b}$ 使得质心系中的椭圆轨迹退化为圆，这是命题人精心构造的**“特征值调和”**——椭圆两半轴之比恰好等于质量分配引起的缩放因子。抓住这一点，便能从“繁琐代数”跃迁到“几何秒杀”。

3. **易错点与陷阱**：
   - **绝对速度与相对速度混淆**：小球的绝对水平速度是 $\dot{x} = \frac{M}{m+M}\dot{x}_r$，而非 $\dot{x}_r$。漏掉缩放因子是考场上的高频失误。
   - **椭圆参数 $\theta$ 不等于地面转角**：即便在进阶解法中发现轨迹为圆，这里的 $\theta$ 也是相对凹槽椭圆的离心角，只有在圆化后才与地面系中的几何转角一致。
   - **极限检验**：当 $M\to\infty$ 时，凹槽固定，所有结果应退回普通椭圆（或圆）滑块模型；当 $m\ll M$ 时，凹槽位移趋于零，轨迹趋近于固定椭圆。这些极限是自我验证的利器。

4. **知识迁移**：这种“动量守恒导致质心静止，相对运动经缩放后仍为二次曲线”的思想，可以平移到许多双体问题中（如双星系统、反冲滑轨等）。识别出“退化为圆/球”的条件，往往是破解含参数物理题的密钥。
```
