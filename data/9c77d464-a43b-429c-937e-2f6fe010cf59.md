这是一组非常典型的**导数构造类**题目。这类题目的核心在于：通过观察给定的导数等式或不等式，识别出其背后隐藏的**乘积法则 $\frac{d}{dx}[u(x)v(x)]$** 或 **商法则 $\frac{d}{dx}[\frac{u(x)}{v(x)}]$**，从而构造出一个单调函数，将复杂的导数关系转化为简单的函数值比较问题。

---

### 第 7 题：解析

**【元解析】**
观察等式 $f'(x)\cos x + f(x)\sin x = \ln x$。
注意到 $\frac{d}{dx}(\cos x) = -\sin x$，而等式中是 $+\sin x$。这提示我们尝试构造分式 $\frac{f(x)}{\cos x}$ 的导数：
$$\left( \frac{f(x)}{\cos x} \right)' = \frac{f'(x)\cos x - f(x)(-\sin x)}{\cos^2 x} = \frac{f'(x)\cos x + f(x)\sin x}{\cos^2 x}$$
因此，原等式可转化为 $\left( \frac{f(x)}{\cos x} \right)' = \frac{\ln x}{\cos^2 x}$。

**【常规解法】**
1. **构造辅助函数**：令 $g(x) = \frac{f(x)}{\cos x}$，则 $g'(x) = \frac{\ln x}{\cos^2 x}$。
2. **判定单调性**：
   - 当 $x \in (0, 1)$ 时，$\ln x < 0 \implies g'(x) < 0$，$g(x)$ 单调递减；
   - 当 $x \in (1, \frac{\pi}{2})$ 时，$\ln x > 0 \implies g'(x) > 0$，$g(x)$ 单调递增。
   - 故 $g(x)$ 在 $x=1$ 处取得最小值。
3. **选项验证**：
   - **A**：$f(\frac{\pi}{6}) = \frac{\sqrt{3}}{2}g(\frac{\pi}{6})$，$f(\frac{\pi}{3}) = \frac{1}{2}g(\frac{\pi}{3})$。
     左边 $= [\frac{\sqrt{3}}{2}g(\frac{\pi}{6}) + \sqrt{3} \cdot \frac{1}{2}g(\frac{\pi}{3})]\cos 1 = \frac{\sqrt{3}}{2}[g(\frac{\pi}{6}) + g(\frac{\pi}{3})]\cos 1$。
     由于 $g(x) > g(1)$ 对 $x \neq 1$ 成立，且 $\cos 1 > 0$，则 $\frac{\sqrt{3}}{2}[g(\frac{\pi}{6}) + g(\frac{\pi}{3})]\cos 1 > \frac{\sqrt{3}}{2}[2g(1)]\cos 1 = \sqrt{3} \frac{f(1)}{\cos 1} \cos 1 = \sqrt{3} f(1)$。**正确**。
   - **B**：$(\sqrt{3}-1)f(\frac{\pi}{3}) = \frac{\sqrt{3}-1}{2}g(\frac{\pi}{3})$。
     $\sqrt{2}f(\frac{5\pi}{12}) = \sqrt{2} \cdot \cos 75^\circ \cdot g(\frac{5\pi}{12}) = \sqrt{2} \cdot \frac{\sqrt{6}-\sqrt{2}}{4} g(\frac{5\pi}{12}) = \frac{\sqrt{3}-1}{2} g(\frac{5\pi}{12})$。
     因为 $\frac{\pi}{3} < \frac{5\pi}{12}$ 且均在 $(1, \frac{\pi}{2})$，故 $g(\frac{\pi}{3}) < g(\frac{5\pi}{12})$。**正确**。
   - **C**：$\sqrt{2}f(\frac{\pi}{6}) = \frac{\sqrt{6}}{2}g(\frac{\pi}{6})$，$\sqrt{3}f(\frac{\pi}{4}) = \frac{\sqrt{6}}{2}g(\frac{\pi}{4})$。
     因为 $\frac{\pi}{6} < \frac{\pi}{4} < 1$，故 $g(\frac{\pi}{6}) > g(\frac{\pi}{4})$。**错误**。
   - **D**：$2f(\frac{\pi}{12}) = 2 \cdot \frac{\sqrt{6}+\sqrt{2}}{4} g(\frac{\pi}{12}) = \frac{\sqrt{6}+\sqrt{2}}{2} g(\frac{\pi}{12})$。
     $(\sqrt{3}+1)f(\frac{\pi}{4}) = (\sqrt{3}+1) \frac{\sqrt{2}}{2} g(\frac{\pi}{4}) = \frac{\sqrt{6}+\sqrt{2}}{2} g(\frac{\pi}{4})$。
     因为 $\frac{\pi}{12} < \frac{\pi}{4} < 1$，故 $g(\frac{\pi}{12}) > g(\frac{\pi}{4})$。**正确**。

**结论**：$\text{A, B, D}$

### 第 8 题：解析

**【元解析】**
不等式为 $\ln(x+1) f'(x) - \ln(x+1) f(x) + \frac{f(x)}{x+1} \ge 0$。
这是一种 $y' + P(x)y \ge 0$ 的形式。我们需要寻找积分因子 $\mu(x) = e^{\int P(x) dx}$。
将式子除以 $\ln(x+1)$ (假设 $x > 0$)：$f'(x) - f(x) + \frac{f(x)}{(x+1)\ln(x+1)} \ge 0$。
这里 $P(x) = \frac{1}{(x+1)\ln(x+1)} - 1$。
积分 $\int P(x)dx = \ln(\ln(x+1)) - x$。
积分因子 $\mu(x) = e^{\ln(\ln(x+1)) - x} = \ln(x+1) e^{-x}$。

**【常规解法】**
1. **构造辅助函数**：令 $h(x) = \ln(x+1) e^{-x} f(x)$。
2. **求导验证**：
   $h'(x) = \frac{1}{x+1} e^{-x} f(x) + \ln(x+1) [-e^{-x} f(x) + e^{-x} f'(x)] = e^{-x} [ \frac{f(x)}{x+1} + \ln(x+1)(f'(x) - f(x)) ]$。
   由题意知 $h'(x) \ge 0$，故 $h(x)$ 在 $(-1, \infty)$ 上单调递增。
3. **利用已知点**：$f(4) = \frac{e^4}{\ln 5} \implies h(4) = \ln(5) \cdot e^{-4} \cdot \frac{e^4}{\ln 5} = 1$。
4. **解不等式**：$\ln(x+3) f(x+2) \ge e^{x+2} \iff e^{-(x+2)} \ln(x+3) f(x+2) \ge 1 \iff h(x+2) \ge 1$。
   由于 $h(x)$ 递增且 $h(4)=1$，则 $x+2 \ge 4 \implies x \ge 2$。

**结论**：$\text{A}$

### 第 9 题：解析

**【元解析】**
$x\ln x \cdot f'(x) + f(x) > 0$。
观察 $\frac{d}{dx}(f(x) \ln x) = f'(x)\ln x + \frac{f(x)}{x}$。
将原式除以 $x$：$\ln x \cdot f'(x) + \frac{f(x)}{x} > 0$。
这直接构造出了 $h(x) = f(x) \ln x$ 的导数。

**【常规解法】**
1. **构造辅助函数**：令 $h(x) = f(x) \ln x$，则 $h'(x) = \ln x \cdot f'(x) + \frac{f(x)}{x} > 0$。
2. **单调性分析**：$h(x)$ 在 $(0, \infty)$ 上严格单调递增。
3. **特殊点判定**：$h(1) = f(1) \ln 1 = 0$。
   - 当 $x > 1$ 时，$h(x) > h(1) = 0 \implies f(x) \ln x > 0$。由于 $\ln x > 0$，则 $f(x) > 0$。
   - 当 $0 < x < 1$ 时，$h(x) < h(1) = 0 \implies f(x) \ln x < 0$。由于 $\ln x < 0$，则 $f(x) > 0$。
4. **验证结论**：对于所有 $x > 0$，$f(x) > 0$ 恒成立。

**结论**：$\text{D}$

### 第 10 题：解析

**【元解析】**
$f'(x) \ln(2x) + \frac{f(x)}{x} > 0$。
注意到 $\frac{d}{dx} \ln(2x) = \frac{1}{x}$。
这又是乘积法则的指纹：$\frac{d}{dx}[f(x) \ln(2x)] = f'(x) \ln(2x) + f(x) \cdot \frac{1}{x}$。

**【常规解法】**
1. **构造辅助函数**：令 $h(x) = f(x) \ln(2x)$，则 $h'(x) > 0$，故 $h(x)$ 在 $(0, \infty)$ 递增。
2. **判定符号**：$h(1/2) = f(1/2) \ln 1 = 0$。
   - $x > 1/2 \implies h(x) > 0 \implies f(x) \ln(2x) > 0 \implies f(x) > 0$ (因为 $\ln(2x)>0$)。
   - $0 < x < 1/2 \implies h(x) < 0 \implies f(x) \ln(2x) < 0 \implies f(x) > 0$ (因为 $\ln(2x)<0$)。
   - 综上，$x > 0$ 时 $f(x) > 0$。
3. **奇函数性质**：$f(x)$ 为奇函数 $\implies x < 0$ 时 $f(x) < 0$。
4. **解不等式**：$(x-2)f(x) < 0$。
   - 当 $x > 0$ 时，$f(x) > 0 \implies x-2 < 0 \implies 0 < x < 2$。
   - 当 $x < 0$ 时，$f(x) < 0 \implies x-2 > 0 \implies x > 2$ (无解)。
   - 当 $x=0$ 时，不等式不成立。

**结论**：$\text{B}$

### 第 11 题：解析

**【元解析】**
$f'(x) \ln x + \frac{f(x)}{x} < 0$。
同样构造 $h(x) = f(x) \ln x$，则 $h'(x) < 0$，故 $h(x)$ 在 $(0, \infty)$ 递减。

**【常规解法】**
1. **判定符号**：$h(1) = f(1) \ln 1 = 0$。
   - $x > 1 \implies h(x) < 0 \implies f(x) \ln x < 0 \implies f(x) < 0$ (因为 $\ln x > 0$)。
   - $0 < x < 1 \implies h(x) > 0 \implies f(x) \ln x > 0 \implies f(x) < 0$ (因为 $\ln x < 0$)。
   - 综上，$x > 0$ 时 $f(x) < 0$。
2. **奇函数性质**：$x < 0$ 时 $f(x) > 0$。
3. **解不等式**：$(x-1)f(x) < 0$。
   - 当 $x > 0$ 时，$f(x) < 0 \implies x-1 > 0 \implies x > 1$。
   - 当 $x < 0$ 时，$f(x) > 0 \implies x-1 < 0 \implies x < 1$ (恒成立)。
   - 综上，解集为 $(-\infty, 0) \cup (1, \infty)$。

**结论**：$\text{D}$

### 💡 总结与反思

#### 1. 认知模型：导数构造的“指纹识别”
当你看到 $f'(x) \cdot A(x) + f(x) \cdot B(x)$ 时，应立即启动以下检索：
- **乘积法则型**：检查是否 $B(x) = A'(x)$。若是，构造 $h(x) = f(x)A(x)$。
- **商法则型**：检查是否 $B(x) = -A'(x)$（或类似结构）。若是，构造 $h(x) = \frac{f(x)}{A(x)}$。
- **积分因子型**：若不满足上述简单关系，尝试除以 $A(x)$ 转化为 $f'(x) + \frac{B(x)}{A(x)}f(x) = 0$，构造 $h(x) = f(x) \cdot e^{\int \frac{B(x)}{A(x)}dx}$。

#### 2. 避坑指南
- **定义域与符号**：在判定 $f(x) \ln x > 0 \implies f(x) > 0$ 时，**必须**分区间讨论 $\ln x$ 的正负。
- **奇偶性迁移**：在处理定义域为 $\text{R}$ 的问题时，先用构造法解决 $x > 0$ 部分，再利用对称性镜像到 $x < 0$。

#### 3. 迁移场景
此类方法不仅用于选择题，在高考压轴题的第 2 问（证明不等式）或第 3 问（求参数范围）中，经常作为“辅助函数”构造的突破口。一旦识别出 $h'(x)$ 的符号，整个问题的维度就从“微分”降级为了“单调性比较”。

在高中数学压轴题或竞赛题中，看到 $f'(x)$ 和 $f(x)$ 混合出现的不等式，本质上是在考查**一阶线性微分方程**的解法。

如果你想在考场上**跳过繁琐的推导，直接秒杀构造函数**，你只需要掌握微积分中的一个核心工具：**积分因子（Integrating Factor）**。

---

### 核心理论：一阶线性结构秒杀法

绝大多数此类题目都可以写成以下标准形式：
$$a(x)f'(x) + b(x)f(x) \ge g(x)$$

#### 🚀 快速构造三步走：

**第一步：标准化（除以 $a(x)$）**
将 $f'(x)$ 的系数化为 $1$：
$$f'(x) + \frac{b(x)}{a(x)}f(x) \ge \frac{g(x)}{a(x)}$$
此时，我们关注项 $P(x) = \frac{b(x)}{a(x)}$。

**第二步：找“积分因子” $\mu(x)$**
积分因子的公式是：$\mu(x) = e^{\int P(x) dx}$。
**这个 $\mu(x)$ 就是你要构造的辅助函数中，乘在 $f(x)$ 前面的那个部分。**

**第三步：写出辅助函数 $h(x)$**
直接构造：
$$h(x) = \mu(x) \cdot f(x)$$
此时，原不等式等价于：
$$h'(x) \ge \mu(x) \cdot \frac{g(x)}{a(x)}$$

---

### 🛠️ 实战简化：常见结构的“直觉识别”

在实际考试中，你不需要每次都去算 $e^{\int P dx}$，因为出题人的套路非常固定。请直接记忆以下**指纹结构**：

#### 类型 1：乘积法则直觉（最简单）
**特征**：$b(x)$ 正好是 $a(x)$ 的导数 $\implies b(x) = a'(x)$。
- **形式**：$a(x)f'(x) + a'(x)f(x) \ge g(x)$
- **秒杀构造**：$h(x) = a(x) \cdot f(x)$
- **结果**：$h'(x) \ge g(x)$
- *对应题目*：第 9, 10, 11 题。例如 $\ln x \cdot f'(x) + \frac{1}{x} f(x)$，因为 $(\ln x)' = \frac{1}{x}$，直接构造 $h(x) = f(x) \ln x$。

#### 类型 2：商法则直觉（反向）
**特征**：$b(x)$ 符号相反，且满足 $b(x) = -a'(x)$。
- **形式**：$a(x)f'(x) - a'(x)f(x) \ge g(x)$
- **秒杀构造**：$h(x) = \frac{f(x)}{a(x)}$
- **结果**：$h'(x) \ge \frac{g(x)}{[a(x)]^2}$
- *对应题目*：第 7 题。$f'(x)\cos x + f(x)\sin x = \ln x$。这里 $a(x)=\cos x$，其导数是 $-\sin x$。原式是 $+\sin x$，符合 $-a'(x)$ 的形式。直接构造 $h(x) = \frac{f(x)}{\cos x}$。

#### 类型 3：指数-对数混合（进阶）
**特征**：$P(x)$ 包含 $\frac{1}{x \ln x}$ 或 $1$ 等项。
- **快速积分表**：
    - $\int \frac{1}{x} dx = \ln x \implies \mu(x) = x$
    - $\int \frac{1}{x \ln x} dx = \ln(\ln x) \implies \mu(x) = \ln x$
    - $\int 1 dx = x \implies \mu(x) = e^x$
    - $\int -1 dx = -x \implies \mu(x) = e^{-x}$
- *对应题目*：第 8 题。$P(x) = \frac{1}{(x+1)\ln(x+1)} - 1$。
    - $\int \frac{1}{(x+1)\ln(x+1)} dx = \ln(\ln(x+1))$
    - $\int -1 dx = -x$
    - $\mu(x) = e^{\ln(\ln(x+1)) - x} = \ln(x+1) \cdot e^{-x}$。
    - 直接构造 $h(x) = \ln(x+1)e^{-x}f(x)$。

---

### 📝 极速对比表（考场思维链）

| 看到结构 | 快速判定 $P(x)$ | 积分因子 $\mu(x)$ | 最终构造 $h(x)$ | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| $f' \cdot A + f \cdot A'$ | $\frac{A'}{A}$ | $A$ | $A \cdot f$ | 乘积法则 |
| $f' \cdot A - f \cdot A'$ | $-\frac{A'}{A}$ | $\frac{1}{A}$ | $\frac{f}{A}$ | 商法则 |
| $f' + f \cdot \frac{1}{x}$ | $\frac{1}{x}$ | $x$ | $x \cdot f$ | 经典线性 |
| $f' - f$ | $-1$ | $e^{-x}$ | $e^{-x} \cdot f$ | 经典线性 |
| $f' + \frac{f}{x \ln x}$ | $\frac{1}{x \ln x}$ | $\ln x$ | $(\ln x) \cdot f$ | 对数线性 |

### 💡 总结：如何最快？

1. **先看 $f'(x)$ 的系数 $a(x)$**。
2. **检查 $f(x)$ 的系数 $b(x)$ 是否是 $a(x)$ 的导数（或其相反数）** $\to$ 是 $\to$ 直接用乘积/商法则 $\to$ **结束**。
3. **如果不是 $\to$ 尝试除以 $a(x)$ $\to$ 看 $P(x)$ 能不能快速积分 $\to$ 结果放入 $e^{\int P dx}$ $\to$ 乘在 $f(x)$ 前面 $\to$ 结束**。

这种方法将“灵感构造”变成了“算法计算”，只要掌握积分因子的逻辑，任何复杂的导数构造题都只是简单的积分运算。
