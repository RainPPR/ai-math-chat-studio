### 【常规解法】

#### 第一步：分析圆的几何性质与 $|QF|$ 的计算
已知圆 $K$ 的中心为 $O_K\left(\dfrac{c}{3}, 0\right)$，半径 $r = \dfrac{b}{3}$。
由于 $PF$ 与圆相切于 $Q$，则 $O_K Q \perp PF$，故 $\triangle O_K Q F$ 是直角三角形 $\left(\angle O_K Q F = 90^\circ\right)$。
计算直角边 $O_K F$ 的长度：
$$|O_K F| = \left| c - \frac{c}{3} \right| = \frac{2c}{3}$$
根据勾股定理：
$$|QF|^2 = |O_K F|^2 - |O_K Q|^2 = \left(\frac{2c}{3}\right)^2 - \left(\frac{b}{3}\right)^2 = \frac{4c^2 - b^2}{9}$$
利用双曲线关系 $b^2 = c^2 - a^2$，代入得：
$$|QF|^2 = \frac{4c^2 - (c^2 - a^2)}{9} = \frac{3c^2 + a^2}{9} \implies |QF| = \frac{\sqrt{3c^2 + a^2}}{3}$$

#### 第二步：确定 $|PF|$ 的长度
已知 $|PQ| = 2|QF|$ 且 $Q$ 在线段 $PF$ 上，则：
$$|PF| = |PQ| + |QF| = 3|QF| = \sqrt{3c^2 + a^2}$$

#### 第三步：利用双曲线焦半径公式建立方程
设点 $P$ 的坐标为 $(x_0, y_0)$，由于 $P$ 在左支上，则 $x_0 \le -a$。
点 $P$ 到右焦点 $F(c, 0)$ 的距离（远焦半径）公式为：
$$|PF| = a - ex_0$$
我们需要将 $x_0$ 用 $a, c$ 表示。注意到直线 $PF$ 是从 $F$ 点出发与圆 $K$ 相切的射线。
设 $\angle Q F O_K = \alpha$，在 $\triangle O_K Q F$ 中：
$$\sin \alpha = \frac{O_K Q}{O_K F} = \frac{b/3}{2c/3} = \frac{b}{2c}$$
则 $\cos \alpha = \sqrt{1 - \sin^2 \alpha} = \frac{\sqrt{4c^2 - b^2}}{2c} = \frac{\sqrt{3c^2 + a^2}}{2c}$。
直线 $PF$ 与 $x$ 轴正方向的夹角 $\theta = \pi - \alpha$（或 $\pi + \alpha$），故 $\cos \theta = -\cos \alpha$。
根据极坐标形式的焦半径公式（以 $F$ 为极点）：
$$|PF| = \frac{b^2/a}{-1 - e \cos \theta} = \frac{b^2/a}{-1 + e \cos \alpha} = \frac{b^2/a}{-1 + \frac{c}{a} \cdot \frac{\sqrt{3c^2 + a^2}}{2c}} = \frac{b^2/a}{\frac{\sqrt{3c^2 + a^2}}{2a} - 1}$$
整理得：
$$|PF| = \frac{2b^2}{\sqrt{3c^2 + a^2} - 2a}$$

#### 第四步：求解离心率 $e$
联立两个 $|PF|$ 的表达式：
$$\sqrt{3c^2 + a^2} = \frac{2b^2}{\sqrt{3c^2 + a^2} - 2a}$$
令 $u = \sqrt{3c^2 + a^2}$，则有 $u(u - 2a) = 2b^2$。
$$u^2 - 2au = 2(c^2 - a^2)$$
$$3c^2 + a^2 - 2a\sqrt{3c^2 + a^2} = 2c^2 - 2a^2$$
$$c^2 + 3a^2 = 2a\sqrt{3c^2 + a^2}$$
两边平方：
$$(c^2 + 3a^2)^2 = 4a^2(3c^2 + a^2)$$
$$c^4 + 6a^2 c^2 + 9a^4 = 12a^2 c^2 + 4a^4$$
$$c^4 - 6a^2 c^2 + 5a^4 = 0$$
除以 $a^4$ 并令 $e^2 = \left(\frac{c}{a}\right)^2$：
$$(e^2)^2 - 6e^2 + 5 = 0 \implies (e^2 - 1)(e^2 - 5) = 0$$
由于双曲线离心率 $e > 1$，故 $e^2 = 5$，解得 $e = \sqrt{5}$。

    *   $\cos \alpha = \frac{4a}{2\sqrt{5}a} = \frac{2}{\sqrt{5}}$。

## 一、 椭圆 (Ellipse)
**定义：** 到两个定点 $F_1, F_2$ 的距离之和等于常数 $2a$ ($2a > |F_1F_2|$) 的点集。

### 1. 标准方程与基础量
*   **标准方程**：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1 \ (a > b > 0)$
*   **基本关系式**：$a^2 = b^2 + c^2$

### 2. 关键点与线
*   **顶点**：$(\pm a, 0), (0, \pm b)$
*   **焦点**：$(\pm c, 0)$
*   **长轴/短轴**：$2a, 2b$

### 3. 焦半径公式 (Focal Radius)
*   **第一定义**：$|PF_1| + |PF_2| = 2a$

### 1. 标准方程与基础量
*   **标准方程**：$\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1 \ (a, b > 0)$
