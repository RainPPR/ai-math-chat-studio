### 【常规解法：分段讨论法】

由于 $\ln x$ 与 $x-1$ 在 $x=1$ 两侧符号相反，必须分区间讨论，以确保不等号方向的正确性。

#### 路径 1：$x > 1$ 时
此时 $\ln x > 0$ 且 $x-1 > 0$，不等式两边均为正。
我们需要证明：
$$\frac{1}{\ln x} < \frac{x}{x-1} \iff \ln x > \frac{x-1}{x} = 1 - \frac{1}{x}$$
构造辅助函数 $\phi(x) = \ln x - \left( 1 - \frac{1}{x} \right)$，则：
$$\phi'(x) = \frac{1}{x} - \frac{1}{x^2} = \frac{x-1}{x^2}$$
当 $x > 1$ 时，$\phi'(x) > 0$，$\phi(x)$ 在 $(1, +\infty)$ 上单调递增。
又因为 $\phi(1) = \ln 1 - (1 - 1) = 0$，
所以当 $x > 1$ 时，$\phi(x) > 0$，即 $\ln x > 1 - \frac{1}{x}$ 成立。

#### 路径 2：$0 < x < 1$ 时
此时 $\ln x < 0$ 且 $x-1 < 0$。
原不等式 $\frac{x}{\ln x} < \frac{x^2}{x-1}$，两边同时除以 $x$（$x > 0$）：
$$\frac{1}{\ln x} < \frac{x}{x-1}$$
注意：此时 $\ln x$ 和 $x-1$ 均为负数。我们将不等式移项得：
$$\frac{1}{\ln x} - \frac{x}{x-1} < 0 \implies \frac{(x-1) - x\ln x}{(x-1)\ln x} < 0$$
由于分母 $(x-1)\ln x > 0$（负 $\times$ 负 $=$ 正），只需证明分子 $\psi(x) = x-1 - x\ln x < 0$。
对 $\psi(x)$ 求导：
$$\psi'(x) = 1 - (\ln x + x \cdot \frac{1}{x}) = 1 - \ln x - 1 = -\ln x$$
当 $0 < x < 1$ 时，$\ln x < 0 \implies \psi'(x) > 0$。
$\psi(x)$ 在 $(0, 1)$ 上单调递增，故 $\psi(x) < \psi(1) = 1-1-0 = 0$。
因此，当 $0 < x < 1$ 时，不等式同样成立。

**综上所述，在定义域内 $f(x) < \frac{x^2}{x-1}$ 恒成立。**

### 【进阶解法：高维变换与对偶】

如果我们在考场上希望快速秒杀，可以利用**变量代换**将问题统一。

**核心技巧：倒数对称变换**
令 $x = \frac{1}{t}$。
当 $x > 1$ 时，$0 < t < 1$；当 $0 < x < 1$ 时，$t > 1$。
将原不等式 $\frac{1}{\ln x} < \frac{x}{x-1}$ 转换为关于 $t$ 的式子：
$$\frac{1}{\ln(1/t)} < \frac{1/t}{1/t - 1} \implies \frac{1}{-\ln t} < \frac{1}{1-t} \implies -\frac{1}{\ln t} < \frac{1}{1-t}$$
整理得：
$$\frac{1}{\ln t} > \frac{1}{t-1} \implies \ln t < t-1 \quad (\text{需考虑 } t \text{ 的范围})$$

*   若 $t > 1$（对应原题 $0 < x < 1$），$\ln t$ 和 $t-1$ 均为正，$\ln t < t-1$ 是经典结论。
*   若 $0 < t < 1$（对应原题 $x > 1$），$\ln t$ 和 $t-1$ 均为负，$\frac{1}{\ln t} > \frac{1}{t-1} \iff \ln t < t-1$（因为两边均为负，取倒数后不等号方向改变，再乘负数再次改变，最终还原为 $\ln t < t-1$）。

**结论**：无论 $x$ 在哪个区间，原不等式最终都等价于 $\ln t < t-1$（其中 $t=1/x$ 或 $t=x$ 的某种形式）。这揭示了该题的**对称美感**：它实际上是同一个基本不等式在原像和镜像空间中的同步体现。

$$n > \frac{f(x)}{\ln(1-x^2)}$$
