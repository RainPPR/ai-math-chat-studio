### 维度一：基础定义与基本恒等式（底层基石）

这是所有推导的起点，必须达到肌肉记忆的程度。

#### 1. 基础定义与倒数关系
- $\tan x = \frac{\sin x}{\cos x}$
- $\cot x = \frac{\cos x}{\sin x} = \frac{1}{\tan x}$
- $\sec x = \frac{1}{\cos x}$
- $\csc x = \frac{1}{\sin x}$

#### 2. 勾股恒等式（Pythagorean Identities）
这是最常用的**平方转换**工具：
- $\sin^2 x + \cos^2 x = 1$
- $1 + \tan^2 x = \sec^2 x$
- $1 + \cot^2 x = \csc^2 x$

#### 3. 对称性与周期性
- **奇偶性**：$\sin(-x) = -\sin x, \tan(-x) = -\tan x, \cot(-x) = -\cot x$；$\cos(-x) = \cos x$（偶函数）。
- **周期性**：$\sin(x + 2k\pi) = \sin x, \cos(x + 2k\pi) = \cos x, \tan(x + k\pi) = \tan x$ （其中 $k \in \mathbb{Z}$）。
- **诱导公式（核心逻辑：$\frac{\pi}{2}$ 变换 $\rightarrow$ 函数名变；$\pi$ 变换 $\rightarrow$ 函数名不变）**：
    - $\sin(\frac{\pi}{2} - x) = \cos x$
    - $\cos(\frac{\pi}{2} - x) = \sin x$
    - $\tan(\frac{\pi}{2} - x) = \cot x$
    - $\sin(\pi - x) = \sin x$
    - $\cos(\pi - x) = -\cos x$

### 维度二：和差化积与积化和差（结构变换）

这是处理三角函数方程和不等式的核心工具，本质是**“将乘法结构转化为加法结构”**或反之。

#### 1. 两角和差公式（母公式）
$$\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta$$
$$\cos(\alpha \pm \beta) = \cos \alpha \cos \beta \mp \sin \alpha \sin \beta$$
$$\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}$$

#### 2. 两倍角公式（重点结论）
- $\sin 2\alpha = 2 \sin \alpha \cos \alpha$
- $\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$
- $\tan 2\alpha = \frac{2 \tan \alpha}{1 - \tan^2 \alpha}$

#### 3. 半角公式（降次武器）
在积分或处理平方项时极其高效：
- $\sin^2 \frac{\alpha}{2} = \frac{1 - \cos \alpha}{2}$
- $\cos^2 \frac{\alpha}{2} = \frac{1 + \cos \alpha}{2}$
- $\tan \frac{\alpha}{2} = \frac{1 - \cos \alpha}{\sin \alpha} = \frac{\sin \alpha}{1 + \cos \alpha}$

#### 4. 和差化积（解决根分布、零点问题）
$$\sin \alpha + \sin \beta = 2 \sin \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2}$$
$$\sin \alpha - \sin \beta = 2 \cos \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2}$$
$$\cos \alpha + \cos \beta = 2 \cos \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2}$$
$$\cos \alpha - \cos \beta = -2 \sin \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2}$$

#### 5. 积化和差（解决积分、乘积求和问题）
$$\sin \alpha \cos \beta = \frac{1}{2} [\sin(\alpha + \beta) + \sin(\alpha - \beta)]$$
$$\cos \alpha \cos \beta = \frac{1}{2} [\cos(\alpha + \beta) + \cos(\alpha - \beta)]$$
$$\sin \alpha \sin \beta = -\frac{1}{2} [\cos(\alpha + \beta) - \cos(\alpha - \beta)]$$

### 维度三：二级结论（高效解题快捷路径）

这些结论是上述公式的**高频组合变形**，在考场上能节省大量时间。

#### 1. 辅助角公式（最强统一形式）
对于 $a \sin x + b \cos x$ 结构，统一为单一三角函数：
$$a \sin x + b \cos x = \sqrt{a^2 + b^2} \sin(x + \varphi), \quad \tan \varphi = \frac{b}{a}$$
**特殊情况**：$\sin x \pm \cos x = \sqrt{2} \sin(x \pm \frac{\pi}{4}) = \sqrt{2} \cos(x \mp \frac{\pi}{4})$。

#### 2. 万能公式（Weierstrass Substitution）
令 $t = \tan \frac{x}{2}$，则所有三角函数均可表示为 $t$ 的有理分式（竞赛/高阶微积分神技）：
$$\sin x = \frac{2t}{1+t^2}, \quad \cos x = \frac{1-t^2}{1+t^2}, \quad \tan x = \frac{2t}{1-t^2}$$

#### 3. 三倍角公式（特定结构识别）
- $\sin 3x = 3 \sin x - 4 \sin^3 x$
- $\cos 3x = 4 \cos^3 x - 3 \cos x$
- $\tan 3x = \frac{3 \tan x - \tan^3 x}{1 - 3 \tan^2 x}$

#### 4. 常用特殊值组合
- $\sin 15^\circ = \frac{\sqrt{6}-\sqrt{2}}{4}$
- $\cos 15^\circ = \frac{\sqrt{6}+\sqrt{2}}{4}$
- $\sin 18^\circ = \frac{\sqrt{5}-1}{4}$
- $\cos 36^\circ = \frac{\sqrt{5}+1}{4}$

### 维度四：三级结论与竞赛级恒等式（顶层视角）

这些结论通常出现在压轴题或数学竞赛中，涉及多项式与三角函数的深度结合。

#### 1. 三角函数之和的乘积形式（$A+B+C = \pi$ 时）
若 $\alpha + \beta + \gamma = \pi$（如三角形内角）：
- $\tan \alpha + \tan \beta + \tan \gamma = \tan \alpha \tan \beta \tan \gamma$
- $\sin 2\alpha + \sin 2\beta + \sin 2\gamma = 4 \sin \alpha \sin \beta \sin \gamma$
- $\cos^2 \alpha + \cos^2 \beta + \cos^2 \gamma = 1 - 2 \cos \alpha \cos \beta \cos \gamma$

#### 2. 等差数列角度的乘积（Dirichlet 核相关）
$$\sum_{k=1}^{n} \sin(kx) = \frac{\sin \frac{nx}{2} \sin \frac{(n+1)x}{2}}{\sin \frac{x}{2}}$$
$$\sum_{k=1}^{n} \cos(kx) = \frac{\sin \frac{nx}{2} \cos \frac{(n+1)x}{2}}{\sin \frac{x}{2}}$$

#### 3. 乘积链公式（$\cos$ 翻倍链）
$$\cos x \cdot \cos 2x \cdot \cos 4x \cdot \dots \cdot \cos 2^{n-1}x = \frac{\sin(2^n x)}{2^n \sin x}$$

### 维度五：几何关联（解析几何与三角形）

三角函数在几何中的具象化。

#### 1. 正弦定理与余弦定理
- **正弦定理**：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$ （$R$ 为外接圆半径）。
- **余弦定理**：$a^2 = b^2 + c^2 - 2bc \cos A$ $\rightarrow$ $\cos A = \frac{b^2 + c^2 - a^2}{2bc}$。

#### 2. 面积公式
- $S = \frac{1}{2}ab \sin C$
- $S = \frac{abc}{4R} = 2R^2 \sin A \sin B \sin C$
- $S = rs$ （$r$ 为内切圆半径，$s$ 为半周长 $\frac{a+b+c}{2}$）。

### 维度六：元认知复盘——如何选择公式？（解题逻辑图）

面对题目，不要盲目尝试，请遵循以下**“特征识别 $\rightarrow$ 路径选择”**逻辑：

1. **看到 $\sin^2 x$ 或 $\cos^2 x$** $\rightarrow$ 考虑 **降次公式** $\rightarrow$ 转化为 $\cos 2x$。
2. **看到 $a \sin x + b \cos x$** $\rightarrow$ 立即使用 **辅助角公式** $\rightarrow$ 转化为单函数。
3. **看到 $\sin \alpha \pm \sin \beta$** $\rightarrow$ 考虑 **和差化积** $\rightarrow$ 转化为乘积（便于找零点）。
4. **看到 $\cos \alpha \cos \beta$** $\rightarrow$ 考虑 **积化和差** $\rightarrow$ 转化为加法（便于抵消）。
5. **看到 $\tan \frac{x}{2}$ 或需要消灭分母** $\rightarrow$ 尝试 **万能公式 $t$-代换**。
6. **看到 $A+B+C=\pi$** $\rightarrow$ 检索 **维度四** 的三角形特有恒等式。
7. **看到 $\tan(A+B)$ 结构但只有 $\tan A, \tan B$** $\rightarrow$ 直接套用 **和差公式**。

**【最终提醒】**
三角函数的精髓在于**“对偶”**。$\sin$ 和 $\cos$ 互为 $\frac{\pi}{2}$ 的移位，$\tan$ 是两者的比值。在复杂的变形中，如果你卡住了，试着将所有的函数全部统一为 $\sin$ 和 $\cos$，通常能看到破局点。
