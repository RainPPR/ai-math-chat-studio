### 一、 前提与推理：分子式拆解与核心结构确立

**前提**：已知分子式为 $\text{C}_6\text{H}_6\text{N}_2\text{Cl}_2$，且限定条件为“含有苯环和两个 $-\text{NH}_2$”。

**推理**：
1. **不饱和度分析**：计算该分子的不饱和度（$\Omega$）。卤素视为氢，氮元素视为碳，则分子式等价为 $\text{C}_8\text{H}_8$。根据公式 $\Omega = \frac{2 \times 8 + 2 - 8}{2} = 5$？这里我们需要采用更精确的算法：$\Omega = \text{C} + 1 - \frac{\text{H}}{2} + \frac{\text{N}}{2} - \frac{\text{X}}{2} = 6 + 1 - \frac{6}{2} + \frac{2}{2} - \frac{2}{2} = 6 + 1 - 3 + 1 - 1 = 4$。分子整体不饱和度为 $4$。苯环本身含有 $3$ 个双键和 $1$ 个环，其不饱和度恰好为 $4$。这表明，**分子中除苯环外，不再存在任何额外的环或双键**。
2. **碳骨架归属**：分子中仅有 $6$ 个碳原子，既然必定存在苯环，则所有的碳原子均参与构成苯环。这意味着，**所有取代基均不含碳原子**。
3. **取代基拆解**：分子中明确存在两个完整的 $-\text{NH}_2$ 基团，这消耗了 $2$ 个 N 原子和 $4$ 个 H 原子。剩余的原子组成为：$2$ 个 Cl 原子和 $2$ 个 H 原子。由于题目强调必须含有完整的 $-\text{NH}_2$，这 $2$ 个 Cl 和 $2$ 个 H 不能取代氨基上的氢（否则会形成 $-\text{N}\text{H}\text{Cl}$ 等，违背“两个 $-\text{NH}_2$”的题意）。因此，这 $2$ 个 Cl 和 $2$ 个 H 只能作为一价基团直接连接在苯环上。
4. **苯环取代状态**：苯环共有 $6$ 个可被取代的位置。现在我们需要在苯环上安置 $2$ 个 $-\text{NH}_2$、$2$ 个 $-\text{Cl}$ 以及保留 $2$ 个 $-\text{H}$。这本质上是一个**四取代苯**的排列问题。

**结论**：该分子必定为**含有两个氨基和两个氯原子的四取代苯**。

### 二、 推理与演绎：基于对称性的系统枚举

为了准确计数，我们将采用**“定一议二”结合局部对称群分析**的方法。我们将苯环的 $6$ 个位置编号为 $1, 2, 3, 4, 5, 6$。

由于存在两个相同的 $-\text{NH}_2$，我们首先固定这两个 $-\text{NH}_2$ 的相对位置，分为邻位、间位、对位三大类。随后，在剩余的 $4$ 个位置中安置 $2$ 个 $-\text{Cl}$ 和 $2$ 个 $-\text{H}$（只需确定 $-\text{Cl}$ 的位置，$-\text{H}$ 自然填补剩余空位）。在此过程中，必须利用分子的**对称轴**来剔除重复的排列。

#### 情形一：两个 $-\text{NH}_2$ 处于邻位（固定于 $1, 2$ 位）
此时，剩余的空位为 $3, 4, 5, 6$。我们需要在其中选择 $2$ 个位置放置 $-\text{Cl}$。
此时分子具有一条对称轴，该对称轴穿过 $1-2$ 键的中点和 $4-5$ 键的中点。其对称映射关系为：$3 \leftrightarrow 6$，$4 \leftrightarrow 5$。
我们在 $\{3, 4, 5, 6\}$ 中选 $2$ 个位置放 $-\text{Cl}$，共有 $\text{C}_4^2 = 6$ 种组合，剔除对称重复后：
1. Cl 在 $3, 4$ 位 $\leftrightarrow$ Cl 在 $6, 5$（即 $5, 6$）位 $\rightarrow$ **计为 $1$ 种**。
2. Cl 在 $3, 5$ 位 $\leftrightarrow$ Cl 在 $6, 4$（即 $4, 6$）位 $\rightarrow$ **计为 $1$ 种**。
3. Cl 在 $3, 6$ 位 $\rightarrow$ 该组合经对称轴映射后仍为 $3, 6$ 位（自对称） $\rightarrow$ **计为 $1$ 种**。
4. Cl 在 $4, 5$ 位 $\rightarrow$ 该组合经对称轴映射后仍为 $4, 5$ 位（自对称） $\rightarrow$ **计为 $1$ 种**。

因此，邻位 $-\text{NH}_2$ 的情形共产生 **$4$ 种**同分异构体。

#### 情形二：两个 $-\text{NH}_2$ 处于间位（固定于 $1, 3$ 位）
此时，剩余的空位为 $2, 4, 5, 6$。在其中选择 $2$ 个位置放置 $-\text{Cl}$。
此时分子具有一条对称轴，穿过顶点 $2$ 和顶点 $5$。其对称映射关系为：$1 \leftrightarrow 3$（$-\text{NH}_2$ 互换），$4 \leftrightarrow 6$，而 $2$ 和 $5$ 分别在轴上。
我们在 $\{2, 4, 5, 6\}$ 中选 $2$ 个位置放 $-\text{Cl}$，共有 $\text{C}_4^2 = 6$ 种组合，剔除对称重复后：
1. Cl 在 $2, 4$ 位 $\leftrightarrow$ Cl 在 $2, 6$ 位 $\rightarrow$ **计为 $1$ 种**。
2. Cl 在 $2, 5$ 位 $\rightarrow$ 映射后仍为 $2, 5$ 位（自对称） $\rightarrow$ **计为 $1$ 种**。
3. Cl 在 $4, 5$ 位 $\leftrightarrow$ Cl 在 $6, 5$（即 $5, 6$）位 $\rightarrow$ **计为 $1$ 种**。
4. Cl 在 $4, 6$ 位 $\rightarrow$ 映射后仍为 $4, 6$ 位（自对称） $\rightarrow$ **计为 $1$ 种**。

因此，间位 $-\text{NH}_2$ 的情形共产生 **$4$ 种**同分异构体。

#### 情形三：两个 $-\text{NH}_2$ 处于对位（固定于 $1, 4$ 位）
此时，剩余的空位为 $2, 3, 5, 6$。在其中选择 $2$ 个位置放置 $-\text{Cl}$。
此时分子的局部对称群阶数升高（属于 $\text{D}_{2\text{h}}$ 对称性），有多个对称操作能保持 $1, 4$ 位的 $-\text{NH}_2$ 位置不变：
- 对称轴 1：穿过顶点 $1$ 和 $4$，映射为 $2 \leftrightarrow 6, 3 \leftrightarrow 5$。
- 对称轴 2：穿过 $2-3$ 键中点和 $5-6$ 键中点，映射为 $2 \leftrightarrow 3, 5 \leftrightarrow 6$。
- 旋转操作：以环中心为轴旋转 $180^\circ$，映射为 $2 \leftrightarrow 5, 3 \leftrightarrow 6$。

我们在 $\{2, 3, 5, 6\}$ 中选 $2$ 个位置放 $-\text{Cl}$，理论上有 $\text{C}_4^2 = 6$ 种组合。在更高阶的对称群作用下，我们需严格甄别等价轨道：
1. Cl 在 $2, 3$ 位 $\xrightarrow{\text{轴1映射}}$ Cl 在 $6, 5$ 位 $\xrightarrow{\text{轴2映射}}$ Cl 在 $5, 6$ 位。这四个位置构成一个完整的等价轨道。 $\rightarrow$ **计为 $1$ 种**。
2. Cl 在 $2, 5$ 位 $\xrightarrow{\text{轴1映射}}$ Cl 在 $6, 3$ 位（即 $3, 6$ 位）。且 $2, 5$ 经轴 $1$ 映射、$180^\circ$ 旋转映射均互为等价。 $\rightarrow$ **计为 $1$ 种**。
3. Cl 在 $2, 6$ 位 $\xrightarrow{180^\circ \text{旋转}}$ Cl 在 $5, 3$ 位（即 $3, 5$ 位）。**（关键点：由于 $180^\circ$ 旋转对称性的存在，Cl 在 $2, 6$ 位与 Cl 在 $3, 5$ 位是完全等价的同一种结构，绝不可重复计数）** $\rightarrow$ **计为 $1$ 种**。

因此，对位 $-\text{NH}_2$ 的情形仅产生 **$3$ 种**同分异构体。

### 三、 最终结论

经过严密的对称群分析等价轨道剔除，我们将所有有效且互不重复的结构进行汇总：
- 邻位 $-\text{NH}_2$ 产生：$4$ 种
- 间位 $-\text{NH}_2$ 产生：$4$ 种
- 对位 $-\text{NH}_2$ 产生：$3$ 种

**最终结论**：含有苯环和两个 $-\text{NH}_2$ 的 $\text{C}_6\text{H}_6\text{N}_2\text{Cl}_2$ 的同分异构体共有 **$11$ 种**。在高考及竞赛的实战解题中，最容易发生的思维陷阱便是在对位 $-\text{NH}_2$ 时遗漏了 $180^\circ$ 旋转等价性，从而误判为 $12$ 种。只有通过引入多对称轴校验，才能确保逻辑链条的万无一失。

### 一、 前提：构建数学模型与对称群

在有机化学中，同分异构体的本质是**分子在三维空间中的不同拓扑排布**。由于苯环具有高度的对称性，许多在平面上看似不同的排列，实际上通过旋转或翻转可以完全重合，属于同一种异构体。

**1. 集合与染色映射**
我们将苯环上的 $6$ 个碳原子位置看作一个集合 $X = \{1, 2, 3, 4, 5, 6\}$。
根据前文的推导，我们需要在 $X$ 上安置 $2$ 个 $-\text{NH}_2$、$2$ 个 $-\text{Cl}$ 和 $2$ 个 $-\text{H}$。这在数学上等价于：**用三种颜色（分别记为 $a$、$b$、$c$）对集合 $X$ 的 $6$ 个位置进行染色，要求每种颜色恰好使用 $2$ 次。**

**2. 构建作用群 $G$**
苯环在自由空间中的对称操作构成了一个二面体群，记为 $D_6$。该群包含 $12$ 个群元素，分为三类：
- **恒等元 $e$**：保持原状不操作（$1$ 种）。
- **旋转操作 $r$**：绕环中心顺时针旋转 $60^\circ$、$120^\circ$、$180^\circ$、$240^\circ$、$300^\circ$（共 $5$ 种）。
- **翻转操作 $f$**：在三维空间中沿特定轴翻转。分为过对角的对称轴（$3$ 种）和过对边中点的对称轴（$3$ 种），共 $6$ 种。

因此，群 $G$ 的阶数 $|G| = 12$。我们的目标是求出在群 $G$ 作用下，不同染色方案的轨道数，即同分异构体的种类数。

### 二、 推理：波利亚计数定理的严密展开

波利亚计数定理的核心在于构建**轮换指标**。对于群 $G$ 中的每一个元素 $g$，它作用在 $6$ 个位置上会产生若干个**轮换**。如果一个轮换的长度为 $k$，则该轮换内的所有位置必须染上同一种颜色，才能在该对称操作下保持不变。

我们令 $x_k$ 表示长度为 $k$ 的轮换，逐一分析 $D_6$ 群的 $12$ 个元素：

**1. 恒等元 $e$**
- **操作**：不动。$6$ 个位置各自独立，形成 $6$ 个长度为 $1$ 的轮换。
- **轮换结构**：$x_1^6$
- **元素个数**：$1$ 个

**2. 旋转 $60^\circ$ 与 $300^\circ$**
- **操作**：所有位置发生循环平移，$1 \rightarrow 2 \rightarrow 3 \rightarrow 4 \rightarrow 5 \rightarrow 6 \rightarrow 1$。形成 $1$ 个长度为 $6$ 的轮换。
- **轮换结构**：$x_6^1$
- **元素个数**：$2$ 个

**3. 旋转 $120^\circ$ 与 $240^\circ$**
- **操作**：位置发生跳跃。$1 \rightarrow 3 \rightarrow 5 \rightarrow 1$ 且 $2 \rightarrow 4 \rightarrow 6 \rightarrow 2$。形成 $2$ 个长度为 $3$ 的轮换。
- **轮换结构**：$x_3^2$
- **元素个数**：$2$ 个

**4. 旋转 $180^\circ$**
- **操作**：对角互换。$1 \rightarrow 4 \rightarrow 1$，$2 \rightarrow 5 \rightarrow 2$，$3 \rightarrow 6 \rightarrow 3$。形成 $3$ 个长度为 $2$ 的轮换。
- **轮换结构**：$x_2^3$
- **元素个数**：$1$ 个

**5. 过对角翻转（如穿过 $1$ 和 $4$ 位）**
- **操作**：$1$ 和 $4$ 不动，$2 \leftrightarrow 6$，$3 \leftrightarrow 5$。形成 $2$ 个长度为 $1$ 的轮换和 $2$ 个长度为 $2$ 的轮换。
- **轮换结构**：$x_1^2 x_2^2$
- **元素个数**：$3$ 个（共有 $3$ 条对角线）

**6. 过对边中点翻转（如穿过 $1-2$ 键和 $4-5$ 键的中点）**
- **操作**：$1 \leftrightarrow 2$，$3 \leftrightarrow 6$，$4 \leftrightarrow 5$。形成 $3$ 个长度为 $2$ 的轮换。
- **轮换结构**：$x_2^3$
- **元素个数**：$3$ 个（共有 $3$ 对对边）

**7. 构建轮换指标多项式 $Z(D_6)$**
将上述所有元素的结构代入，并对群阶数 $12$ 取平均，得到轮换指标：
$$ Z(D_6) = \frac{1}{12} \left( x_1^6 + 2x_6^1 + 2x_3^2 + x_2^3 + 3x_1^2 x_2^2 + 3x_2^3 \right) $$
合并同类项得到：
$$ Z(D_6) = \frac{1}{12} \left( x_1^6 + 2x_6^1 + 2x_3^2 + 4x_2^3 + 3x_1^2 x_2^2 \right) $$

**8. 映射生成函数并提取系数**
根据波利亚计数定理，我们将 $x_k$ 替换为颜色的生成函数 $a^k + b^k + c^k$，其中 $a$ 代表 $-\text{NH}_2$，$b$ 代表 $-\text{Cl}$，$c$ 代表 $-\text{H}$。
多项式 $F(a,b,c)$ 将包含所有可能的染色方案。我们要求解的是每种基团恰好出现 $2$ 次，即多项式中 $a^2 b^2 c^2$ 项的系数。

$$ F(a,b,c) = \frac{1}{12} \left[ (a+b+c)^6 + 2(a^6+b^6+c^6) + 2(a^3+b^3+c^3)^2 + 4(a^2+b^2+c^2)^3 + 3(a+b+c)^2(a^2+b^2+c^2)^2 \right] $$

我们逐一计算各项中 $a^2 b^2 c^2$ 的系数：

- **第一项 $(a+b+c)^6$**：多项式展开，求 $a^2 b^2 c^2$ 系数。根据多项式定理，系数为 $\frac{6!}{2!2!2!} = \frac{720}{8} = \mathbf{90}$。
- **第二项 $2(a^6+b^6+c^6)$**：该项只存在 $a^6$、$b^6$、$c^6$，不可能出现 $a^2 b^2 c^2$ 项。系数为 $\mathbf{0}$。
- **第三项 $2(a^3+b^3+c^3)^2$**：展开后存在 $a^3 a^3 = a^6$ 等项，若要出现 $a^2$ 是不可能的（只有 $a^3$ 的整数倍）。系数为 $\mathbf{0}$。
- **第四项 $4(a^2+b^2+c^2)^3$**：要得到 $a^2 b^2 c^2$，必须从三个括号中分别挑出 $a^2$、$b^2$、$c^2$，其全排列数为 $3! = 6$。因此系数为 $4 \times 6 = \mathbf{24}$。
- **第五项 $3(a+b+c)^2(a^2+b^2+c^2)^2$**：前一项需提供 $a^2$、$b^2$ 或 $c^2$ 中的一个，例如 $a^2$；后一项需提供剩下的 $b^2 c^2$。计算逻辑为：从 $(a+b+c)^2$ 中取出 $a^2$ 系数为 $1$，从 $(a^2+b^2+c^2)^2$ 中取出 $b^2 c^2$ 系数为 $2$。考虑 $a, b, c$ 的全排列，总系数为 $3! \times 1 \times 2 = 12$。因此该项系数为 $3 \times 12 = \mathbf{18}$。

**9. Burnside 引理求和与轨道数计算**
将所有提取的系数相加，并除以群 $G$ 的阶数 $12$：
$$ \text{轨道数} = \frac{1}{12} (90 + 0 + 0 + 24 + 18) = \frac{132}{12} = 11 $$

### 三、 结论

通过抽象代数中**波利亚计数定理**的严密演算，我们直接得出了 $a^2 b^2 c^2$ 项的系数为 $11$。

**最终结论**：含有苯环和两个 $-\text{NH}_2$ 的 $\text{C}_6\text{H}_6\text{N}_2\text{Cl}_2$ 的同分异构体共有 **$11$ 种**。
