### 【元解析与特征挖掘】

面对该题，我们首先需要对 $f(x)$ 的“指纹”特征进行深度挖掘：
1.  **结构分量识别**：
    *   $f(x) = f(-x)$ $\implies$ 偶函数。
    *   $f(x) + f(2-x) = 0 \implies f(2-x) = -f(x)$。结合偶函数得 $f(2+x) = -f(-x) = -f(x)$。

2.  **算子特征分析**：
    *   $f'(x) = \frac{\pi}{2} f(x+1)$。这是一个典型的**差分-微分方程**。

    *   $f(x)$ 在 $[0,2]$ 单调递减，$f(1/2) = \frac{\sqrt{2}}{2}$， $f(0) < \sqrt{2}$。这些条件用于锁定系数 $\text{Amplitude}$ 和相位 $\text{Phase}$。

### 【常规解法】

#### 第一阶段：确定 $f(x)$ 的解析式
由于 $f(x)$ 是周期为 4 的偶函数且满足 $f(x+2) = -f(x)$，我们可以尝试构造形式为 $f(x) = a \cos\left( \frac{\pi}{2} x \right)$ 的函数。

**验证条件**：
1.  **对称性**：$\cos\left( \frac{\pi}{2}(-x) \right) = \cos\left( \frac{\pi}{2} x \right)$ 且 $\cos\left( \frac{\pi}{2}(2-x) \right) = \cos\left( \pi - \frac{\pi}{2} x \right) = -\cos\left( \frac{\pi}{2} x \right)$。满足。
2.  **导数关系**：
    $$\text{左边 } f'(x) = -a \cdot \frac{\pi}{2} \sin\left( \frac{\pi}{2} x \right)$$
    $$\text{右边 } \frac{\pi}{2} f(x+1) = \frac{\pi}{2} a \cos\left( \frac{\pi}{2} x + \frac{\pi}{2} \right) = -\frac{\pi}{2} a \sin\left( \frac{\pi}{2} x \right)$$
    两者相等，满足。
3.  **参数确定**：
    由 $f\left( \frac{1}{2} \right) = a \cos\left( \frac{\pi}{4} \right) = a \cdot \frac{\sqrt{2}}{2} = \frac{\sqrt{2}}{2} \implies a = 1$。
    此时 $f(0) = 1 < \sqrt{2}$，且 $\cos\left( \frac{\pi}{2} x \right)$ 在 $[0,2]$ 上单调递减。所有条件均成立。
    **结论**：$f(x) = \cos\left( \frac{\pi}{2} x \right)$。

#### 第二阶段：求解 $F(x)$ 的最大值
代入 $f(x)$，得：
$$F(x) = 3\cos\left( \frac{\pi}{2} x \right) - \cos\left( \frac{3\pi}{2} x \right)$$
利用三倍角公式 $\cos 3\theta = 4\cos^3 \theta - 3\cos \theta$，令 $\theta = \frac{\pi}{2} x$：
$$F(x) = 3\cos \theta - (4\cos^3 \theta - 3\cos \theta) = 6\cos \theta - 4\cos^3 \theta$$
设 $t = \cos \theta, t \in [-1, 1]$，构造函数 $g(t) = -4t^3 + 6t$。
求导得 $g'(t) = -12t^2 + 6$，令 $g'(t) = 0 \implies t = \pm \frac{\sqrt{2}}{2}$。

*   $g(1) = 2, \quad g(-1) = -2$
*   $g\left( \frac{\sqrt{2}}{2} \right) = -4\left( \frac{2\sqrt{2}}{8} \right) + 6\left( \frac{\sqrt{2}}{2} \right) = -\sqrt{2} + 3\sqrt{2} = 2\sqrt{2}$
*   $g\left( -\frac{\sqrt{2}}{2} \right) = -2\sqrt{2}$

**结论**：$F(x)$ 的最大值为 $\mathbf{2\sqrt{2}}$。

我们需要寻找 $\theta \in \mathbb{R}$，使得 $\max_{x \in \mathbb{R}} \left[ 3\cos\left( \frac{\pi}{2} x \right) - \cos\left( \frac{3\pi}{2} x + \frac{\pi}{2} \theta \right) \right] \le b$。
令 $\phi = \frac{\pi}{2} \theta$。我们要最小化关于 $\phi$ 的最大值。

**构造特殊点法（Lower Bound Analysis）**：
对于任意给定的 $\phi$，我们尝试寻找某个 $x$，使得 $\cos\left( \frac{3\pi}{2} x + \phi \right)$ 与 $\cos\left( \frac{\pi}{2} x \right)$ 形成“共振”。
令 $\frac{3\pi}{2} x + \phi = \pi - \frac{\pi}{2} x + 2k\pi \quad (k \in \mathbb{Z})$。
解得 $2\pi x = \pi - \phi + 2k\pi \implies x = \frac{1}{2} - \frac{\phi}{2\pi} + k$。
在此类 $x$ 点上，$\cos\left( \frac{3\pi}{2} x + \phi \right) = \cos\left( \pi - \frac{\pi}{2} x \right) = -\cos\left( \frac{\pi}{2} x \right)$。

$$H = 3\cos\left( \frac{\pi}{2} x \right) - \left( -\cos\left( \frac{\pi}{2} x \right) \right) = 4\cos\left( \frac{\pi}{2} x \right)$$
代入 $x = \frac{1}{2} - \frac{\phi}{2\pi} + k$，得 $H = 4\cos\left( \frac{\pi}{4} - \frac{\phi}{4} + \frac{k\pi}{2} \right)$。
对于任意 $\phi$，通过选择合适的 $k$，集合 $\left\{ \cos\left( u + \frac{k\pi}{2} \right) \mid k \in \mathbb{Z} \right\}$ 中必包含一个值 $\ge \frac{\sqrt{2}}{2}$（即 $\max(|\cos u|, |\sin u|) \ge \frac{\sqrt{2}}{2}$）。

当 $\theta = 0$ 时，由第一问知最大值恰好为 $2\sqrt{2}$。
**结论**：实数 $b$ 的最小值为 $\mathbf{2\sqrt{2}}$。

### 【进阶解法/技巧】

**1. 唯一性证明（Fourier Analysis View）**
若要严格证明 $f(x) = \cos(\frac{\pi}{2}x)$ 是唯一解，可设 $f(x) = \sum_{n \text{ odd}} a_n \cos(\frac{n\pi}{2}x)$（由对称性可知仅含奇次谐波）。
代入 $f'(x) = \frac{\pi}{2}f(x+1)$：
$$\sum -a_n \frac{n\pi}{2} \sin\left(\frac{n\pi}{2}x\right) = \sum \frac{\pi}{2} a_n \cos\left(\frac{n\pi}{2}x + \frac{n\pi}{2}\right)$$
注意到 $\cos\left(\frac{n\pi}{2}x + \frac{n\pi}{2}\right) = (-1)^{\frac{n-1}{2}} \cdot \left(-\sin\frac{n\pi}{2}x\right)$。
对比系数 $\implies -a_n \cdot n = a_n \cdot (-1)^{\frac{n+1}{2}}$。
若 $a_n \neq 0$，则 $n = (-1)^{\frac{n-1}{2}}$。此等式仅在 $n=1$ 时成立。
因此 $a_n=0$ 对于所有 $n > 1$ 成立，证明了函数的唯一性。

**2. 极小化最大值（Minimax Strategy）**
第二问实质上是一个 $\text{Chebyshev}$ 逼近问题。我们通过构造 $\cos(3\alpha + \phi) = -\cos \alpha$ 将高频项“降频”为基频项，从而将复杂的波形叠加转化为简单的振幅分析。这种**“共振点构造法”**是处理多频率三角函数不等式的最高效路径。
