```text
model/2026-06-06T04:26:13.625Z

这是一道典型的**含参超越函数零点问题**。这类问题的核心在于通过导数分析函数的单调性与极值，将“零点个数”转化为“极值正负”的判定问题。

### 🔍 元解析与特征挖掘（Meta-Analysis）

1.  **结构分析**：
    函数 $f(x) = e^{x-k} - \ln x - k$ 包含了指数函数 $e^{x-k}$ 和对数函数 $\ln x$。这是一个典型的“混合型”超越函数。
2.  **特征识别**：
    *   **定义域**：由于 $\ln x$ 的存在，定义域为 $(0, +\infty)$。
    *   **参数位置**：参数 $k$ 同时出现在指数项的偏移量和常数项中。这种结构暗示我们不能简单地使用“参变分离法”（因为 $k$ 无法被轻易分离到等号一侧），而应采用**“极值分析法”**。
    *   **凹凸性预判**：$e^{x-k}$ 是凸函数，$-\ln x$ 也是凸函数，常数 $-k$ 不影响凹凸性。因此 $f(x)$ 在定义域内是**严格凸函数**（$\cup$ 形），这意味着它最多有两个零点。

---

### 🛠️ 【常规解法】：极值判定路径

**第一步：分析单调性与极值点**
对 $f(x)$ 求导：
$$f'(x) = e^{x-k} - \frac{1}{x}$$
令 $f'(x) = 0$，即 $e^{x-k} = \frac{1}{x}$。
由于 $f''(x) = e^{x-k} + \frac{1}{x^2} > 0$ 恒成立，说明 $f'(x)$ 在 $(0, +\infty)$ 上严格单调递增。
且 $\lim_{x \to 0^+} f'(x) = -\infty$，$\lim_{x \to +\infty} f'(x) = +\infty$。
根据零点存在性定理，方程 $f'(x) = 0$ 有且仅有一个实根 $x_0$，且 $x_0$ 满足：
$$e^{x_0-k} = \frac{1}{x_0} \implies x_0 - k = \ln \frac{1}{x_0} = -\ln x_0 \implies \mathbf{k = x_0 + \ln x_0}$$

**第二步：构建零点存在条件**
由于 $f(x)$ 是 $\cup$ 形函数，且 $\lim_{x \to 0^+} f(x) = +\infty$，$\lim_{x \to +\infty} f(x) = +\infty$。
函数 $f(x)$ 有两个零点的充分必要条件是其**最小值 $f(x_0) < 0$**。

**第三步：将条件转化为关于 $x_0$ 的不等式**
将 $e^{x_0-k} = \frac{1}{x_0}$ 和 $k = x_0 + \ln x_0$ 代入 $f(x_0)$：
$$f(x_0) = \frac{1}{x_0} - \ln x_0 - (x_0 + \ln x_0) = \frac{1}{x_0} - 2\ln x_0 - x_0$$
我们需要求解 $\frac{1}{x_0} - 2\ln x_0 - x_0 < 0$。

**第四步：求解不等式**
设 $g(x) = \frac{1}{x} - 2\ln x - x$ ($x > 0$)，求导分析其单调性：
$$g'(x) = -\frac{1}{x^2} - \frac{2}{x} - 1 = -\left( \frac{1}{x} + 1 \right)^2$$
显然 $g'(x) < 0$ 恒成立，故 $g(x)$ 在 $(0, +\infty)$ 上严格单调递减。
观察特殊值：$g(1) = \frac{1}{1} - 2\ln 1 - 1 = 1 - 0 - 1 = 0$。
因此，$g(x_0) < 0 \iff x_0 > 1$。

**第五步：回归参数 $k$**
已知 $k = x_0 + \ln x_0$。
设 $\psi(x) = x + \ln x$，则 $\psi'(x) = 1 + \frac{1}{x} > 0$，$\psi(x)$ 严格单调递增。
因为 $x_0 > 1$，所以 $k > \psi(1) = 1 + \ln 1 = 1$。

**结论**：实数 $k$ 的取值范围是 $(1, +\infty)$。

---

### 🚀 【进阶解法/技巧】：临界状态分析法

在竞赛或高考压轴题中，我们可以直接寻找**“临界状态”**（即函数只有一个零点，此时最小值恰好为 $0$）。

1.  **临界点捕捉**：
    当 $f(x)$ 只有一个零点时，该点必然是极小值点 $x_0$，满足 $f(x_0) = 0$ 且 $f'(x_0) = 0$。
    $$\begin{cases} e^{x_0-k} - \ln x_0 - k = 0 \\ e^{x_0-k} - \frac{1}{x_0} = 0 \end{cases}$$
2.  **消元求解**：
    由第二式得 $e^{x_0-k} = \frac{1}{x_0}$，代入第一式：
    $$\frac{1}{x_0} - \ln x_0 - k = 0 \implies k = \frac{1}{x_0} - \ln x_0$$
    同时由第二式取对数得 $k = x_0 + \ln x_0$。
    联立得：$\frac{1}{x_0} - \ln x_0 = x_0 + \ln x_0 \implies \frac{1}{x_0} - 2\ln x_0 - x_0 = 0$。
    通过观察法（或单调性）迅速锁定 $x_0 = 1$。
3.  **确定临界值**：
    将 $x_0 = 1$ 代入 $k = x_0 + \ln x_0$，得 $k_{crit} = 1$。
4.  **方向判定**：
    观察原式 $f(x) = e^{x-k} - \ln x - k$。当 $k$ 增大时，$-k$ 项使函数整体下移，$e^{x-k}$ 项也随之减小。因此，**$k$ 越大，函数值越小，越容易产生两个零点**。
    故 $k > 1$。

### 📝 【总结与反思】

#### 1. 认知模型提炼
本题属于 **“极值点 $\to$ 临界值 $\to$ 参数范围”** 的逻辑链条。
其核心模型为：
$$\text{零点个数} \xrightarrow{\text{单调性}} \text{极值正负} \xrightarrow{\text{参数关联}} \text{参数范围}$$

#### 2. 易错陷阱点
*   **忽视定义域**：在处理 $\ln x$ 时，必须明确 $x > 0$。
*   **计算失误**：在处理 $f(x_0)$ 时，容易忘记将 $e^{x_0-k}$ 替换为 $\frac{1}{x_0}$，导致出现两个变量 $x_0$ 和 $k$ 无法化简。
*   **方向判断错误**：在临界法中，如果没分析 $k$ 与 $f(x)$ 的增减关系，可能会误写成 $k < 1$。

#### 3. 迁移场景
如果你在题目中看到以下结构，请立即启动此模型：
*   $f(x) = a^x + \ln x + C$
*   $f(x) = e^x - px - q$
*   只要是**凸函数**且要求**零点个数** $\implies$ **分析极小值 $\text{min} f(x)$ 的符号**。

**最终答案**：$\mathbf{k \in (1, +\infty)}$ 🌟
```
