$$12^\circ = 2 \times 6^\circ, \quad 24^\circ = 2 \times 12^\circ, \quad 48^\circ = 2 \times 24^\circ$$

**2. 结构母题定位：**
这种 $\cos \theta \cos 2\theta \cos 4\theta \dots \cos 2^{n-1}\theta$ 的结构是三角函数中的“指纹”结构，其对应的核心数学工具是**二倍角公式**：
$$\sin 2\theta = 2 \sin \theta \cos \theta \implies \cos \theta = \frac{\sin 2\theta}{2 \sin \theta}$$
该公式具有一种“链式反应”的特性，可以通过连续代换将乘积形式转化为商的形式。

$$P = \sin 6^\circ \cos 12^\circ \cos 24^\circ \cos 48^\circ$$

$$P = \frac{(\sin 6^\circ \cos 6^\circ) \cos 12^\circ \cos 24^\circ \cos 48^\circ}{\cos 6^\circ}$$

2. 利用 $\sin 12^\circ \cos 12^\circ = \frac{1}{2} \sin 24^\circ$：
   $$P = \frac{\frac{1}{4} \sin 24^\circ \cos 24^\circ \cos 48^\circ}{\cos 6^\circ}$$

3. 利用 $\sin 24^\circ \cos 24^\circ = \frac{1}{2} \sin 48^\circ$：
   $$P = \frac{\frac{1}{8} \sin 48^\circ \cos 48^\circ}{\cos 6^\circ}$$

   $$P = \frac{\frac{1}{16} \sin 96^\circ}{\cos 6^\circ}$$

利用诱导公式 $\sin(90^\circ + \theta) = \cos \theta$：
$$\sin 96^\circ = \sin(90^\circ + 6^\circ) = \cos 6^\circ$$

代入原式：
$$P = \frac{\frac{1}{16} \cos 6^\circ}{\cos 6^\circ} = \frac{1}{16}$$

代入 $P$：
$$P = \sin 6^\circ \cdot \frac{\sin 96^\circ}{8 \sin 12^\circ}$$

*   第 1 组：$(1 + \tan 1^\circ)(1 + \tan 44^\circ) = 2$
*   第 2 组：$(1 + \tan 2^\circ)(1 + \tan 43^\circ) = 2$
*   ...

2.  最后一项是 $(1 + \tan 45^\circ) = 1 + 1 = 2$。

$$1 = \tan \alpha + \tan \beta + \tan \alpha \tan \beta$$

$$(1 + \tan \alpha)(1 + \tan \beta) = 1 + \tan \alpha + \tan \beta + \tan \alpha \tan \beta$$

$$(1 + \tan \alpha)(1 + \tan \beta) = 1 + 1 = 2$$

$$\cos(\alpha - \beta) = \cos(\alpha - (90^\circ - \alpha)) = \cos(2\alpha - 90^\circ) = \sin 2\alpha$$
这意味着，我们只要能求出这些直角三角形的 $\sin 2\alpha$（或者 $\tan \alpha$），就能得到答案。

**3. 面积比与边长关系：**
已知 $S_{\text{小}} : S_{\text{大}} = 4 : 9$，则边长之比为 $s : L = 2 : 3$。

---

### 【详细推导过程】

在最常见的此类“弦图”模型中（即从顶点连向对边上 $\frac{1}{n}$ 处），小正方形的边长 $s$ 与大正方形边长 $L$ 的关系满足：
$$s = \frac{L|n-1|}{\sqrt{n^2+1}}$$
其中 $n$ 是分点比。

**步骤 1：利用面积比求 $n$**
已知 $\frac{s^2}{L^2} = \frac{4}{9}$，代入上述公式：
$$\frac{(n-1)^2}{n^2+1} = \frac{4}{9}$$
交叉相乘：
$$9(n^2 - 2n + 1) = 4(n^2 + 1)$$
$$9n^2 - 18n + 9 = 4n^2 + 4 \implies 5n^2 - 18n + 5 = 0$$

**步骤 2：求解 $n$ 或相关量**
我们不需要求出 $n$ 的具体值，因为我们需要的是 $\sin 2\alpha$。
在这些直角三角形中，$\tan \beta = \frac{1}{n}$（$\beta$ 是小角）。
那么 $\sin 2\beta$（即 $\sin(2\beta)$）的公式为：
$$\sin 2\beta = \frac{2 \tan \beta}{1 + \tan^2 \beta} = \frac{2/n}{1 + 1/n^2} = \frac{2n}{n^2+1}$$

**步骤 3：代入 $n$ 的关系式**
从步骤 1 的方程 $5n^2 - 18n + 5 = 0$ 中，我们可以得到：
$$5(n^2 + 1) = 18n \implies n^2 + 1 = \frac{18n}{5}$$
将其代入 $\sin 2\beta$ 的表达式中：
$$\sin 2\beta = \frac{2n}{\frac{18n}{5}} = \frac{2n \cdot 5}{18n} = \frac{10n}{18n} = \frac{5}{9}$$

**步骤 4：得出最终结果**
由于 $\alpha + \beta = 90^\circ$，则 $\alpha - \beta = 90^\circ - 2\beta$。
$$\cos(\alpha - \beta) = \cos(90^\circ - 2\beta) = \sin 2\beta$$
因此：
$$\cos(\alpha - \beta) = \frac{5}{9}$$

### 【总结与反思】

#### 1. 认知复盘（Cognitive Reflection）
本题的难点在于将**几何面积比 $\rightarrow$ 边长关系 $\rightarrow$ 三角函数值** 串联起来。
*   **关键突破口**：识别出 $\cos(\alpha - \beta)$ 在直角三角形中等同于 $\sin 2\theta$。
*   **计算技巧**：在处理 $5n^2 - 18n + 5 = 0$ 时，不要急于求出根（根包含 $\sqrt{14}$，计算会非常繁琐），而应直接构造 $\frac{2n}{n^2+1}$ 这一结构，利用整体代换秒杀。

#### 2. 知识迁移（Schema Transfer）
此类问题属于“参数化几何”模型。如果以后遇到类似的“正方形内嵌正方形”且涉及角度差的问题，可以尝试以下路径：
$$\text{面积比} \xrightarrow{\text{建立 } s \text{ 与 } L \text{ 关系}} \text{确定 } \tan \theta \xrightarrow{\text{利用二倍角公式}} \cos(\alpha-\beta)$$

**最终结论：** 四个小三角形大小角之差的余弦值为 $\frac{5}{9}$。
