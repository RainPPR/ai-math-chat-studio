### 🔍 元解析与特征挖掘 (Feature Mining)

在处理这类“多次独立重复试验”且“结果累加”的问题时，我们需要识别出两个关键特征：
1.  **独立同分布 (i.i.d.)**：每次抛掷硬币是相互独立的，且每次得分的分布完全相同。
2.  **线性映射关系**：总得分 $X$ 是一个关于“正面次数”的线性函数。

**结构母题识别**：
本题属于 $\text{Binomial} \to \text{Linear Transformation}$ 模型。即：先建立一个服从二项分布的计数变量 $Y$，再通过 $X = aY + b$ 将其映射到得分空间。

---

### 🛠️ 基准推导 (The Ground Solution)

**路径：基于二项分布的整体变换法**

1.  **引入计数变量**：
    设抛掷 $8$ 次硬币中，正面向上的次数为随机变量 $Y$。
    由于硬币质地均匀，且每次抛掷独立，则 $Y$ 服从二项分布：
    $$Y \sim B(n, p), \text{ 其中 } n = 8, p = \frac{1}{2}$$

2.  **建立 $X$ 与 $Y$ 的函数关系**：
    若正面向上 $Y$ 次，则反面向上 $(8 - Y)$ 次。
    总得分 $X$ 可表示为：
    $$X = 2Y + (-1)(8 - Y) = 2Y - 8 + Y = 3Y - 8$$

3.  **计算期望 $E(X)$**：
    利用期望的线性性质 $E(aY + b) = aE(Y) + b$：
    已知二项分布的期望 $E(Y) = np = 8 \times \frac{1}{2} = 4$。
    $$E(X) = E(3Y - 8) = 3E(Y) - 8 = 3 \times 4 - 8 = 4$$

4.  **计算方差 $D(X)$**：
    利用方差的性质 $D(aY + b) = a^2 D(Y)$：
    已知二项分布的方差 $D(Y) = np(1-p) = 8 \times \frac{1}{2} \times \frac{1}{2} = 2$。
    $$D(X) = D(3Y - 8) = 3^2 \times D(Y) = 9 \times 2 = 18$$

### 🚀 高维博弈 (High-Level Strategy)

**路径：基于独立随机变量之和的局部分解法**

在竞赛数学或概率论进阶中，我们倾向于将总和分解为单个试验的贡献，这种方法在处理更复杂的加权得分时具有极强的通用性。

1.  **定义单次随机变量**：
    设 $X_i$ 为第 $i$ 次抛掷的得分（$i=1, 2, \dots, 8$）。
    $X_i$ 的分布为：
    $$X_i = \begin{cases} 2, & P = \frac{1}{2} \\ -1, & P = \frac{1}{2} \end{cases}$$

2.  **计算单次指标**：
    - **单次期望**：
      $$E(X_i) = 2 \times \frac{1}{2} + (-1) \times \frac{1}{2} = 0.5$$
    - **单次方差**：
      首先计算 $E(X_i^2) = 2^2 \times \frac{1}{2} + (-1)^2 \times \frac{1}{2} = 2 + 0.5 = 2.5$。
      $$D(X_i) = E(X_i^2) - [E(X_i)]^2 = 2.5 - (0.5)^2 = 2.5 - 0.25 = 2.25$$

3.  **利用独立性进行累加**：
    由于 $X = \sum_{i=1}^8 X_i$ 且 $X_i$ 相互独立：
    - **总期望**：$E(X) = \sum_{i=1}^8 E(X_i) = 8 \times 0.5 = 4$
    - **总方差**：$D(X) = \sum_{i=1}^8 D(X_i) = 8 \times 2.25 = 18$

**两种路径对比**：
- **整体法**：计算量小，依赖于对二项分布公式的熟练掌握，适合简单线性得分。
- **局部法**：逻辑极其纯粹，不需要记忆 $B(n,p)$ 的方差公式，且能轻松迁移至“每次得分概率不同”或“得分权重动态变化”的复杂变式。

### 💡 总结与反思 (Cognitive Reflection)

**1. 核心模型提炼**：
本题的本质是 **“计数 $\to$ 得分”** 的映射。
- $\text{Counting Variable } (Y) \xrightarrow{\text{Linear Map}} \text{Score Variable } (X)$
- 映射公式：$X = (\text{正分} - \text{负分}) \cdot Y + \text{总次数} \cdot \text{负分}$

**2. 易错陷阱点**：
- **方差系数**：最常见的错误是在计算 $D(X)$ 时忘记将系数 $3$ 平方，直接写成 $3 \times D(Y)$。请务必记住：**方差对系数是平方级敏感的**。
- **正负号**：在建立 $X = 3Y - 8$ 时，若将负分 $-1$ 误处理为正数 $1$，会导致结果出现严重偏差。

**3. 迁移场景**：
如果题目改为：“正面得 $a$ 分，反面得 $b$ 分，抛掷 $n$ 次”，则：
- $E(X) = n \cdot \frac{a+b}{2}$
- $D(X) = n \cdot \frac{(a-b)^2}{4}$
（通过上述局部法可以瞬间推导出该通式，这便是从“算力”到“脑力”的升阶）。

**最终结果**：
$$\mathbf{E(X) = 4, \quad D(X) = 18}$$
