```text

这是一个典型的三角恒等变换与最值优化问题。本题的难点在于如何高效地从一个复杂的三角等式中提取出角度之间的线性关系，并将其转化为一个可处理的单变量函数。

### 【元解析与特征挖掘】

1.  **结构指纹识别**：
    *   左端 $\frac{\cos A}{1 + \sin A}$ 是一个经典的“半角切值”结构。利用 $\sin A = \cos(\frac{\pi}{2}-A)$ 和 $1+\cos \theta = 2\cos^2\frac{\theta}{2}$，可以迅速将其转化为 $\tan$ 形式。
    *   右端 $\frac{\sin 2B}{1 + \cos 2B}$ 是标准的半角公式形式 $\tan B$。
    *   **母题识别**：本题属于“由三角等式 $\to$ 角度关系 $\to$ 边长比例 $\to$ 目标函数最值”的递进式结构。

2.  **路径设计**：
    *   **第一步（解析转换）**：将等式两边统一为 $\tan$ 函数，解出 $A, B$ 的关系。
    *   **第二步（维度降低）**：利用 $\triangle ABC$ 内角和 $\pi$ 将 $C$ 用 $B$ 表示，将目标式 $\frac{a^2+b^2}{c^2}$ 转化为关于 $B$ 的单变量函数。
    *   **第三步（最值求解）**：通过代数换元（如令 $u = \cos^2 B$），将三角函数最值问题转化为分式函数的极值问题，利用均值不等式（AM-GM）求解。

---

### 【常规解法】

#### 1. 提取角度关系
首先处理等式 $\dfrac{\cos A}{1+\sin A}=\dfrac{\sin 2B}{1+\cos 2B}$。

**左边：**
$$\frac{\cos A}{1+\sin A} = \frac{\sin(\frac{\pi}{2}-A)}{1+\cos(\frac{\pi}{2}-A)} = \frac{2\sin(\frac{\pi}{4}-\frac{A}{2})\cos(\frac{\pi}{4}-\frac{A}{2})}{2\cos^2(\frac{\pi}{4}-\frac{A}{2})} = \tan\left(\frac{\pi}{4} - \frac{A}{2}\right)$$

**右边：**
$$\frac{\sin 2B}{1+\cos 2B} = \frac{2\sin B \cos B}{2\cos^2 B} = \tan B$$

因此，$\tan\left(\frac{\pi}{4} - \frac{A}{2}\right) = \tan B$。
由于 $A, B \in (0, \pi)$，且 $\frac{\pi}{4} - \frac{A}{2} \in (-\frac{\pi}{4}, \frac{\pi}{4})$，而 $\tan B$ 在 $(0, \pi)$ 上单调，结合三角形内角和，唯一的可能解为：
$$\frac{\pi}{4} - \frac{A}{2} = B \implies A + 2B = \frac{\pi}{2}$$

#### 2. 目标式转换
由 $A + 2B = \frac{\pi}{2}$ 及 $A+B+C = \pi$，可得：
$$C = \pi - (A+B) = \pi - (\frac{\pi}{2} - 2B + B) = \frac{\pi}{2} + B$$
同时，由于 $A > 0$，则 $\frac{\pi}{2} - 2B > 0 \implies B < \frac{\pi}{4}$。故 $B \in (0, \frac{\pi}{4})$。

根据正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$，目标式可化为：
$$f = \frac{a^2+b^2}{c^2} = \frac{\sin^2 A + \sin^2 B}{\sin^2 C}$$

代入 $A = \frac{\pi}{2}-2B$ 和 $C = \frac{\pi}{2}+B$：
$$\sin A = \sin(\frac{\pi}{2}-2B) = \cos 2B$$
$$\sin C = \sin(\frac{\pi}{2}+B) = \cos B$$
于是：
$$f(B) = \frac{\cos^2 2B + \sin^2 B}{\cos^2 B}$$

#### 3. 精密计算与最值求解
令 $u = \cos^2 B$。由于 $B \in (0, \frac{\pi}{4})$，则 $u \in (\frac{1}{2}, 1)$。
已知 $\cos 2B = 2\cos^2 B - 1 = 2u-1$，$\sin^2 B = 1-u$。
将这些代入 $f$：
$$f(u) = \frac{(2u-1)^2 + (1-u)}{u} = \frac{4u^2 - 4u + 1 + 1 - u}{u} = \frac{4u^2 - 5u + 2}{u}$$
$$f(u) = 4u + \frac{2}{u} - 5$$

根据均值不等式（AM-GM）：
$$4u + \frac{2}{u} \ge 2\sqrt{4u \cdot \frac{2}{u}} = 2\sqrt{8} = 4\sqrt{2}$$
等号成立条件为 $4u = \frac{2}{u} \implies u^2 = \frac{1}{2} \implies u = \frac{1}{\sqrt{2}}$。
检查范围：$\frac{1}{2} < \frac{1}{\sqrt{2}} < 1$ 成立。

因此，$\dfrac{a^2+b^2}{c^2}$ 的最小值为：
$$\mathbf{4\sqrt{2} - 5}$$

### 【进阶解法/技巧】

**高维视野：利用“对偶变换”与“参数化”**

在处理 $\frac{\cos^2 2B + \sin^2 B}{\cos^2 B}$ 时，如果不想通过 $u = \cos^2 B$ 这种常规换元，可以尝试**结构分解**：
$$f = \frac{\cos^2 2B}{\cos^2 B} + \tan^2 B = \frac{(2\cos^2 B - 1)^2}{\cos^2 B} + \tan^2 B$$
$$f = \frac{4\cos^4 B - 4\cos^2 B + 1}{\cos^2 B} + \tan^2 B = 4\cos^2 B - 4 + \frac{1}{\cos^2 B} + \tan^2 B$$
利用 $\frac{1}{\cos^2 B} = 1 + \tan^2 B$，则：
$$f = 4\cos^2 B - 4 + 1 + 2\tan^2 B = 4\cos^2 B + 2\tan^2 B - 3$$
此时可将 $\tan^2 B$ 写成 $\frac{1}{\cos^2 B}-1$：
$$f = 4\cos^2 B + \frac{2}{\cos^2 B} - 2 - 3 = 4\cos^2 B + \frac{2}{\cos^2 B} - 5$$
这种方法通过将分式拆解为 $\cos^2 B$ 的函数，直接揭示了其对偶结构（$x$ 与 $1/x$），比整体通分后再除以 $u$ 的心理压力更小，计算路径更清晰。

### 【总结与反思】

#### 1. 认知复盘 (Cognitive Reflection)
本题的解题逻辑链条为：**【特征识别 $\to$ 线性化角度 $\to$ 变量单参数化 $\to$ 凸函数最值】**。
最核心的突破口在于对 $\frac{\cos A}{1+\sin A}$ 的认知。在高中数学竞赛和高考压轴题中，$\frac{\cos \theta}{1+\sin \theta} = \tan(\frac{\pi}{4}-\frac{\theta}{2})$ 是一个极高频的“隐藏指纹”，建议将其直接内化为二级结论。

#### 2. 易错陷阱 (Pitfalls)
*   **范围遗漏**：在解 $\tan X = \tan Y$ 时，必须考虑 $X = Y + k\pi$。本题中若忽略 $B \in (0, \pi)$ 的约束，可能会丢失解或引入无效解。
*   **定义域校验**：在使用均值不等式之前，必须校验等号成立时的 $u = \frac{1}{\sqrt{2}}$ 是否在 $u \in (\frac{1}{2}, 1)$ 范围内。如果不在，则最小值在端点处取得。

#### 3. 迁移场景 (Schema Transfer)
当你看到 $\frac{1 \pm \sin \theta}{\cos \theta}$ 或 $\frac{\cos \theta}{1 \pm \sin \theta}$ 这种形式时，应立即联想到：
1.  **半角切值公式**：$\tan(\frac{\pi}{4} \pm \frac{\theta}{2})$。
2.  **共轭相乘**：$\frac{\cos \theta}{1+\sin \theta} \cdot \frac{1-\sin \theta}{1-\sin \theta} = \frac{\cos \theta (1-\sin \theta)}{\cos^2 \theta} = \frac{1-\sin \theta}{\cos \theta} = \sec \theta - \tan \theta$。
这两者在处理导数不等式或复杂三角最值时具有极强的通用性。
```
