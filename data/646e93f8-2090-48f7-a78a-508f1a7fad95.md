# 深度解析：三角函数偶函数与单调性问题

---

## 🔍 元解析与特征挖掘

本题的核心结构是两个条件的**交叉约束**：
- **偶函数条件** $\Rightarrow$ 锁定相位 $\theta$ 的候选值
- **单调性条件** $\Rightarrow$ 筛选整数参数 $a$ 的合法范围

关键洞察：偶函数条件将 $\theta$ 压缩到离散候选集，单调性条件进一步排除不合理解，最终 $f\!\left(\dfrac{2\pi}{3}\right)$ 的值在所有合法 $a$ 下**坍缩为唯一值**——这是本题最精妙的设计。

---

## 📘 常规解法（基准路径）

### 第一步：利用偶函数条件确定 $\theta$

$f(x)$ 为偶函数，即 $f(-x) = f(x)$ 对所有 $x$ 成立：

$$2\sin(-ax + \theta) = 2\sin(ax + \theta)$$

利用和差化积公式展开：

$$\sin(\theta + ax) - \sin(\theta - ax) = 2\cos\theta \cdot \sin(ax) = 0$$

此式须对**所有** $x$ 成立。若 $a = 0$，则 $f(x) = 2\sin\theta$ 为常函数，不可能在 $\left(0, \dfrac{\pi}{2}\right)$ 上单调递增，故 $a \neq 0$。

因此 $\sin(ax)$ 不恒为零，必须有：

$$\cos\theta = 0 \implies \theta = \frac{\pi}{2} + k\pi,\quad k \in \mathbb{Z}$$

结合 $0 \le \theta < 2\pi$，得候选值：

$$\boxed{\theta = \frac{\pi}{2} \quad \text{或} \quad \theta = \frac{3\pi}{2}}$$

### 第二步：利用单调性条件筛选

**情形一：** $\theta = \dfrac{\pi}{2}$

$$f(x) = 2\sin\!\left(ax + \frac{\pi}{2}\right) = 2\cos(ax)$$

$$f'(x) = -2a\sin(ax)$$

要求在 $\left(0, \dfrac{\pi}{2}\right)$ 上 $f'(x) > 0$，即 $a\sin(ax) < 0$。

但当 $x \to 0^+$ 时，$ax \to 0$（无论 $a$ 正负），$\sin(ax)$ 与 $ax$ 同号，故 $a\sin(ax) \to a \cdot (ax) = a^2 x > 0$，与 $a\sin(ax) < 0$ 矛盾。

> ❌ **$\theta = \dfrac{\pi}{2}$ 被排除。**

**情形二：** $\theta = \dfrac{3\pi}{2}$

$$f(x) = 2\sin\!\left(ax + \frac{3\pi}{2}\right) = -2\cos(ax)$$

$$f'(x) = 2a\sin(ax)$$

要求在 $\left(0, \dfrac{\pi}{2}\right)$ 上 $f'(x) > 0$，即 $a\sin(ax) > 0$。

由于 $\cos(ax)$ 是偶函数，$f(x) = -2\cos(ax) = -2\cos(|a|x)$，故只需讨论 $|a|$：

$$f'(x) = 2|a|\sin(|a|x) > 0 \iff \sin(|a|x) > 0$$

在 $x \in \left(0, \dfrac{\pi}{2}\right)$ 上，$|a|x \in \left(0, \dfrac{|a|\pi}{2}\right)$。

要使 $\sin(|a|x) > 0$ 在整个区间成立，需：

$$\frac{|a|\pi}{2} \le \pi \implies |a| \le 2$$

结合 $a \in \mathbb{Z},\ a \neq 0$，得 $a \in \{-2, -1, 1, 2\}$。

> ✅ **$\theta = \dfrac{3\pi}{2}$ 成立。**

### 第三步：计算 $f\!\left(\dfrac{2\pi}{3}\right)$

$$f\!\left(\frac{2\pi}{3}\right) = -2\cos\!\left(\frac{2a\pi}{3}\right)$$

逐一验证所有合法 $a$ 值：

| $a$ | $\dfrac{2a\pi}{3}$ | $\cos\!\left(\dfrac{2a\pi}{3}\right)$ | $f\!\left(\dfrac{2\pi}{3}\right)$ |
|:---:|:---:|:---:|:---:|
| $\pm 1$ | $\pm\dfrac{2\pi}{3}$ | $-\dfrac{1}{2}$ | $1$ |
| $\pm 2$ | $\pm\dfrac{4\pi}{3}$ | $-\dfrac{1}{2}$ | $1$ |

> 关键观察：$\cos\!\left(\dfrac{4\pi}{3}\right) = \cos\!\left(2\pi - \dfrac{2\pi}{3}\right) = \cos\!\left(\dfrac{2\pi}{3}\right) = -\dfrac{1}{2}$，因此所有合法 $a$ 给出**相同结果**。

$$\boxed{\theta = \frac{3\pi}{2}, \quad f\!\left(\frac{2\pi}{3}\right) = 1}$$

## 🚀 进阶解法（高维视角）

### 相位对称性直觉

偶函数的图像关于 $y$ 轴对称。正弦函数 $y = \sin(u)$ 的对称轴位于 $u = \dfrac{\pi}{2} + k\pi$（即波峰/波谷处）。

因此，$f(x) = 2\sin(ax + \theta)$ 关于 $x = 0$ 对称，等价于 $x = 0$ 处取到极值：

$$f'(0) = 2a\cos(\theta) = 0 \implies \cos\theta = 0$$

这直接给出 $\theta \in \left\{\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right\}$，**一步到位**。

### 单调性快速判定

$f(0) = 2\sin(\theta)$ 是极值点。

- 若 $\theta = \dfrac{\pi}{2}$，$f(0) = 2$（极大值），则 $f(x)$ 在 $x = 0$ 右侧必然**递减**，与题设矛盾。
- 若 $\theta = \dfrac{3\pi}{2}$，$f(0) = -2$（极小值），则 $f(x)$ 在 $x = 0$ 右侧**递增**，符合题设。

> 这种"**极值点 + 邻域单调性**"的判断方法，将复杂的导数分析压缩为一步直觉判断，是考场上的高效策略。

### $f\!\left(\dfrac{2\pi}{3}\right)$ 的不变量本质

无论 $|a| = 1$ 还是 $|a| = 2$：

$$\frac{2|a|\pi}{3} \equiv \frac{2\pi}{3} \pmod{2\pi} \quad \text{或} \quad \frac{2|a|\pi}{3} \equiv \frac{4\pi}{3} \pmod{2\pi}$$

而 $\cos\!\left(\dfrac{2\pi}{3}\right) = \cos\!\left(\dfrac{4\pi}{3}\right) = -\dfrac{1}{2}$，这是因为 $\dfrac{2\pi}{3}$ 和 $\dfrac{4\pi}{3}$ 关于 $x$ 轴对称（$\cos(2\pi - \alpha) = \cos\alpha$）。

这一**余弦函数的对称不变量**保证了答案的唯一性，也是出题者的精心布局。

### 核心解法模型

```
三角函数偶函数 + 单调性 问题模板：
1. 偶函数 → f'(0) = 0 → 锁定相位 θ（极值点在 y 轴上）
2. 单调性 → f(0) 是极大还是极小 → 筛选 θ
3. 周期约束 → 单调区间长度 ≤ 半周期 → 确定 |a| 范围
4. 代入求值 → 利用三角恒等式验证答案唯一性
```
