```text

这是一道典型的三角形几何与三角函数综合题。它不仅考查正弦定理、余弦定理的熟练运用，更深层的考点在于**三角恒等变换的结构识别**以及**函数单调性的区间映射**。

### 【元解析与特征挖掘】

**1. 结构分量识别：**
题干给出 $a = b + 2b\cos C$，我们可以将其改写为 $a - b = 2b\cos C$。
在三角形中，看到 $\cos C$ 往往有两种思考路径：
- **代数路径**：使用余弦定理 $\cos C = \frac{a^2+b^2-c^2}{2ab}$，将问题转化为边长的代数关系。
- **几何/三角路径**：使用正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B}$，将问题转化为角度的函数关系。

**2. 核心突破口：**
该等式 $a = b(1 + 2\cos C)$ 具有明显的“正弦化”潜力。由于 $A+B+C = \pi$，$\sin A$ 可以转化为 $\sin(B+C)$。这种“角之和”的结构暗示我们可以通过和差化积或倍角公式将方程简化为关于 $B$ 和 $C$ 的简单关系式。

---

### 【常规解法】

#### 第一部分：证明 $C=2B$

**步骤 1：正弦化转换**
根据正弦定理 $\frac{a}{\sin A} = \frac{b}{\sin B} = 2R$，原式 $a = b + 2b\cos C$ 可转化为：
$$\sin A = \sin B + 2\sin B \cos C$$

**步骤 2：利用内角和性质**
因为 $A = \pi - (B+C)$，所以 $\sin A = \sin(B+C)$。代入上式：
$$\sin(B+C) = \sin B + 2\sin B \cos C$$

**步骤 3：展开与化简**
利用和角公式 $\sin(B+C) = \sin B \cos C + \cos B \sin C$：
$$\sin B \cos C + \cos B \sin C = \sin B + 2\sin B \cos C$$
移项整理得：
$$\cos B \sin C - \sin B \cos C = \sin B$$

**步骤 4：应用差角公式**
左边符合 $\sin(C-B)$ 的结构：
$$\sin(C-B) = \sin B$$

**步骤 5：讨论角度范围**
由于 $B, C$ 是三角形内角，且 $C-B \in (-\pi, \pi)$，$B \in (0, \pi)$。
由 $\sin(C-B) = \sin B$ 可得：
1. $C-B = B \implies \mathbf{C = 2B}$
2. $C-B = \pi - B \implies C = \pi$ （这在三角形中是不可能的）

**结论：** 证得 $C = 2B$。 $\square$

---

#### 第二部分：求 $\frac{a+c}{b}$ 的取值范围

**步骤 1：建立单变量函数**
已知 $C=2B$，则 $A = \pi - (B+C) = \pi - 3B$。
由于 $A > 0$，故 $3B < \pi \implies B < \frac{\pi}{3}$。又 $B > 0$，所以 $\mathbf{B \in (0, \frac{\pi}{3})}$。

利用正弦定理，将目标式 $S = \frac{a+c}{b}$ 表示为 $B$ 的函数：
$$S = \frac{\sin A + \sin C}{\sin B} = \frac{\sin(\pi-3B) + \sin 2B}{\sin B} = \frac{\sin 3B + \sin 2B}{\sin B}$$

**步骤 2：三角恒等变换**
利用三倍角公式 $\sin 3B = 3\sin B - 4\sin^3 B$ 和倍角公式 $\sin 2B = 2\sin B \cos B$：
$$S = \frac{3\sin B - 4\sin^3 B + 2\sin B \cos B}{\sin B}$$
由于 $\sin B \neq 0$，约分得：
$$S = 3 - 4\sin^2 B + 2\cos B$$

**步骤 3：统一变量为 $\cos B$**
利用 $\sin^2 B = 1 - \cos^2 B$：
$$S = 3 - 4(1 - \cos^2 B) + 2\cos B = 4\cos^2 B + 2\cos B - 1$$

**步骤 4：分析函数区间**
令 $t = \cos B$。由于 $B \in (0, \frac{\pi}{3})$，则 $t \in (\frac{1}{2}, 1)$。
构造函数 $f(t) = 4t^2 + 2t - 1$ 在区间 $(\frac{1}{2}, 1)$ 上的表现：
- $f'(t) = 8t + 2 > 0$ 恒成立，函数 $f(t)$ 在该区间单调递增。
- 下界：$t \to \frac{1}{2}^+ \implies f(t) \to 4(\frac{1}{4}) + 2(\frac{1}{2}) - 1 = 1$。
- 上界：$t \to 1^- \implies f(t) \to 4(1)^2 + 2(1) - 1 = 5$。

**结论：** $\frac{a+c}{b}$ 的取值范围是 $\mathbf{(1, 5)}$。

### 【进阶解法/技巧】

**1. 边长关系对撞（Algebraic Insight）：**
在第一问中，如果采用余弦定理，原式 $a = b + 2b\cos C$ 可变形为：
$$a = b + 2b \frac{a^2+b^2-c^2}{2ab} = b + \frac{a^2+b^2-c^2}{a}$$
$$a^2 = ab + a^2 + b^2 - c^2 \implies \mathbf{c^2 = b(a+b)}$$
这是一个著名的三角形结论：**当且仅当 $C=2B$ 时，边长满足 $c^2 = b(a+b)$**。在竞赛中，这个结论可以直接调用，或作为快速检验的基准。

**2. 和差化积的极速路径：**
在计算 $\frac{\sin 3B + \sin 2B}{\sin B}$ 时，可使用和差化积：
$$\sin 3B + \sin 2B = 2\sin\frac{5B}{2}\cos\frac{B}{2}$$
$$\sin B = 2\sin\frac{B}{2}\cos\frac{B}{2}$$
$$S = \frac{\sin(5B/2)}{\sin(B/2)}$$
通过 $\sin(5\theta) = 16\sin^5\theta - 20\sin^3\theta + 5\sin\theta$（虽然此公式较偏），或直接展开 $\sin(\frac{5B}{2}) = \sin(2B + \frac{B}{2})$ 亦可快速得出结果。

### 【总结与反思】

#### 认知复盘（Meta-Cognitive Summary）

本题的逻辑链条为：**边长关系 $\xrightarrow{正弦定理}$ 角度关系 $\xrightarrow{恒等变换}$ 单变量函数 $\xrightarrow{区间映射}$ 取值范围**。

**1. 关键模型提炼：**
- **“同构识别”**：当题目出现 $a = b + k \cdot b\cos C$ 形式时，应立刻警觉其与 $\sin(C-B)$ 或 $\sin(C+B)$ 的潜在联系。
- **“变量压缩”**：在处理三角形范围问题时，尽可能将所有三角函数统一到一个变量（如 $\cos B$）上，将几何问题转化为简单的二次函数区间问题。

**2. 陷阱点提示：**
- **范围界限**：最容易出错的地方是 $B$ 的取值范围。必须意识到 $A > 0$ 隐含了 $B < 60^\circ$ 的限制，否则范围将扩大。
- **逻辑严密性**：在 $\sin(C-B) = \sin B$ 求解时，不能直接写 $C-B=B$，必须排除 $C-B = \pi - B$ 的情况。

**3. 迁移场景：**
此类方法可迁移至所有涉及“边角关系证明”和“边长比值范围”的压轴题中。核心在于：**能用正弦定理将边化角，尽量不用余弦定理将角化边（因为 $\sin$ 的线性组合比 $\cos$ 的平方项更容易化简）**。
```
