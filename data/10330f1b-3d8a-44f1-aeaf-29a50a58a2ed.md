这是一道典型的关于**函数性质综合（奇偶性、周期性、对称性）**的解析题。题目通过两个函数方程约束了 $f(x)$ 的全局结构，而给出的区间解析式则是为了通过局部性质反推参数。

### 【元解析与特征挖掘】

在进入计算前，我们首先对题干中的“数学指纹”进行深度提取：

1.  **偶函数特征**：$f(x) = f(-x)$ $\implies$ 图象关于 $y$ 轴对称。
2.  **反周期特征**：$f(x) + f(x-2) = 0 \implies f(x) = -f(x-2)$。
    *   这是一个“半周期反号”结构。
    *   推导周期：$f(x+2) = -f(x)$，则 $f(x+4) = -f(x+2) = -(-f(x)) = f(x)$。
    *   **结论 1**：$f(x)$ 是周期为 $T=4$ 的周期函数。
3.  **对称中心挖掘**：
    *   结合 $f(x) = f(-x)$ 与 $f(x) = -f(x-2)$。
    *   $f(x) = -f(x-2) = -f(-(x-2)) = -f(2-x)$。
    *   $f(x) = -f(2-x) \implies f(x) + f(2-x) = 0$。
    *   **结论 2**：图象关于点 $(1, 0)$ 中心对称。
4.  **对称轴挖掘**：
    *   $f(2+x) = -f(x)$ 且 $f(2-x) = -f(x)$。
    *   因此 $f(2+x) = f(2-x)$。
    *   **结论 3**：图象关于直线 $x=2$ 轴对称。

---

### 【常规解法】

**第一步：利用对称中心确定关键点**
由结论 2 知，函数关于 $(1, 0)$ 中心对称，则必有：
$$f(1) = 0$$
根据周期性 $f(x+2) = -f(x)$，代入 $x=1$：
$$f(3) = -f(1) = 0$$
由于 $x=3$ 落在给定区间 $\left[\dfrac{3}{2}, 3\right]$ 内，代入解析式 $f(x) = x^2 + ax + b$：
$$3^2 + 3a + b = 0 \implies 3a + b = -9 \quad \text{—— (式 1)}$$

**第二步：利用周期性/对称性构造等式**
我们需要第二个独立方程。考虑区间内的两点 $\dfrac{3}{2}$ 和 $\dfrac{5}{2}$。
由 $f(x+2) = -f(x)$ 及 $f(x) = f(-x)$ 可得：
$$f\left(\frac{3}{2}\right) = -f\left(-\frac{1}{2}\right) = -f\left(\frac{1}{2}\right)$$
又因为 $f\left(\frac{5}{2}\right) = -f\left(\frac{1}{2}\right)$，
所以：
$$f\left(\frac{3}{2}\right) = f\left(\frac{5}{2}\right)$$
将解析式代入：
$$\left(\frac{3}{2}\right)^2 + a\left(\frac{3}{2}\right) + b = \left(\frac{5}{2}\right)^2 + a\left(\frac{5}{2}\right) + b$$
$$\frac{9}{4} + \frac{3}{2}a = \frac{25}{4} + \frac{5}{2}a$$
$$\frac{3}{2}a - \frac{5}{2}a = \frac{25}{4} - \frac{9}{4}$$
$$-a = 4 \implies \mathbf{a = -4}$$

**第三步：求解 $b$**
将 $a = -4$ 代入（式 1）：
$$3(-4) + b = -9$$
$$-12 + b = -9 \implies \mathbf{b = 3}$$

### 【进阶解法/技巧】

如果你能瞬间识别出**结论 3（关于 $x=2$ 对称）**，本题可以被“秒杀”。

**高维视角分析：**
1.  **对称轴判定**：已知 $f(x)$ 在 $\left[\dfrac{3}{2}, 3\right]$ 上是二次函数 $f(x) = x^2 + ax + b$。
2.  **结构对撞**：既然 $f(x)$ 全局关于 $x=2$ 对称，且该二次函数定义域覆盖了 $x=2$ 及其左右对称区域，那么这个抛物线的**顶点横坐标必须在 $x=2$ 上**。
3.  **快速锁定 $a$**：
    $$\text{顶点 } x_0 = -\frac{a}{2 \times 1} = 2 \implies \mathbf{a = -4}$$
4.  **快速锁定 $b$**：
    由 $f(1)=0$ 且 $f(x+2)=-f(x)$ $\implies f(3)=0$。
    直接代入 $f(3) = 3^2 - 4(3) + b = 0 \implies 9 - 12 + b = 0 \implies \mathbf{b = 3}$。

**对比分析：**
*   **常规法**：依赖于具体的点值计算，逻辑链路为：$\text{性质} \to \text{点} \to \text{方程} \to \text{解}$。
*   **进阶法**：依赖于几何结构识别，逻辑链路为：$\text{性质} \to \text{对称轴} \to \text{顶点} \to \text{参数}$。后者在处理复杂变式（如解析式为高次函数）时具有极强的鲁棒性。

### 【总结与反思】

#### 1. 认知模型提炼：函数性质的“叠加效应”
本题的核心在于**多种对称性的叠加**。在数学竞赛或高考压轴题中，请记住以下模版：
*   **偶函数 + $f(x+T) = -f(x)$** $\implies$ 周期为 $2T$，且关于 $x = \frac{T}{2}$ 对称。
*   **奇函数 + $f(x+T) = -f(x)$** $\implies$ 周期为 $2T$，且关于 $x = \frac{T}{2}$ 中心对称。

#### 2. 易错陷阱点
*   **周期误判**：很多学生会直接认为 $f(x)+f(x-2)=0$ 意味着周期是 $2$，实际上是 $4$。
*   **定义域忽略**：在代入 $f(3)=0$ 之前，必须确认 $x=3$ 是否在给定的解析式区间内。

#### 3. 迁移场景
此类问题常出现在：
*   **导数题的背景设定**：先通过函数方程确定 $f(x)$ 的解析式，再讨论单调性或极值。
*   **解析几何的结合**：将对称性转化为坐标变换，简化计算量。
