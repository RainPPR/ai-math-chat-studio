这是一道典型的高考压轴级别导数综合题。它不仅考察了极值点的计算、导数函数的单调性分析，还隐含了**参变分离**与**函数最值博弈**的思维模型。

### 【元解析与特征挖掘】

**1. 结构分量分析**：
*   **母函数结构**：$g(x) = P(x)e^x$ 类型。此类函数的导数必然仍是 $(Q(x))e^x$ 形式，极值点由多项式 $Q(x)=0$ 决定。
*   **关键指纹**：$\frac{g(x_2)}{2} \le 1 - t(e^{-2-x_1}-1)$。
    *   观察到 $x_1, x_2$ 是二次方程的根，满足韦达定理 $x_1 + x_2 = -2$，这意味着 $e^{-2-x_1} = e^{x_2}$。
    *   这是一个极其重要的**同构转换**，将两个极值点的复杂关系统一到了单一变量 $x_2$ 上。

**2. 逻辑路径设计**：
*   **第一步**：通过 $g'(x)=0$ 确定 $x_1, x_2$ 的存在条件及相互关系。
*   **第二步**：利用极值点的定义，将 $g(x_2)$ 用 $x_2$ 的简洁形式表示（消去参数 $a$）。
*   **第三步**：将原不等式转化为关于 $x_2$ 和 $t$ 的函数关系式，将 $t$ 隔离。
*   **第四步**：构造辅助函数 $h(x)$，通过分析其在不同区间（$x_2 > 0$ 与 $-1 < x_2 < 0$）的极值情况，确定 $t$ 的取值范围。

---

### 【常规解法】

#### 1. 极值点的确定与性质
对 $g(x)$ 求导：
$$g'(x) = 2xe^x + (x^2-a-1)e^x = (x^2+2x-a-1)e^x$$
若 $g(x)$ 有两个极值点 $x_1, x_2$，则方程 $x^2+2x-(a+1)=0$ 有两个不等实根。
由 $\Delta = 4 + 4(a+1) = 4a+8 > 0 \implies a > -2$。
根据韦达定理：
$$x_1 + x_2 = -2, \quad x_1 x_2 = -(a+1)$$
由此得 $x_2 = -1 + \sqrt{a+2}$。由于 $a > -2$，故 **$x_2 \in (-1, +\infty)$**。

#### 2. 不等式的简化
因为 $x_2$ 是 $g'(x)=0$ 的根，所以 $x_2^2 + 2x_2 - a - 1 = 0 \implies x_2^2 - a - 1 = -2x_2$。
代入 $g(x)$ 得：
$$g(x_2) = (-2x_2)e^{x_2}$$
原不等式 $\frac{g(x_2)}{2} \le 1 - t(e^{-2-x_1}-1)$ 可化为：
$$-x_2 e^{x_2} \le 1 - t(e^{x_2}-1)$$
整理得：
$$t(e^{x_2}-1) \le 1 + x_2 e^{x_2}$$

#### 3. 分区间讨论 $t$ 的范围
由于 $x_2$ 可取 $(-1, +\infty)$ 上的任意值，我们分三种情况讨论：

**情况 $\text{I}$：$x_2 > 0$**
此时 $e^{x_2}-1 > 0$，得 $t \le \dfrac{1 + x_2 e^{x_2}}{e^{x_2}-1}$。
设 $h(x) = \dfrac{1 + xe^x}{e^x-1} \quad (x > 0)$。
求导分析：
$$h'(x) = \frac{(e^x + e^x + xe^x)(e^x-1) - (1+xe^x)e^x}{(e^x-1)^2} = \frac{e^x(2e^x - 3 - x)}{(e^x-1)^2}$$
令 $\phi(x) = 2e^x - x - 3$。
$\phi'(x) = 2e^x - 1$，在 $x>0$ 时 $\phi'(x) > 0$，$\phi(x)$ 单调递增。
$\phi(0) = -1 < 0$ 且 $\phi(1) = 2e-4 > 0$，故 $\phi(x)$ 在 $(0, 1)$ 内有唯一零点 $x_0$。
因此，$h(x)$ 在 $(0, x_0)$ 递减，在 $(x_0, +\infty)$ 递增。
其最小值为 $h(x_0)$。由于 $2e^{x_0} = x_0 + 3$，代入 $h(x)$：
$$h(x_0) = \frac{1 + x_0 \frac{x_0+3}{2}}{\frac{x_0+3}{2}-1} = \frac{2 + x_0^2 + 3x_0}{x_0+1} = \frac{(x_0+1)(x_0+2)}{x_0+1} = x_0 + 2$$
因为 $0 < x_0 < 1$，所以 $2 < h(x_0) < 3$。

**情况 $\text{II}$：$-1 < x_2 < 0$**
此时 $e^{x_2}-1 < 0$，得 $t \ge \dfrac{1 + x_2 e^{x_2}}{e^{x_2}-1}$。
同样分析 $h(x)$ 在 $(-1, 0)$ 上的单调性：
在 $(-1, 0)$ 内，$\phi(x) = 2e^x - x - 3$ 的最大值为 $\phi(0) = -1 < 0$。
因此 $h'(x) < 0$，函数 $h(x)$ 在 $(-1, 0)$ 上单调递减。
其上界为 $h(-1) = \dfrac{1 - e^{-1}}{e^{-1}-1} = -1$。
故 $t \ge -1$。

**情况 $\text{III}$：$x_2 = 0$**
原不等式变为 $0 \le 1$，对任意 $t$ 均成立。

### 【进阶解法/技巧】

**高维视野：临界值博弈**
在处理这类“总有成立”的问题时，本质上是在寻找 $t$ 的**生存区间**。
$t$ 必须同时满足：
1.  $t \le \min_{x>0} h(x) = x_0 + 2$
2.  $t \ge \max_{x \in (-1, 0)} h(x) = -1$

**关于上界 $5/2$ 的精密验证**：
我们需要判断 $x_0 + 2$ 与 $2.5$ 的大小关系。
已知 $x_0$ 是 $2e^x - x - 3 = 0$ 的根。
测试 $x = 0.5$：
$$\phi(0.5) = 2\sqrt{e} - 0.5 - 3 = 2\sqrt{e} - 3.5 \approx 2(1.648) - 3.5 = 3.296 - 3.5 < 0$$
由于 $\phi(x)$ 单调递增且 $\phi(0.5) < 0$，说明 $x_0 > 0.5$。
因此：
$$h(x_0) = x_0 + 2 > 0.5 + 2 = 2.5$$
这意味着 $t$ 的理论上限是 $x_0+2 \approx 2.58$。
只要 $t < 2.5$，必然满足 $t \le x_0+2$。

**结论**：
综上所述，要使不等式对所有 $a > -2$ 成立，必须满足 $-1 \le t \le x_0 + 2$。
由于 $x_0 + 2 > 2.5$，因此区间 $[-1, 2.5)$ 是该条件的一个充分子集。
证明完毕。

### 【总结与反思】

#### 1. 认知复盘：该题的“骨架”是什么？
本题的本质是 **“参数 $\to$ 根 $\to$ 函数 $\to$ 范围”** 的传递过程。
*   **陷阱点**：很多学生会试图在 $a$ 的表达式中硬算，这会导致计算量爆炸。
*   **突破口**：利用 $x_1+x_2 = -2$ 实现变量统一，将一个关于 $a$ 的复杂问题转化为一个关于 $x$ 的函数极值问题。

#### 2. 解题逻辑模板 (Schema)
面对“证明参数 $t$ 的取值范围”类问题，建议遵循以下链路：
$$\text{特征提取 (韦达定理/同构)} \to \text{变量统一 (消参)} \to \text{分情况讨论 (符号切换)} \to \text{单调性分析 (辅助函数)} \to \text{临界值对比}$$

#### 3. 知识迁移
*   **关联点**：此题中的 $h(x)$ 构造方式在解析几何的“距离最小值”问题或概率分布的“参数估计”中经常出现。
*   **技巧总结**：当导数结果出现 $\phi(x) = 2e^x - x - 3$ 这种无法用初等函数求根的式子时，**不要强求根的精确值**，而应通过**特殊值代入**（如 $x=0.5$）来判定其与目标界限（如 $2.5$）的大小关系。
