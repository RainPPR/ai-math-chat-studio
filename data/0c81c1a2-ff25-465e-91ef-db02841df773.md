# 上篇：等高线映射——第二题的恒等变形技巧

## 一、什么是“等高线”？

对于一个函数 $y = f(x)$，**等高线**就是水平线 $y = k$ 与函数图像的交点。如果函数不是单调的（比如先增后减），那么**同一个函数值 $k$ 可能对应两个不同的自变量**，它们位于极值点的两侧。

```text
        f(x)
         |
    k ___|___  ← 等高线 y = k
         |  /\
         | /  \
         |/    \
         +------------ x
         x₁  x₀  x₂
```

在比较大小的题目中，如果我们能把一个位于递增区间的点，通过等高线“映射”到递减区间，就可以**统一单调性**，然后直接比较自变量大小——这就是“等高线秒杀”的本质。

---

## 二、第二题的“母函数”与等高线发现

### 2.1 母函数的确定

$$a = \frac{\ln 2}{2},\quad b = \frac{\ln 3}{e},\quad c = \frac{\sqrt{2}}{e^{\sqrt{2}}}$$

看到 $c = \frac{\sqrt{2}}{e^{\sqrt{2}}}$，立刻锁定母函数：

$$f(x) = \frac{x}{e^x}$$

验证：$a = \frac{\ln 2}{e^{\ln 2}} = f(\ln 2)$，$c = f(\sqrt{2})$ ✅

至于 $b = \frac{\ln 3}{e} = \ln 3 \cdot \frac{1}{e} = \ln 3 \cdot f(1)$，稍特殊，但也可纳入体系。

### 2.2 $f(x)$ 的单调性画像

$$f'(x) = \frac{1 - x}{e^x}$$

| 区间 | $(0, 1)$ | $(1, +\infty)$ |
|:---:|:--------:|:-------------:|
| 导数符号 | **正** | **负** |
| 单调性 | **递增** | **递减** |

全局最大值在 $x = 1$ 处，$f(1) = \frac{1}{e}$。

图像形如一座“单峰山”：
- 左坡（$(0, 1)$）：上坡，自变量越大，函数值越大
- 右坡（$(1, +\infty)$）：下坡，自变量越大，函数值越小

### 2.3 核心困境：自变量分散在两个单调区间

- $\ln 2 \approx 0.693$，位于**左坡**（递增区间）
- $\sqrt{2} \approx 1.414$，位于**右坡**（递减区间）

我们不能直接说“因为 $\ln 2 < \sqrt{2}$，所以 $f(\ln 2) < f(\sqrt{2})$”——因为它们在**不同的单调区间**上！

这就是等高线技巧登场的时候。

### 2.4 关键一步：恒等变形找到“镜像点”

观察 $a = f(\ln 2) = \dfrac{\ln 2}{e^{\ln 2}} = \dfrac{\ln 2}{2}$。

现在问：**有没有另一个点 $x^*$，在右坡，使得 $f(x^*) = f(\ln 2)$？**

也就是解 $f(x) = \dfrac{\ln 2}{2}$。但是，我们不需要解方程，只需要做一个巧妙的代数变形：

$$\frac{\ln 2}{2} \quad \xrightarrow{\text{分子分母同乘 } 2} \quad \frac{2\ln 2}{4}$$

现在，把分母 $4$ 写成 $e^{\ln 4}$，分子 $2\ln 2$ 写成 $\ln 4$：

$$\frac{\ln 2}{2} = \frac{2\ln 2}{4} = \frac{\ln 4}{e^{\ln 4}} = f(\ln 4)$$

于是我们得到了一个**恒等式**：

$$\boxed{f(\ln 2) = f(\ln 4)}$$

```text
         f(x)
          |
    f(ln2) |------●----------------●------
    =f(ln4)|    (ln2, f)         (ln4, f)
          |   /                    \
          |  /                      \
          | /                        \
          +-------------------------------- x
             0.693    1    1.386
            (左坡)  (峰顶)  (右坡)
```

**为什么是“分子分母同乘 2”？**

因为分母 $2 = e^{\ln 2}$，要变成 $e^{\text{某数}}$ 的形式，我们需要分母变成一个 $e$ 的幂次。观察到 $f(\ln t) = \dfrac{\ln t}{t}$ 的形式，乘以 $\frac{2}{2}$ 得到分母 $4 = e^{\ln 4}$，恰好对上了 $f(\cdot)$ 的结构。

**更一般的发现技巧**：对于 $f(x) = \dfrac{x}{e^x}$，若 $f(\alpha) = \dfrac{\alpha}{e^\alpha}$，可以通过分数基本性质 $\dfrac{\alpha}{e^\alpha} = \dfrac{k\alpha}{k e^\alpha}$，令 $k e^\alpha = e^\beta$（即 $k = e^{\beta - \alpha}$），则 $\dfrac{k\alpha}{e^\beta} = \dfrac{\alpha e^{\beta-\alpha}}{e^\beta}$，这必须等于 $f(\beta) = \dfrac{\beta}{e^\beta}$，从而 $\alpha e^{\beta-\alpha} = \beta$。取 $\alpha = \ln 2$，$\beta = \ln 4$，恰好满足 $\ln 2 \cdot e^{\ln 4 - \ln 2} = \ln 2 \cdot e^{\ln 2} = \ln 2 \cdot 2 = 2\ln 2 = \ln 4$，验证成功。

### 2.5 等高线映射后的比较

现在 $a = f(\ln 4)$，而 $\ln 4 \approx 1.386$。

- $a = f(\ln 4)$ 的输入 $\ln 4$ 在**右坡**
- $c = f(\sqrt{2})$ 的输入 $\sqrt{2} \approx 1.414$ 也在**右坡**

两者统一到了递减区间！在递减区间，**自变量越大，函数值越小**。

因为 $\ln 4 < \sqrt{2}$（$1.386 < 1.414$），所以：

$$f(\ln 4) > f(\sqrt{2}) \quad \implies \quad a > c$$

这就是**等高线映射**的完整逻辑链：

1. **发现** $a$ 的输入在左坡，$c$ 的输入在右坡
2. **通过恒等变形**，将 $a$ “映射”到右坡的等价点 $f(\ln 4)$
3. **统一单调区间后**，直接比较自变量大小
4. **秒杀结论**：$c < a$

## 三、等高线技巧的通用范式

### 3.1 适用条件

- 函数 $f(x)$ 在定义域内有**唯一极值点** $x_0$
- 比较的两个点分别位于极值点两侧
- 存在**简洁的恒等变形**可以将一个点映射到另一侧

### 3.2 操作步骤

| 步骤 | 操作 |
|:---:|------|
| **①** | 确定母函数 $f(x)$ 及其极值点 $x_0$ |
| **②** | 判断两个自变量的位置（同侧/异侧） |
| **③** | 若异侧，对其中一个进行恒等变形：利用 $f(\alpha) = f(\beta)$ 或直接代数等价变形 |
| **④** | 统一到同一单调区间后，比较自变量大小，得函数值大小 |

### 3.3 另一个经典例子

考虑 $a = \dfrac{\ln 3}{3}$ 和 $b = \dfrac{\ln 1.5}{1.5}$，比较大小。

母函数 $f(x) = \dfrac{\ln x}{x}$，其导数 $f'(x) = \dfrac{1 - \ln x}{x^2}$，在 $(0, e)$ 递增，$(e, +\infty)$ 递减。

- $a = f(3)$，$3 > e$，在递减区间
- $b = f(1.5)$，$1.5 < e$，在递增区间

异侧！寻找等高线映射。注意到：

$$a = \frac{\ln 3}{3} = \frac{2\ln 3}{6} = \frac{\ln 9}{6}$$

而 $f(9) = \dfrac{\ln 9}{9}$，不等于 $\dfrac{\ln 9}{6}$。所以这不是 $f(\cdot)$ 的标准形式。换一个思路：$f(3) = \dfrac{\ln 3}{3}$，是否存在 $x$ 使 $f(x) = f(3)$？需要 $\dfrac{\ln x}{x} = \dfrac{\ln 3}{3}$，即 $x^3 = 3^x$。尝试 $x = 3$（平凡解）或另一个解。通过观察，$x = 3^{3/3}?$ 不行。其实 $3^1.5 = 3\sqrt{3} \approx 5.2$，不是整数。这个例子不好，换一个：

**更好例子**：比较 $a = \dfrac{\ln 2}{2}$ 和 $b = \dfrac{\ln 1.2}{1.2}$。

$f(x) = \dfrac{\ln x}{x}$。$a = f(2)$（递减区间，因为 $2 > e$），$b = f(1.2)$（递增区间）。

恒等变形：$\dfrac{\ln 2}{2} = \dfrac{2\ln 2}{4} = \dfrac{\ln 4}{4} = f(4)$。

现在 $a = f(4)$（递减区间），$4 > 1.2$ 吗？但 $1.2$ 在递增区间，不在递减区间。还是异侧。

其实这个例子说明：**等高线映射不一定总是把点拉到同侧**，它只能把一侧的点映射到另一侧。如果另一侧的点还在递增区间，可能需要再次映射。

不过对于第二题，$\sqrt{2}$ 恰好在递减区间，一次映射就统一了。这种“恰好”在出题中是精心设计的。

---

## 四、第二题中 $b$ 的处理技巧

$$b = \frac{\ln 3}{e} = \ln 3 \cdot \frac{1}{e} = \ln 3 \cdot f(1)$$

这里不需要等高线，而是利用**全局最大值**：

- $f(1) = \frac{1}{e}$ 是 $f(x)$ 的全局最大值
- $\ln 3 > 1$
- 因此 $b = \ln 3 \cdot f(1) > 1 \cdot f(1) \ge f(\ln 2) = a$

这是另一种高维视角：**将复杂表达式拆解为“系数 × 极值”的形式**，然后与极值比较。

# 下篇：偏移对称性——第五题的构造逻辑

## 一、问题的几何本质

第五题中，$a = e^{1/4} - \frac{5}{4}$，$b = e^{-1/4} - \frac{3}{4}$。

统一到母函数 $f(x) = e^x - x - 1$：

$$a = f\left(\frac{1}{4}\right),\quad b = f\left(-\frac{1}{4}\right)$$

所以我们要比较 $f(0.25)$ 和 $f(-0.25)$。

从图像上看，$f(x) = e^x - x - 1$ 在 $x=0$ 处取得极小值 $0$，但左右两侧的“翘起速度”不一样：**正半轴的增长远快于负半轴**。这就是“偏移对称性”的几何直觉。

```text
         f(x)
          |        /
          |       /
          |      /
          |     /
          |    /
     f(0.25)  /*
          |  / |
          | /  |
    f(0)=0 ●   |
          |    |
 f(-0.25) |    *
          |   /
          |  /
          +------------------------ x
         -0.25  0  0.25
```

直观上，$f(0.25) > f(-0.25)$，即 $a > b$。如何严格证明？

## 二、核心构造：差值函数 $g(x)$

定义：

$$g(x) = f(x) - f(-x),\quad x > 0$$

如果 $g(x) > 0$ 对所有 $x > 0$ 成立，那么 $f(x) > f(-x)$，问题解决。

### 2.1 计算 $g(x)$ 的具体形式

$$g(x) = (e^x - x - 1) - (e^{-x} + x - 1) = e^x - e^{-x} - 2x$$

这个式子有什么特点？
- $g(0) = 0$（平凡）
- $g(x)$ 是**奇函数**吗？检查：$g(-x) = e^{-x} - e^x + 2x = -g(x)$，确实是奇函数。
- 我们只需要证明 $g(x) > 0$ 对于 $x > 0$。

### 2.2 导数分析

$$g'(x) = e^x + e^{-x} - 2$$

由**均值不等式（AM-GM）**：

$$e^x + e^{-x} \ge 2\sqrt{e^x \cdot e^{-x}} = 2$$

等号当且仅当 $e^x = e^{-x}$，即 $x = 0$ 时成立。

因此对于 $x > 0$，$g'(x) > 0$ 严格成立。

这意味着 $g(x)$ 在 $(0, +\infty)$ 上**严格单调递增**。

$$g(x) > g(0) = 0 \quad \text{对任意 } x > 0 \text{ 成立。}$$

**结论**：$f(x) > f(-x)$ 对所有 $x > 0$ 成立。代入 $x = \frac{1}{4}$，即得 $a > b$。

---

## 三、为什么想到构造 $g(x) = f(x) - f(-x)$？

这不是凭空而来的技巧，它有深刻的数学直觉来源：

### 3.1 函数的“奇偶分解”

任何函数 $f(x)$ 都可以唯一地分解为偶函数部分和奇函数部分：

$$f(x) = \underbrace{\frac{f(x) + f(-x)}{2}}_{\text{偶部 } f_{\text{even}}(x)} + \underbrace{\frac{f(x) - f(-x)}{2}}_{\text{奇部 } f_{\text{odd}}(x)}$$

而我们构造的 $g(x) = f(x) - f(-x) = 2 f_{\text{odd}}(x)$，正是**奇部的两倍**。

对于 $f(x) = e^x - x - 1$：

- **偶部**：$f_{\text{even}}(x) = \dfrac{(e^x - x - 1) + (e^{-x} + x - 1)}{2} = \dfrac{e^x + e^{-x}}{2} - 1 = \cosh x - 1 \ge 0$
- **奇部**：$f_{\text{odd}}(x) = \dfrac{(e^x - x - 1) - (e^{-x} + x - 1)}{2} = \dfrac{e^x - e^{-x}}{2} - x = \sinh x - x$

所以 $g(x) = 2(\sinh x - x)$。

而 $\sinh x > x$ 对所有 $x > 0$ 成立（这是双曲正弦的基本不等式）。因此 $g(x) > 0$。

### 3.2 “偏移”的几何含义

“偏移对称性”这个词的意思是：$f(x)$ 不是真正的偶函数，它在 $x=0$ 两侧**不对称**。奇部 $\sinh x - x$ 衡量了这种**偏离对称的程度**。

- 如果奇部为正，说明 $f(x)$ 比 $f(-x)$ 大——函数在正半轴“翘得更高”
- 如果奇部为负，说明 $f(x)$ 比 $f(-x)$ 小——函数在负半轴“沉得更深”

由于 $f(x) = e^x - x - 1$ 中，$e^x$ 是指数增长，而 $e^{-x}$ 只是趋近于 $0$，在正半轴的增长必然压倒负半轴，所以 $f(x) > f(-x)$ 是自然的。

---

## 四、该技巧的通用范式

### 4.1 适用条件

- 需要比较 $f(p)$ 和 $f(q)$，且 $p$ 和 $q$ 关于某点 $x_0$ **对称**（即 $p + q = 2x_0$）
- 最常见的是比较 $f(x)$ 和 $f(-x)$（关于原点对称）

### 4.2 操作步骤

| 步骤 | 操作 |
|:---:|------|
| **①** | 确认需要比较 $f(a)$ 和 $f(b)$，且 $a + b = 0$（或关于某点对称） |
| **②** | 构造 $g(x) = f(x) - f(-x)$（若对称中心不是原点，则作平移变换） |
| **③** | 求导，利用基本不等式（如 AM-GM、柯西等）判断 $g'(x)$ 的符号 |
| **④** | 由 $g(0) = 0$ 和单调性，确定 $g(x)$ 在 $x > 0$ 时的符号 |
| **⑤** | 得出结论 |

### 4.3 扩展到非原点对称

若需要比较 $f(1 + t)$ 和 $f(1 - t)$（关于 $x = 1$ 对称），构造：

$$h(t) = f(1 + t) - f(1 - t)$$

类似地分析 $h'(t)$ 的符号即可。

### 4.4 另一个经典例子

比较 $\displaystyle a = e^{0.2} - 1.2$ 和 $\displaystyle b = e^{-0.2} - 0.8$。

母函数 $f(x) = e^x - x - 1$：

$$a = f(0.2),\quad b = f(-0.2)$$

直接套用上面的结论：$f(0.2) > f(-0.2)$，即 $a > b$。

---

## 五、两个技巧的对比总结

| 维度 | **等高线映射**（第二题） | **偏移对称性**（第五题） |
|:---:|:----------------------:|:----------------------:|
| **问题特征** | 比较的两个点位于极值点**两侧**，单调性不同 | 比较的两个点关于某点**对称**（如 $x$ 与 $-x$） |
| **核心思想** | 用恒等变形将一侧的点“映射”到另一侧，统一单调性 | 构造差值函数，利用函数的奇部分析不对称性 |
| **关键操作** | 寻找 $f(\alpha) = f(\beta)$ 的代数恒等式 | 构造 $g(x) = f(x) - f(-x)$，求导判号 |
| **数学根基** | 函数的单峰性质 + 分数恒等变形 | 函数的奇偶分解 + AM-GM / 基本不等式 |
| **几何直觉** | “翻山”——从山的一面沿等高线走到另一面 | “看翘”——比较函数在对称轴两侧的翘起高度 |

---

## 🎓 终极心法

当你下次看到类似题目时，试着问自己两个问题：

1. **“这几个数，本质上是不是同一个函数在不同点的取值？”**
   👉 如果是，且它们分布在极值点两侧 → **等高线映射**

2. **“要比较的两个自变量，是不是关于某条对称轴对称？”**
   👉 如果是 → **差值函数 $g(x) = f(x_0 + t) - f(x_0 - t)$**

这两招一旦内化为本能，你就能在 30 秒内找到多数压轴比较题的“题眼”。数学的美，正在于这种**结构洞察**——不是算出来的，而是“看”出来的。

## 方法一（★推荐）：整体换元——设根号为“新世界的主角”

这个方法的灵感很简单：既然题目中 $c=\sqrt{1.04}-1$ 带着个碍眼的根号，为什么不直接把整个根号设成一个新变量，把 $\ln$ 也纳入它的体系呢？

### 1. 令 $u=\sqrt{1.04}$

因为 $1.04>1$，所以 $u>1$。

现在，我们**用 $u$ 重写所有表达式**。

**重写 $c$**：
$$c = u-1$$

**重写 $b$**：
注意到 $1.02 = \frac{2.04}{2} = \frac{1.04+1}{2} = \frac{u^2+1}{2}$。
因此：
$$b = \ln 1.02 = \ln\frac{u^2+1}{2}$$

**重写 $a$**：
注意到 $1.01^2 = 1.0201 = \frac{4.0404}{4}$？等一下，更漂亮的是：
$1.01 = \frac{4.04}{4} = \frac{1.04+3}{4} = \frac{u^2+3}{4}$。
因此：
$$a = 2\ln 1.01 = 2\ln\frac{u^2+3}{4}$$

### 2. 比较 $\boldsymbol{b}$ 和 $\boldsymbol{c}$

构造函数：
$$F(u) = \ln\frac{u^2+1}{2} - (u-1),\quad u \ge 1$$

求导（注意链式法则）：
$$F'(u) = \frac{1}{\frac{u^2+1}{2}} \cdot \frac{2u}{2} - 1 = \frac{2u}{u^2+1} - 1 = \frac{2u - u^2 - 1}{u^2+1} = \frac{-(u-1)^2}{u^2+1}$$

由于 $(u-1)^2 \ge 0$，所以 $F'(u) \le 0$ 对所有 $u \ge 1$ 成立，等号仅当 $u=1$。

因此 $F(u)$ 在 $[1, +\infty)$ 上**严格单调递减**。

$$F(u) < F(1) = \ln\frac{1+1}{2} - 0 = \ln 1 - 0 = 0$$

所以 $F(u) < 0$，即 **$\ln\frac{u^2+1}{2} < u-1$**，也就是 **$b < c$**。

✅ 完全没有遇到复杂的根式比较，只是一个简单的分式函数求导。

### 3. 比较 $\boldsymbol{c}$ 和 $\boldsymbol{a}$

构造函数：
$$G(u) = 2\ln\frac{u^2+3}{4} - (u-1),\quad u \ge 1$$

求导：
$$G'(u) = 2 \cdot \frac{1}{\frac{u^2+3}{4}} \cdot \frac{2u}{4} - 1 = 2 \cdot \frac{4}{u^2+3} \cdot \frac{u}{2} - 1 = \frac{4u}{u^2+3} - 1$$
$$= \frac{4u - u^2 - 3}{u^2+3} = \frac{-(u^2 - 4u + 3)}{u^2+3} = \frac{-(u-1)(u-3)}{u^2+3}$$

现在分析符号：
- 分母 $u^2+3 > 0$ 恒成立
- 我们关心的点是 $u = \sqrt{1.04} \approx 1.0198$，属于区间 $(1, 3)$

在 $u \in (1, 3)$ 内：
- $(u-1) > 0$
- $(u-3) < 0$
- 乘积 $(u-1)(u-3) < 0$
- 前面有个负号，所以 $G'(u) > 0$

因此 $G(u)$ 在 $[1, 3]$ 上严格单调递增。

$$G(u) > G(1) = 2\ln\frac{1+3}{4} - 0 = 2\ln 1 = 0$$

所以 $G(u) > 0$，即 **$2\ln\frac{u^2+3}{4} > u-1$**，也就是 **$a > c$**。

✅ 同样非常简单，导数符号由二次函数 $u^2-4u+3$ 的根直接决定。

已证 $b < c$ 且 $c < a$，故 **$b < c < a$**。

## 方法二：对被积函数直接比大小（积分视角）

你卡住的那个 $G'(x)$，其实可以换一个角度理解。

注意到 $\ln(1+x) = \int_0^x \frac{1}{1+t}\,dt$，而 $\sqrt{1+4x}-1 = \int_0^x \frac{2}{\sqrt{1+4t}}\,dt$。

因此：
$$a = 2\ln 1.01 = \int_0^{0.01} \frac{2}{1+t}\,dt$$
$$c = \sqrt{1.04}-1 = \int_0^{0.01} \frac{2}{\sqrt{1+4t}}\,dt$$

现在比较被积函数：对于 $t \in (0, 0.01]$，我们要判断 $\frac{2}{1+t}$ 和 $\frac{2}{\sqrt{1+4t}}$ 谁大。

等价于判断 $1+t$ 和 $\sqrt{1+4t}$ 谁小。

两边平方（都是正数）：
$$(1+t)^2 = 1+2t+t^2,\quad (\sqrt{1+4t})^2 = 1+4t$$

由于 $t \in (0, 0.01]$，$t^2 < 2t$ 吗？$t < 2$ 时成立，而 $t \le 0.01$ 当然满足。

因此 $(1+t)^2 < 1+4t \implies 1+t < \sqrt{1+4t} \implies \frac{2}{1+t} > \frac{2}{\sqrt{1+4t}}$。

被积函数在整个积分区间上严格更大，所以积分值也严格更大：
$$\int_0^{0.01} \frac{2}{1+t}\,dt > \int_0^{0.01} \frac{2}{\sqrt{1+4t}}\,dt \implies a > c$$

**这个方法的好处**：把“构造函数求导再分析导函数符号”变成了“比较两个被积函数再积分”，逻辑链条更短。而且那个平方比较 $t^2 < 2t$ 因为 $t$ 极小，变得非常显然（甚至不需要写 $t<2$，直接说 $t=0.01$ 时 $t^2=0.0001 \ll 0.02=2t$ 即可）。

### 对 $b$ 和 $c$ 同理：
$$b = \ln 1.02 = \int_0^{0.02} \frac{1}{1+t}\,dt,\quad c = \sqrt{1.04}-1 = \int_0^{0.02} \frac{2}{\sqrt{1+4t}}\,dt$$

比较 $\frac{1}{1+t}$ 和 $\frac{2}{\sqrt{1+4t}}$：由于 $1+t < \sqrt{1+4t}$ 对小的 $t$ 成立，所以 $\frac{1}{1+t} < \frac{2}{\sqrt{1+4t}}$。

积分得 $b < c$。

**不过要稍微注意**：这里比较 $b$ 和 $c$ 时，自变量是 $0.02$，而 $c$ 的积分上限应该是多少？重新检查：$c=\sqrt{1.04}-1$。令 $x=0.02$，$\sqrt{1+2x}-1 = \int_0^{x} \frac{1}{\sqrt{1+2t}}\,dt$。对，前面的系数是 1 不是 2。所以严格写应该是：
$b = \ln(1+0.02) = \int_0^{0.02} \frac{1}{1+t}\,dt$
$c = \sqrt{1+2\cdot 0.02}-1 = \int_0^{0.02} \frac{1}{\sqrt{1+2t}}\,dt$
比较被积函数 $\frac{1}{1+t}$ 和 $\frac{1}{\sqrt{1+2t}}$，平方后：$(1+t)^2 = 1+2t+t^2 > 1+2t$，所以 $1+t > \sqrt{1+2t}$，从而 $\frac{1}{1+t} < \frac{1}{\sqrt{1+2t}}$，积分得 $b < c$。

**所以积分法也完全避开了导数符号的复杂判断**，只是将问题转化为了在很小的区间上比较两个简单函数的大小——这往往可以通过直接代数放缩或平方完成。
