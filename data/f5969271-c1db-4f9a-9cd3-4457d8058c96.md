这道题目是一道经典的**不放回抽样与等待时间问题**，在概率论中属于**负超几何分布**的变体。这类问题在高考压轴题或竞赛中频频出现。

下面我将为你展示两种截然不同的解题视野：一种是立足于考场的**代数硬核推导**（常规解法），另一种则是站在高维视角、利用对称性瞬间秒杀的**“对称等分法”**（进阶解法）。

### 【常规解法】分布律与组合恒等式

这是在考场上最稳健、最容易想到的标准路径。我们通过写出随机变量 $X$ 的分布律，利用二项式系数的性质进行求和。

#### 第一步：确定 $X$ 的取值范围与概率分布

设非黄球（红球与黑球的总和）个数为 $m = N - n$。
最后一个黄球被取出时，总共取出的球数 $X$ 的可能取值为：
$$X \in \{n, \, n+1, \, \dots, \, N\}$$

事件 $\{X = k\}$ 发生，意味着：
1. **在第 $k$ 次取球时，取出的是黄球**；
2. **在前 $k-1$ 次取球中，恰好取出了 $n-1$ 个黄球**（剩下的 $k-n$ 个是非黄球）。

我们将 $N$ 个球的取出顺序看作一个随机排列，所有排列方案数为 $\binom{N}{n}$（只需决定 $n$ 个黄球在 $N$ 个位置中的哪几个即可）。
满足 $\{X = k\}$ 的方案数为：
第 $k$ 个位置固定为黄球，前 $k-1$ 个位置中任意选 $n-1$ 个放置黄球，即 $\binom{k-1}{n-1}$。

因此，$X$ 的概率分布律为：

$$P(X = k) = \frac{\binom{k-1}{n-1}}{\binom{N}{n}}, \quad k = n, n+1, \dots, N$$


#### 第二步：计算数学期望 $E(X)$

根据数学期望的定义：

$$E(X) = \sum_{k=n}^{N} k \cdot P(X = k) = \sum_{k=n}^{N} k \frac{\binom{k-1}{n-1}}{\binom{N}{n}}$$

由于 $\binom{N}{n}$ 是常数，可以提到求和号外面。我们重点处理求和项 $k \binom{k-1}{n-1}$。利用组合数的吸收公式：

$$k \binom{k-1}{n-1} = k \cdot \frac{(k-1)!}{(n-1)!(k-n)!} = n \cdot \frac{k!}{n!(k-n)!} = n \binom{k}{n}$$

代入期望公式中，得：

$$E(X) = \frac{n}{\binom{N}{n}} \sum_{k=n}^{N} \binom{k}{n}$$


#### 第三步：利用朱世杰恒等式求和

利用经典的朱世杰恒等式（Hockey-stick Identity）：
$$\sum_{i=r}^{n} \binom{i}{r} = \binom{n+1}{r+1}$$

对本题的求和项进行转化：

$$\sum_{k=n}^{N} \binom{k}{n} = \binom{N+1}{n+1}$$

因此，期望值为：

$$E(X) = \frac{n \binom{N+1}{n+1}}{\binom{N}{n}}$$

展开组合数进行化简：

$$E(X) = n \cdot \frac{\frac{(N+1)!}{(n+1)!(N-n)!}}{\frac{N!}{n!(N-n)!}} = n \cdot \frac{N+1}{n+1} = \frac{n(N+1)}{n+1}$$

### 【进阶解法】对称等分法（一句话秒杀）

如果你拥有更高的数学直观，你会发现这道题的代数演算其实掩盖了极其美丽的物理对称性。

#### 核心直观：间隔的对称性

我们将 $N$ 个球随机排列在一行。其中有 $n$ 个黄球，以及 $m = N-n$ 个非黄球。

这 $n$ 个黄球作为“隔板”，天然地将这 $m$ 个非黄球分割成了 $n+1$ 个区间：
* $Y_1$：第 $1$ 个黄球左边的非黄球个数；
* $Y_2$：第 $1$ 个与第 $2$ 个黄球之间的非黄球个数；
* $\dots$
* $Y_{n+1}$：最后（第 $n$ 个）黄球右边的非黄球个数。

由于不放回随机抽取的等可能性，这 $N$ 个球的任何排列都是等概率出现的。这意味着**每个非黄球落入这 $n+1$ 个区间的概率是完全均等的**。

根据对称性与期望的线性性质，这 $n+1$ 个区间内非黄球个数的期望值必然完全相等：

$$E(Y_1) = E(Y_2) = \dots = E(Y_{n+1})$$

因为非黄球的总数是 $N-n$，所以：

$$\sum_{i=1}^{n+1} E(Y_i) = N - n \implies E(Y_{n+1}) = \frac{N-n}{n+1}$$

#### 建立与 $X$ 的关系

最后一个黄球被取出时，总共取出的球数 $X$ 是多少？
很显然，我们**没有取出来**的球，恰好就是**最后一个黄球之后的那些非黄球**（个数为 $Y_{n+1}$）。
因此，有恒等式：

$$X = N - Y_{n+1}$$

两边取期望：

$$E(X) = E(N - Y_{n+1}) = N - E(Y_{n+1})$$

代入 $E(Y_{n+1})$ 的值：

$$E(X) = N - \frac{N-n}{n+1} = \frac{N(n+1) - (N-n)}{n+1} = \frac{n(N+1)}{n+1}$$

无需任何复杂的二项式定理和组合数求和，答案跃然纸上！

---

### 【总结与反思】元认知复盘

1. **极端值与特例检验**：
   * 若 $n = N$（全是黄球），带入公式得 $E(X) = \frac{N(N+1)}{N+1} = N$，显然正确，因为必须取完所有 $N$ 个球。
   * 若 $N=3, n=2$，公式给出 $E(X) = \frac{2 \times 4}{3} = \frac{8}{3}$。手动列举排列（Y-Y-R, Y-R-Y, R-Y-Y）对应的 $X$ 分别为 $2, 3, 3$，均值确实为 $\frac{2+3+3}{3} = \frac{8}{3}$。

2. **方法论迁移（Schema Transfer）**：
   这种“对称隔板法”不仅适用于本题，在解决以下场景时同样是降维打击：
   * **抽签的公平性**：为什么第 $k$ 个人抽中某张签的概率与第一个人一样？（因为排列的对称性）
   * **洗牌问题**：一幅牌随机洗好，第一张 A 出现的位置期望、最后一张 A 出现的位置期望。
   * **几何概率**：在区间 $[0, 1]$ 上随机撒 $n$ 个点，将区间分成 $n+1$ 段，每段长度的期望均为 $\frac{1}{n+1}$。

**结论**：在处理“不放回抽样中某类元素首次/最后一次出现的位置”时，**将“目标元素”视为隔板，将“其余元素”视为被分隔的对称区间**，是突破计算瓶颈的最强思维武器。

### 路径一：代数递推法（利用帕斯卡恒等式）

这种方法的底层逻辑是利用组合数最基础的性质：**帕斯卡恒等式（Pascal's Identity）**
$$\binom{k}{r} + \binom{k}{r+1} = \binom{k+1}{r+1}$$
*（直观理解：从 $k+1$ 个元素中选 $r+1$ 个，要么包含最后一个元素，要么不包含。）*

我们要计算的式子是 $\binom{n}{n} + \binom{n+1}{n} + \binom{n+2}{n} + \dots + \binom{N}{n}$。

**关键技巧：给第一个项“变身”**
注意，$\binom{n}{n} = 1$，而 $\binom{n+1}{n+1}$ 也等于 $1$。
我们把第一项 $\binom{n}{n}$ 替换成 $\binom{n+1}{n+1}$，然后开始像多米诺骨牌一样触发链式反应：

1. **第一步（触发）：**
   $$\underbrace{\binom{n+1}{n+1} + \binom{n+1}{n}}_{\text{利用帕斯卡恒等式}} = \binom{n+2}{n+1}$$

2. **第二步（传递）：**
   将上一步的结果与第三项合并：
   $$\underbrace{\binom{n+2}{n+1} + \binom{n+2}{n}}_{\text{再次利用帕斯卡恒等式}} = \binom{n+3}{n+1}$$

3. **第三步（循环）：**
   继续合并：
   $$\underbrace{\binom{n+3}{n+1} + \binom{n+3}{n}}_{\text{再次利用}} = \binom{n+4}{n+1}$$

4. **最终步（收尾）：**
   当你一直这样合并到最后一项 $\binom{N}{n}$ 时，你会发现结果变成了：
   $$\binom{N}{n+1} + \binom{N}{n} = \mathbf{\binom{N+1}{n+1}}$$

**总结：** 只要你记得 $\binom{n}{n} = \binom{n+1}{n+1}$，你就可以通过不断的“两两合并”，将整个求和序列压缩成一个单一的组合数。

### 路径二：组合计数法（用逻辑直觉化简）

如果你不想算，可以用“讲故事”的方法。
我们要计算的是：$\sum_{k=n}^{N} \binom{k}{n}$ 的结果是什么？

**尝试给这个数学式子建立一个物理场景：**
想象你有 $N+1$ 个标号为 $\{1, 2, 3, \dots, N+1\}$ 的球，现在你要从中随机取出 $n+1$ 个球。
**总的方案数显然是 $\binom{N+1}{n+1}$。**

现在，我们换一种方式来数这些方案。我们关注这 $n+1$ 个球中**标号最大的那个球**是多少：

* **情况 1**：最大的球标号是 $n+1$。
  那么剩下的 $n$ 个球必须从前 $n$ 个标号 $\{1, \dots, n\}$ 中选。方案数：$\binom{n}{n}$。
* **情况 2**：最大的球标号是 $n+2$。
  那么剩下的 $n$ 个球必须从前 $n+1$ 个标号 $\{1, \dots, n+1\}$ 中选。方案数：$\binom{n+1}{n}$。
* **情况 3**：最大的球标号是 $n+3$。
  那么剩下的 $n$ 个球必须从前 $n+2$ 个标号中选。方案数：$\binom{n+2}{n}$。
* $\dots$
* **情况末**：最大的球标号是 $N+1$。
  那么剩下的 $n$ 个球必须从前 $N$ 个标号 $\{1, \dots, N\}$ 中选。方案数：$\binom{N}{n}$。

因为最大值的取值是互斥的（最大值要么是 $n+1$，要么是 $n+2 \dots$），所以把所有情况相加，就是总的选取方案数：
$$\binom{n}{n} + \binom{n+1}{n} + \dots + \binom{N}{n} = \binom{N+1}{n+1}$$

    $$P(L_Y > L_R \text{ or } L_Y > L_B) = P(L_Y > L_R) + P(L_Y > L_B) - P(L_Y > L_R \text{ and } L_Y > L_B)$$

        $$P(L_Y > L_R) = \frac{\text{Number of Yellows}}{\text{Number of Yellows} + \text{Number of Reds}} = \frac{5}{5 + 5} = \frac{1}{2}$$

### 【常规解法】后缀排布与状态分类（代数推导框架）

在常规思路中，我们关注**最后一个黄球出现的位置**。

设最后一个黄球在第 $k$ 次被取出（$5 \le k \le 18$），则第 $k$ 次之后还剩 $20-k$ 个位置。
要满足“盒子内还有红球和黑球”，意味着：
1. 第 $k$ 次之后的所有球中，**不能没有红球**（即不能全为黑球）；
2. 第 $k$ 次之后的所有球中，**不能没有黑球**（即不能全为红球）。

我们设 $s = 20 - k$ 为第 $k$ 次之后剩余的位置数（$2 \le s \le 15$）。
对于固定的 $s$，总的排布方式需要先在前面 $20-s-1$ 个位置中选 $4$ 个放黄球，再在剩下的位置中排布红、黑球。

若用 $P(s)$ 表示在剩余 $s$ 个位置中既有红球又有黑球的概率，则需要对红球的个数 $j$ 进行复杂的分类讨论：

$$\text{满足条件的排布数} = \sum_{s=2}^{15} \binom{20-s-1}{4} \left[ \binom{15}{5} - \binom{15-s}{5} - \binom{15-s}{5-s} \right]$$

这个求和式中嵌套了多项组合数的乘积与相减，在有限的考试时间内，**几乎无法保证计算的零失误**。

### 【进阶解法】投影法 + 容斥原理（1分钟秒杀）

现在，我们跳出具体的“位置”限制，站在**相对顺序**的高维视角来审视这个问题。

#### 第一步：翻译数学语言
设 $L_Y, L_R, L_B$ 分别为**最后一个**黄球、红球、黑球被取出的位置（即 $1$ 到 $20$ 中的某个序号）。
“黄球最先被全部取出”这一事件，等价于：**最后一个黄球的位置，比最后一个红球和最后一个黑球的位置都要靠前**。

即我们要计算的概率为：
$$P(L_Y < L_R \text{ 且 } L_Y < L_B)$$

#### 第二步：引入对立事件与容斥原理
直接求 $L_Y$ 最小比较困难，我们求其对立事件（最大值在 $L_Y$ 端）：
$$P(L_Y < L_R \text{ 且 } L_Y < L_B) = 1 - P(L_Y > L_R \text{ 或 } L_Y > L_B)$$

根据**容斥原理**，并集概率可以展开为：
$$P(L_Y > L_R \text{ 或 } L_Y > L_B) = P(L_Y > L_R) + P(L_Y > L_B) - P(L_Y > L_R \text{ 且 } L_Y > L_B)$$

#### 第三步：利用“投影法”瞬间化简子概率
这是本题灵魂所在。由于球的排列是随机的，当我们只关心某两种颜色的相对顺序时，**可以完全忽略第三种颜色**（这在概率论中称为“边际分布”或“投影”）。

1. **求 $P(L_Y > L_R)$**：
   * 含义：最后一个黄球在最后一个红球之后。
   * 投影：我们**只看黄球和红球**（共 $5+5=10$ 个球），完全不管黑球。
   * 在这 $10$ 个球的随机排列中，最后一个球是黄球的概率，显然就是：
     $$P(L_Y > L_R) = \frac{\text{黄球数}}{\text{黄球数} + \text{红球数}} = \frac{5}{5 + 5} = \frac{1}{2}$$

2. **求 $P(L_Y > L_B)$**：
   * 含义：最后一个黄球在最后一个黑球之后。
   * 投影：我们**只看黄球和黑球**（共 $5+10=15$ 个球），完全不管红球。
   * 在这 $15$ 个球的随机排列中，最后一个球是黄球的概率：
     $$P(L_Y > L_B) = \frac{\text{黄球数}}{\text{黄球数} + \text{黑球数}} = \frac{5}{5 + 10} = \frac{1}{3}$$

3. **求 $P(L_Y > L_R \text{ 且 } L_Y > L_B)$**：
   * 含义：最后一个黄球比红球、黑球都晚出现。也就是**全场最后一个球是黄球**。
   * 这时我们要看所有的 $20$ 个球。最后一个位置是黄球的概率：
     $$P(L_Y > L_R \text{ 且 } L_Y > L_B) = \frac{\text{黄球数}}{\text{总球数}} = \frac{5}{20} = \frac{1}{4}$$

#### 第四步：合流得出答案
将上述三个投影概率代入容斥原理公式中：

$$P(L_Y > L_R \text{ 或 } L_Y > L_B) = \frac{1}{2} + \frac{1}{3} - \frac{1}{4} = \frac{6 + 4 - 3}{12} = \frac{7}{12}$$

因此，黄球最先被全部取出的概率为：

$$P(L_Y < L_R \text{ 且 } L_Y < L_B) = 1 - \frac{7}{12} = \frac{5}{12}$$
