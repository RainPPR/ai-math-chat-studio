这是一道典型的对数比较问题。这类题目的核心在于**“统一基底”**与**“符号判定”**。很多学生在处理时容易陷入繁琐的数值估算，而高级的解法应当是通过构造统一的变量，将比较大小问题转化为函数性质或代数不等式的判定问题。

---

### 【元解析与特征挖掘】

**1. 结构分量识别：**
- $a = \log_{0.2} 0.3$：底数 $\in (0, 1)$，真数 $\in (0, 1)$ $\implies a > 0$。
- $b = \log_2 0.3$：底数 $> 1$，真数 $\in (0, 1)$ $\implies b < 0$。

**2. 关键指纹：**
观察到 $a$ 和 $b$ 的真数相同（均为 $0.3$），但底数不同。底数 $0.2 = 1/5$ 与底数 $2$ 之间存在对数转换关系。这意味着我们可以通过**换底公式**将 $a$ 用 $b$ 来表示，从而将三者的比较转化为关于单个变量 $b$ 的讨论。

**3. 路径博弈：**
- **暴力路径**：尝试估算 $\log_2 0.3$ 的具体数值（如 $-1.737$），然后计算。这种方法在考场上极易出错且缺乏逻辑美感。
- **优雅路径**：统一基底 $\to$ 符号判定 $\to$ 构造差值 $\to$ 利用对数运算性质化简。

---

### 【常规解法】

**第一步：判定基础符号**
由对数函数的单调性可知：
- 对于 $a = \log_{0.2} 0.3$，由于 $0.2 < 0.3 < 1$，且底数 $0.2 \in (0, 1)$，则 $a > 0$。
- 对于 $b = \log_2 0.3$，由于 $0.3 < 1$，且底数 $2 > 1$，则 $b < 0$。

由此直接得出：
- **$ab$ 的符号**：正 $\times$ 负 $=$ 负 $\implies ab < 0$。
- **$a+b$ 的符号**：需要进一步分析。

**第二步：统一基底，分析 $a+b$**
利用换底公式 $\log_M N = \frac{\log_k N}{\log_k M}$，将 $a$ 统一到基底 $2$：
$$a = \log_{0.2} 0.3 = \frac{\log_2 0.3}{\log_2 0.2} = \frac{b}{\log_2 (1/5)} = \frac{b}{-\log_2 5}$$
则 $a+b$ 可表示为：
$$a+b = \frac{b}{-\log_2 5} + b = b \left( 1 - \frac{1}{\log_2 5} \right)$$
因为 $5 > 2^2$，所以 $\log_2 5 > 2$，进而 $0 < \frac{1}{\log_2 5} < \frac{1}{2}$。
所以 $\left( 1 - \frac{1}{\log_2 5} \right) > 0$。
由于 $b < 0$，故 **$a+b < 0$**。

**第三步：比较 $ab$ 与 $a+b$**
考察差值 $ab - (a+b)$：
$$ab - (a+b) = a(b-1) - b$$
代入 $a = \frac{b}{-\log_2 5}$：
$$ab - (a+b) = \frac{b(b-1)}{-\log_2 5} - b = \frac{b^2 - b}{-\log_2 5} - b$$
通分得：
$$ab - (a+b) = \frac{b^2 - b + b\log_2 5}{-\log_2 5} = \frac{b(b + \log_2 5 - 1)}{-\log_2 5}$$
现在分析分子中 $(b + \log_2 5 - 1)$ 的符号：
$$b + \log_2 5 - 1 = \log_2 0.3 + \log_2 5 - \log_2 2 = \log_2 \left( \frac{0.3 \times 5}{2} \right) = \log_2 0.75$$
由于 $0.75 < 1$，故 $\log_2 0.75 < 0$。

综合符号判定：
- $b < 0$
- $b + \log_2 5 - 1 < 0$
- $-\log_2 5 < 0$
则 $ab - (a+b) = \frac{(-) \times (-)}{(-)} = \frac{(+)}{(-)} < 0$。
所以 **$ab < a+b$**。

**结论：**
$$ab < a+b < 0$$

---

### 【进阶解法/技巧】

对于竞赛级选手，可以通过**对偶构造法**快速锁定答案。

**核心技巧：构造单变量函数**
令 $x = \log_2 0.3$（已知 $x < 0$），且令 $k = \log_2 5$（已知 $k > 2$）。
则 $a = -\frac{x}{k}, b = x$。
我们要比较的是：
1. $ab = -\frac{x^2}{k}$
2. $a+b = x - \frac{x}{k} = \frac{x(k-1)}{k}$
3. $0$

由于 $x < 0$ 且 $k > 1$，显然 $ab < 0$ 且 $a+b < 0$。
比较 $ab$ 和 $a+b$，等价于比较 $-\frac{x^2}{k}$ 和 $\frac{x(k-1)}{k}$。
两边同除以 $\frac{x}{k}$（注意 $\frac{x}{k} < 0$，不等号反向）：
$$-x \quad \text{vs} \quad k-1$$
即比较 $k-1+x$ 的符号。
$$k-1+x = \log_2 5 - \log_2 2 + \log_2 0.3 = \log_2 \left( \frac{5 \times 0.3}{2} \right) = \log_2 0.75 < 0$$
既然 $k-1+x < 0$，说明 $k-1 < -x$。
在除以负数 $\frac{x}{k}$ 之前，我们有 $\frac{x(k-1)}{k} > \frac{x(-x)}{k} = -\frac{x^2}{k}$。
因此 $a+b > ab$。

### 【总结与反思】

**1. 认知模型提炼：**
本题的解题逻辑可以抽象为：
$$\text{真数相同} \xrightarrow{\text{换底}} \text{单变量化} \xrightarrow{\text{差值分析}} \text{符号判定}$$

**2. 易错点警示：**
- **符号陷阱**：在处理 $\log_{0.2} 0.3$ 时，容易忘记底数在 $(0,1)$ 之间会导致单调性相反，从而误判 $a$ 的正负。
- **除法反向**：在比较 $ab$ 与 $a+b$ 时，若通过除法消项，必须极其审慎地对待除数的正负号。

**3. 迁移场景：**
当你遇到形如 $\log_{f(x)} g(x)$ 和 $\log_{h(x)} g(x)$ 的比较时，永远优先考虑：
- 是否可以通过换底公式统一成同一个基底？
- 是否可以通过 $\log_M N = \frac{1}{\log_N M}$ 将真数变为底数？
- 最终目标是构造出 $\log_k (\text{常数})$ 这种可以直接判定符号的形式。
