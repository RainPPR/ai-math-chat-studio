这是一道典型的组合概率问题，涉及到离散型随机变量的分布及其数学期望。从本质上来看，这是一个**超几何分布（Hypergeometric Distribution）**的模型：在不放回抽样的情况下，研究样本中具有某种特定属性的个体数量。

### 🚀 元解析与特征挖掘

*   **核心结构**：总体数量 $N=8$，目标群体（A, B, C）数量 $M=3$，抽样数量 $n=3$。
*   **随机变量 $X$**：被选中的目标群体数量。由于我们选 3 个，而目标群体共有 3 个，因此 $X$ 的可能取值为 $\{0, 1, 2, 3\}$。
*   **模型识别**：这是一个典型的“从有限总体中不放回抽取”问题 $\implies$ **超几何分布**。

---

### 【常规解法：组合计数法】

我们将通过计算每种情况的组合数，除以总的样本空间大小来确定分布列。

#### 1. 计算总样本空间
从 8 个物品中随机选出 3 个的总方法数为：
$$\Omega = \binom{8}{3} = \frac{8 \times 7 \times 6}{3 \times 2 \times 1} = 56$$

#### 2. 计算 $X$ 各取值的概率 $P(X=k)$
根据组合公式，选出 $k$ 个目标物品且选出 $(3-k)$ 个非目标物品（共 $8-3=5$ 个）的方法数为 $\binom{3}{k} \times \binom{5}{3-k}$。

*   **当 $X=0$ 时**（A, B, C 均未被选中）：
    $$P(X=0) = \frac{\binom{3}{0} \binom{5}{3}}{56} = \frac{1 \times 10}{56} = \frac{10}{56} = \frac{5}{28}$$

*   **当 $X=1$ 时**（选中 A, B, C 中的 1 个）：
    $$P(X=1) = \frac{\binom{3}{1} \binom{5}{2}}{56} = \frac{3 \times 10}{56} = \frac{30}{56} = \frac{15}{28}$$

*   **当 $X=2$ 时**（选中 A, B, C 中的 2 个）：
    $$P(X=2) = \frac{\binom{3}{2} \binom{5}{1}}{56} = \frac{3 \times 5}{56} = \frac{15}{56}$$

*   **当 $X=3$ 时**（A, B, C 全部被选中）：
    $$P(X=3) = \frac{\binom{3}{3} \binom{5}{0}}{56} = \frac{1 \times 1}{56} = \frac{1}{56}$$

#### 3. 汇总分布列
$X$ 的分布列如下表所示：

| $X$ | $0$ | $1$ | $2$ | $3$ |
| :--- | :---: | :---: | :---: | :---: |
| $P$ | $\frac{10}{56}$ | $\frac{30}{56}$ | $\frac{15}{56}$ | $\frac{1}{56}$ |
| (化简) | $\frac{5}{28}$ | $\frac{15}{28}$ | $\frac{15}{56}$ | $\frac{1}{56}$ |

*(验证：$\frac{10+30+15+1}{56} = \frac{56}{56} = 1$，计算正确 $\checkmark$)*

#### 4. 计算数学期望 $E(X)$
根据期望定义 $E(X) = \sum_{i} x_i p_i$：
$$E(X) = 0 \cdot \frac{10}{56} + 1 \cdot \frac{30}{56} + 2 \cdot \frac{15}{56} + 3 \cdot \frac{1}{56}$$
$$E(X) = \frac{0 + 30 + 30 + 3}{56} = \frac{63}{56} = \frac{9}{8} = 1.125$$

---

### 【进阶解法：期望的线性性质】

在竞赛或高效率计算中，求期望无需写出完整的分布列，可以利用 **指示随机变量（Indicator Random Variables）**。

**思路**：
设 $X_A, X_B, X_C$ 为指示变量，若物品 $A$ 被选中则 $X_A = 1$，否则 $X_A = 0$。
则总选中数 $X = X_A + X_B + X_C$。

1.  **计算单个变量的期望**：
    由于每个物品被选中的概率是相等的，物品 $A$ 被选中的概率为：
    $$E(X_A) = P(A \text{ is chosen}) = \frac{\binom{7}{2}}{\binom{8}{3}} = \frac{21}{56} = \frac{3}{8}$$
    *(直观理解：在 8 个位置中选 3 个，任何一个特定物品被选中的概率就是 $3/8$)*

2.  **利用线性性质**：
    $$E(X) = E(X_A + X_B + X_C) = E(X_A) + E(X_B) + E(X_C)$$
    $$E(X) = \frac{3}{8} + \frac{3}{8} + \frac{3}{8} = \frac{9}{8}$$

**对比分析**：
*   **常规法** $\implies$ 能够给出完整的概率分布，但计算量大，容易在分式加法上出错。
*   **线性法** $\implies$ 极速求得期望，完全跳过了概率分布的推导，展现了数学的简洁美。

### 🧠 总结与反思

#### 1. 知识模型提炼
本题属于 **超几何分布 $X \sim H(N, M, n)$**，其通用公式为：
$$P(X=k) = \frac{\binom{M}{k} \binom{N-M}{n-k}}{\binom{N}{n}}$$
其数学期望的通用公式为：
$$E(X) = n \cdot \frac{M}{N}$$
代入本题：$E(X) = 3 \cdot \frac{3}{8} = \frac{9}{8}$。

#### 2. 避坑指南
*   **样本空间混淆**：容易误将总数看作 $3^3$ 或 $8^3$，必须明确是“组合”而非“排列”且是“不放回”抽样。
*   **分布列完备性**：在写分布列后，务必进行 $\sum P = 1$ 的校验。

#### 3. 迁移场景
如果你遇到“从 $N$ 个球（$M$ 个红球）中取出 $n$ 个，求红球个数的期望”，可以直接套用 $E = n \frac{M}{N}$，无需通过繁琐的组合数求和。
