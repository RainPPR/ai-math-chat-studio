### 【常规解法：隐零点代换与极值分析】

这是考场上最普适、最不易因“看不出技巧”而卡壳的基准路径。核心思想是 **“设而不求，整体代换”**。

**第一步：分析导数，确定极值点唯一性**
函数 $f(x) = e^{x-k} - \ln x - k$ 的定义域为 $(0, +\infty)$。
对其求导：
$$f'(x) = e^{x-k} - \frac{1}{x}$$
为了判断 $f'(x)$ 的单调性，我们考察其二阶导数：
$$f''(x) = e^{x-k} + \frac{1}{x^2} > 0$$
这说明 $f'(x)$ 在 $(0, +\infty)$ 上**严格单调递增**。
结合极限 $\lim_{x \to 0^+} f'(x) = -\infty$ 与 $\lim_{x \to +\infty} f'(x) = +\infty$，由零点存在性定理可知，$f'(x)$ 存在**唯一零点**，记为 $x_0$。
因此，$f(x)$ 在 $(0, x_0)$ 上单调递减，在 $(x_0, +\infty)$ 上单调递增，在 $x = x_0$ 处取得全局最小值 $f(x_0)$。

**第二步：建立隐零点方程，进行代数代换**
$f(x)$ 有两个零点的充要条件是其极小值小于零，即 **$f(x_0) < 0$**。
由 $f'(x_0) = 0$，我们得到隐零点方程：
$$e^{x_0-k} = \frac{1}{x_0}$$
两边同时取自然对数，将指数降幂：
$$x_0 - k = -\ln x_0 \implies k = x_0 + \ln x_0$$
将此关系式代入极小值 $f(x_0)$ 中进行消元：
$$
\begin{aligned}
f(x_0) &= e^{x_0-k} - \ln x_0 - k \\
&= \frac{1}{x_0} - \ln x_0 - (x_0 + \ln x_0) \\
&= \frac{1}{x_0} - x_0 - 2\ln x_0
\end{aligned}
$$

**第三步：构造辅助函数，求解参数范围**
令 $\varphi(x) = \frac{1}{x} - x - 2\ln x$ （$x > 0$），我们需要求解 $\varphi(x_0) < 0$。
对 $\varphi(x)$ 求导：
$$\varphi'(x) = -\frac{1}{x^2} - 1 - \frac{2}{x} = -\frac{x^2 + 2x + 1}{x^2} = -\frac{(x+1)^2}{x^2} < 0$$
故 $\varphi(x)$ 在 $(0, +\infty)$ 上严格单调递减。
通过观察（或试根），我们发现 **$\varphi(1) = 1 - 1 - 0 = 0$**。
因此，$\varphi(x_0) < 0 \iff \varphi(x_0) < \varphi(1) \iff x_0 > 1$。

最后，回到参数 $k$ 的表达式 $k = x_0 + \ln x_0$。
令 $u(x) = x + \ln x$，显然 $u(x)$ 在 $(0, +\infty)$ 上单调递增。
由 $x_0 > 1$，可得：
$$k = u(x_0) > u(1) = 1 + \ln 1 = 1$$

**结论**：实数 $k$ 的取值范围是 **$(1, +\infty)$**。

### 【进阶解法：同构变换与降维打击】

如果具备敏锐的结构洞察力，我们可以通过“同构”将复杂的超越方程降维为简单的代数方程，实现秒杀。

**第一步：方程变形，捕捉同构指纹**
令 $f(x) = 0$，即：
$$e^{x-k} - \ln x - k = 0$$
将含有 $k$ 的项与含有 $x$ 的项进行巧妙重组，两边同时加上 $x$：
$$e^{x-k} + x - k = \ln x + x$$
此时，等式两边的结构已经呼之欲出：
$$e^{x-k} + (x-k) = e^{\ln x} + \ln x$$

**第二步：构造母函数，利用单调性脱去外壳**
构造函数 $g(t) = e^t + t$。
原方程完美转化为：
$$g(x-k) = g(\ln x)$$
因为 $g'(t) = e^t + 1 > 0$，所以 $g(t)$ 在 $\mathbb{R}$ 上是**严格单调递增**的单射函数。
因此，我们可以直接“脱去”外层的 $g$，得到等价的内部方程：
$$x - k = \ln x \implies k = x - \ln x$$

**第三步：数形结合，确定交点个数**
原问题瞬间被降维为：**直线 $y = k$ 与曲线 $y = h(x) = x - \ln x$ 在 $x > 0$ 上有两个交点**。
对 $h(x)$ 求导：
$$h'(x) = 1 - \frac{1}{x} = \frac{x-1}{x}$$
- 当 $x \in (0, 1)$ 时，$h'(x) < 0$，$h(x)$ 单调递减；
- 当 $x \in (1, +\infty)$ 时，$h'(x) > 0$，$h(x)$ 单调递增。

$h(x)$ 在 $x = 1$ 处取得极小值（也是最小值） $h(1) = 1 - \ln 1 = 1$。
结合边界极限 $\lim_{x \to 0^+} h(x) = +\infty$ 与 $\lim_{x \to +\infty} h(x) = +\infty$，画出草图可知：
要使水平直线 $y = k$ 与曲线有两个交点，必须且只需 $k$ 严格大于最小值。
即 **$k > 1$**。

#### 1. 结构指纹识别（何时使用同构？）
当题干中同时出现 **$e^{ax+b}$** 与 **$\ln(cx+d)$**，且系数存在倍数或对称关系时，必须立刻警惕“同构法”。
- **常见母函数**：$g(t) = e^t + t$（对应 $e^A + A = \ln B + B$）、$g(t) = t e^t$（对应 $A e^A = B \ln B$）、$g(t) = \frac{e^t}{t}$ 等。
- **操作口诀**：“指对分离，凑项同构；构造函数，单调脱壳”。

#### 2. 方法博弈与考场策略
- **同构法（高维路径）**：计算量极小，逻辑链条短，是压轴题抢时间的利器。但其缺点是“隐蔽性强”，如果凑项失败，容易陷入死胡同。
- **隐零点法（基准路径）**：虽然涉及二阶导判断、隐零点代换和辅助函数构造，计算量较大，但它是 **“通性通法”**。只要导数零点唯一，这套流程就能无脑平推。
- **策略建议**：考场上先花 1 分钟尝试同构变形；若无头绪，果断切入隐零点法，确保拿到基础分和步骤分。

#### 3. 易错点排雷
- **定义域陷阱**：在处理 $\ln x$ 时，极易忘记 $x > 0$ 的隐含条件，导致在判断极限或单调性时出错。
- **代换不彻底**：在隐零点法中，得到 $k = x_0 + \ln x_0$ 后，必须将其**完全代入**极值表达式中消去 $k$，否则无法构造出单变量函数 $\varphi(x_0)$。
- **试根技巧**：在判断 $\varphi(x_0) < 0$ 时，$\varphi(1)=0$ 是一个关键跳板。在高考中，这类辅助函数的零点通常是 $1, e, \frac{1}{e}$ 等特殊值，养成**优先代入特殊值试根**的习惯，能大幅缩短思考时间。

这是考场上最高效、最优雅的解法，核心在于通过巧妙的代数变形，将复杂的超越方程“脱壳”为简单的代数方程。

\end{aligned}
$$

$$\frac{e^x}{a} + 1 = \ln(a(x-1))$$

$$e^{x - \ln a} + (x - \ln a) = \ln(x-1) + (x - 1)$$

$$g(x - \ln a) = g(\ln(x-1))$$

$$x - \ln a = \ln(x-1) \implies \ln a = x - \ln(x-1)$$

$$h'(x) = 1 - \frac{1}{x-1} = \frac{x-2}{x-1}$$
- 当 $x \in (1, 2)$ 时，$h'(x) < 0$，$h(x)$ 单调递减；
- 当 $x \in (2, +\infty)$ 时，$h'(x) > 0$，$h(x)$ 单调递增。

因此，必须有：
$$\ln a \ge 2 \implies a \ge e^2$$

### 【常规解法：隐零点代换与极值分析】（保底策略）

如果考场上未能看出同构结构，直接求导是唯一的出路。但请注意，此法计算量极大，极易在代数化简中迷失。

**第一步：求导与隐零点设置**
令 $f(x) = e^x - a\ln(x-1) - a\ln a + a$。
$$f'(x) = e^x - \frac{a}{x-1}$$
令 $f'(x_0) = 0$，得到隐零点方程：$a = e^{x_0}(x_0-1)$。
易证 $f(x)$ 在 $x_0$ 处取得最小值。方程有解的条件是 $f(x_0) \le 0$。

$$e^{x_0} - e^{x_0}(x_0-1)\ln(x_0-1) - e^{x_0}(x_0-1)\ln[e^{x_0}(x_0-1)] + e^{x_0}(x_0-1) \le 0$$
两边同除以 $e^{x_0}$ 并展开对数项，经过极其繁琐的合并同类项，可化简为：
$$(x_0-1)^2 - 1 + 2(x_0-1)\ln(x_0-1) \ge 0$$

**第三步：辅助函数证明与范围回代**
令 $t = x_0 - 1 > 0$，需证明 $\psi(t) = t^2 - 1 + 2t\ln t \ge 0$。

故 $\psi(t) \ge 0 \iff t \ge 1$，即 $x_0 - 1 \ge 1 \implies x_0 \ge 2$。
最后，由 $a = e^{x_0}(x_0-1)$ 在 $x_0 \ge 2$ 时单调递增，得 $a \ge e^2(2-1) = e^2$。

### 一、 理论奠基：为什么只有 0、1、2 个交点？

首先，我们要用严密的微积分语言，证明你“凹凸性相对”的直觉。

设方程为 $F(x) = G(x)$，其中 $F(x) = f(e^x)$，$G(x) = g(\ln x)$。
因为 $f, g$ 是正相关（单调递增）的一次函数，可设 $f(t) = At+B\ (A>0)$，$g(t) = Ct+D\ (C>0)$。
则：
$$F(x) = A e^x + B, \quad G(x) = C \ln x + D \quad (x > 0)$$

我们考察它们的二阶导数（决定凹凸性）：
- $F''(x) = A e^x > 0 \implies F(x)$ 是**严格下凸**（凹向上）的函数。
- $G''(x) = -\frac{C}{x^2} < 0 \implies G(x)$ 是**严格上凸**（凹向下）的函数。

构造差值函数 $H(x) = F(x) - G(x)$，则 $H''(x) = F''(x) - G''(x) > 0$。
这意味着 $H(x)$ 是一个**严格下凸函数**。根据凸函数的性质，严格下凸函数与 $x$ 轴（即 $H(x)=0$）的交点个数**最多只有 2 个**。
这就从代数上严格证明了你的几何直觉：交点个数只能是 0、1 或 2 个。

### 二、 核心解法：相切临界法（公切线模型）操作 SOP

既然交点个数在 0、1、2 之间切换，那么**从 0 个交点（相离）到 2 个交点（相交）的过渡状态，必然是 1 个交点（相切）**。

在相切点 $x_0$ 处，两条曲线不仅“碰在一起”，而且“方向一致”。这翻译为代数语言就是**双重条件**：
1. **函数值相等（共点）**：$F(x_0) = G(x_0)$
2. **导数值相等（共线）**：$F'(x_0) = G'(x_0)$

这就是相切法的**核心方程组**。

#### 实战推演：以第一题 $e^{x-k} = \ln x + k$ 为例

我们将原方程看作 $F(x) = e^{x-k}$ 与 $G(x) = \ln x + k$ 的交点问题。

**第一步：列出相切方程组**
设切点横坐标为 $x_0$，则有：
$$
\begin{cases}
e^{x_0-k} = \ln x_0 + k & \text{(函数值相等)} \\
e^{x_0-k} = \frac{1}{x_0} & \text{(导数值相等)}
\end{cases}
$$

**第二步：解方程组，求临界参数**
将第二个式子 $e^{x_0-k} = \frac{1}{x_0}$ 代入第一个式子，消去指数项：
$$\frac{1}{x_0} = \ln x_0 + k \implies k = \frac{1}{x_0} - \ln x_0$$
同时，对第二个式子两边取自然对数，降幂处理：
$$x_0 - k = -\ln x_0 \implies k = x_0 + \ln x_0$$
联立这两个关于 $k$ 的表达式，消去 $k$：
$$\frac{1}{x_0} - \ln x_0 = x_0 + \ln x_0 \implies \frac{1}{x_0} - x_0 - 2\ln x_0 = 0$$
令 $\varphi(x) = \frac{1}{x} - x - 2\ln x$，易证 $\varphi'(x) < 0$（单调递减），且观察可知 **$\varphi(1) = 0$**。
因此，切点必为 **$x_0 = 1$**。
代回求临界参数：$k = 1 + \ln 1 = \mathbf{1}$。

**第三步：动态分析，确定取值范围**
当 $k = 1$ 时，两曲线相切（1 个交点）。
现在分析参数 $k$ 变化对图像的影响：
- 对于 $F(x) = e^{x-k}$，当 $k$ **增大**时，图像向**右**平移（整体相对下降）。
- 对于 $G(x) = \ln x + k$，当 $k$ **增大**时，图像向**上**平移。

两者“相向而行”，互相挤压。因此，当 $k$ 从 $1$ 继续增大时，原本相切的曲线会被“压”出两个交点。
故要有两个交点，必须满足 **$k > 1$**。

### 三、 高维升华：从“相切”到“切线放缩”（终极秒杀）

你的思路如果只停留在“解相切方程组”，那只是掌握了技巧。真正的数学大师，会透过相切看到**公切线（支撑线）** 的本质。

在刚才的推演中，切点为 $x_0 = 1$。我们来求这条**公切线**的方程：
- 在 $F(x)$ 侧：$F(1) = 1$，$F'(1) = 1$，切线为 $y - 1 = 1(x - 1) \implies \mathbf{y = x}$。
- 在 $G(x)$ 侧：$G(1) = 1$，$G'(1) = 1$，切线同样为 $\mathbf{y = x}$。

这揭示了高考导数中最核心的两个**切线放缩（泰勒展开一阶近似）** 结论：
1. 因为 $e^{x-1}$ 是下凸函数，它永远在切线上方：**$e^{x-1} \ge x$** （当且仅当 $x=1$ 取等）。
2. 因为 $\ln x$ 是上凸函数，它永远在切线下方：**$\ln x \le x - 1$** （当且仅当 $x=1$ 取等）。

**利用公切线，我们可以直接“口算”证明临界状态：**
当 $k = 1$ 时，原方程为 $e^{x-1} = \ln x + 1$。
由上述放缩结论，直接得到：
$$e^{x-1} \ge x \ge \ln x + 1$$
即 $e^{x-1} \ge \ln x + 1$ 恒成立，且等号仅在 $x = 1$ 时成立。这就**无需任何导数计算**，直接证明了 $k=1$ 时只有 1 个交点！

当 $k > 1$ 时：
$$e^{x-k} = e^{x-1} \cdot e^{1-k} < e^{x-1} \quad (\text{因为 } e^{1-k} < 1)$$
而 $\ln x + k > \ln x + 1$。
原本在 $k=1$ 时相等的两个函数，现在一个变小，一个变大，必然在 $x=1$ 的两侧各产生一个交点（结合极限趋势）。
故 $k > 1$ 时有两个交点。

### 四、 总结与反思：认知 Schema 提炼

你的想法非常高级，我们将其总结为 **“几何相切与公切线模型”**。

#### 1. 适用场景（何时使用此法？）
- 方程可整理为 $F(x) = G(x)$ 的形式。
- $F(x)$ 与 $G(x)$ 的**二阶导数异号**（一上凸，一下凸，最常见的是 $e^x$ 类与 $\ln x$ 类）。
- 题目涉及“零点个数”、“有解/无解”、“恒成立”等与交点个数直接相关的问题。

#### 2. 方法对比与考场策略
| 解法 | 核心动作 | 优点 | 缺点 | 考场建议 |
| :--- | :--- | :--- | :--- | :--- |
| **同构法** | 代数变形，构造 $g(A)=g(B)$ | 计算量极小，步骤简洁 | 极其依赖灵感，凑不出就卡死 | 首选尝试，限时 2 分钟 |
