### 第一部分：基本定义与同角关系 (Foundations)

这是所有变形的基石，必须达到直觉反应的程度。

**1. 核心定义与商数关系**
$$\tan \theta = \frac{\sin \theta}{\cos \theta} \quad (\cos \theta \neq 0)$$

**2. 平方关系（及其二级变形）**
- **基准公式**：
$$\sin^2 \theta + \cos^2 \theta = 1$$
- **二级结论（含 $\tan$ 的变形）**：
$$1 + \tan^2 \theta = \frac{1}{\cos^2 \theta} \quad (\cos \theta \neq 0)$$
- **三级结论（用于快速求值）**：
$$\sin^2 \theta = 1 - \cos^2 \theta = (1 - \cos \theta)(1 + \cos \theta)$$

### 第二部分：诱导公式与周期性 (Symmetry & Periodicity)

**核心心法**：$\text{奇变偶不变，符号看象限}$。

**1. 周期与对称性 ($k \in \mathbb{Z}$)**
$$\sin(x + 2k\pi) = \sin x, \quad \cos(x + 2k\pi) = \cos x, \quad \tan(x + k\pi) = \tan x$$

**2. 负角公式（奇偶性）**
$$\sin(-\theta) = -\sin \theta, \quad \cos(-\theta) = \cos \theta, \quad \tan(-\theta) = -\tan \theta$$

**3. 核心诱导组**
- **互余关系 ($\frac{\pi}{2} - \theta$)**：
$$\sin\left(\frac{\pi}{2} - \theta\right) = \cos \theta, \quad \cos\left(\frac{\pi}{2} - \theta\right) = \sin \theta, \quad \tan\left(\frac{\pi}{2} - \theta\right) = \frac{1}{\tan \theta}$$
- **关于 $y$ 轴对称 ($\pi - \theta$)**：
$$\sin(\pi - \theta) = \sin \theta, \quad \cos(\pi - \theta) = -\cos \theta, \quad \tan(\pi - \theta) = -\tan \theta$$

### 第三部分：和差角公式 (Addition & Subtraction)

这是三角函数变形的“母函数”，绝大多数高级结论均由此推演。

**1. 正余弦和差公式**
$$\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta$$
$$\cos(\alpha \pm \beta) = \cos \alpha \cos \beta \mp \sin \alpha \sin \beta \quad (\text{注意符号相反})$$

**2. 正切和差公式**
$$\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}$$

**3. 二级结论（$\tan$ 的和差变形）**：常用于证明题中将 $\tan$ 转化为 $\sin, \cos$ 的积。
$$\tan \alpha \pm \tan \beta = \frac{\sin(\alpha \pm \beta)}{\cos \alpha \cos \beta}$$

### 第四部分：倍角、半角与多倍角 (Multiple Angles)

**1. 二倍角公式 (Double Angle)**
- **正弦**：$\sin 2\alpha = 2 \sin \alpha \cos \alpha$
- **余弦（三种形式，根据需要切换）**：
$$\cos 2\alpha = \cos^2 \alpha - \sin^2 \alpha = 2\cos^2 \alpha - 1 = 1 - 2\sin^2 \alpha$$
- **正切**：$\tan 2\alpha = \frac{2 \tan \alpha}{1 - \tan^2 \alpha}$

**2. 降幂公式 (Power Reduction)**：由 $\cos 2\alpha$ 推演，是处理 $\sin^2, \cos^2$ 的唯一利器。
$$\sin^2 \alpha = \frac{1 - \cos 2\alpha}{2}, \quad \cos^2 \alpha = \frac{1 + \cos 2\alpha}{2}, \quad \tan^2 \alpha = \frac{1 - \cos 2\alpha}{1 + \cos 2\alpha}$$

**3. 三倍角公式 (Triple Angle)**
$$\sin 3\alpha = 3 \sin \alpha - 4 \sin^3 \alpha$$
$$\cos 3\alpha = 4 \cos^3 \alpha - 3 \cos \alpha$$
$$\tan 3\alpha = \frac{3 \tan \alpha - \tan^3 \alpha}{1 - 3 \tan^2 \alpha}$$
- **三级结论（乘积形式）**：极少见但能秒杀竞赛题。
$$\sin 3\alpha = 4 \sin \alpha \sin(60^\circ - \alpha) \sin(60^\circ + \alpha)$$
$$\cos 3\alpha = 4 \cos \alpha \cos(60^\circ - \alpha) \cos(60^\circ + \alpha)$$

**4. 四倍角公式 (Quadruple Angle)**
$$\sin 4\alpha = 4 \cos^3 \alpha \sin \alpha - 4 \cos \alpha \sin^3 \alpha$$
$$\cos 4\alpha = 8 \cos^4 \alpha - 8 \cos^2 \alpha + 1$$
$$\tan 4\alpha = \frac{4 \tan \alpha - 4 \tan^3 \alpha}{1 - 6 \tan^2 \alpha + \tan^4 \alpha}$$

**5. 半角公式 (Half Angle)**
$$\sin \frac{\alpha}{2} = \pm \sqrt{\frac{1 - \cos \alpha}{2}}, \quad \cos \frac{\alpha}{2} = \pm \sqrt{\frac{1 + \cos \alpha}{2}}$$
- **$\tan$ 的有理形式（极重要二级结论）**：
$$\tan \frac{\alpha}{2} = \frac{\sin \alpha}{1 + \cos \alpha} = \frac{1 - \cos \alpha}{\sin \alpha}$$

### 第五部分：积化和差与和差化积 (Product-Sum Transforms)

**1. 积化和差 (Product to Sum)**
$$\sin \alpha \cos \beta = \frac{1}{2} [\sin(\alpha + \beta) + \sin(\alpha - \beta)]$$
$$\cos \alpha \sin \beta = \frac{1}{2} [\sin(\alpha + \beta) - \sin(\alpha - \beta)]$$
$$\cos \alpha \cos \beta = \frac{1}{2} [\cos(\alpha + \beta) + \cos(\alpha - \beta)]$$
$$\sin \alpha \sin \beta = \frac{1}{2} [\cos(\alpha - \beta) - \cos(\alpha + \beta)]$$

**2. 和差化积 (Sum to Product)**
$$\sin \alpha + \sin \beta = 2 \sin \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2}$$
$$\sin \alpha - \sin \beta = 2 \cos \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2}$$
$$\cos \alpha + \cos \beta = 2 \cos \frac{\alpha + \beta}{2} \cos \frac{\alpha - \beta}{2}$$
$$\cos \alpha - \cos \beta = -2 \sin \frac{\alpha + \beta}{2} \sin \frac{\alpha - \beta}{2}$$

### 第六部分：辅助角公式与万能公式 (Advanced Tools)

**1. 辅助角公式 (Harmonic Addition)**
对于 $a \sin x + b \cos x$ 形式，可合并为单正弦函数：
$$a \sin x + b \cos x = \sqrt{a^2 + b^2} \sin(x + \varphi)$$
其中 $\cos \varphi = \frac{a}{\sqrt{a^2 + b^2}}, \sin \varphi = \frac{b}{\sqrt{a^2 + b^2}}$。

**2. 万能公式 (The Weierstrass Substitution)**
设 $t = \tan \frac{\alpha}{2}$，则所有三角函数可代数化：
$$\sin \alpha = \frac{2t}{1 + t^2}, \quad \cos \alpha = \frac{1 - t^2}{1 + t^2}, \quad \tan \alpha = \frac{2t}{1 - t^2}$$

### 第七部分：三角形中的三角恒等式 (Triangle Identities)

在 $\triangle ABC$ 中，$A+B+C = \pi$。

**2. 面积公式 $S$**

**3. 三角形内角恒等式 (三级结论/竞赛级)**
- $\tan A + \tan B + \tan C = \tan A \tan B \tan C$
- $\sin 2A + \sin 2B + \sin 2C = 4 \sin A \sin B \sin C$

### 第十部分：元认知总结 (Meta-Cognitive Summary)

当你面对一道复杂的三角函数压轴题时，请启动以下**决策树**：

1. **结构识别** $\to$ 看到 $\sin^2, \cos^2 \implies$ 优先考虑**降幂** $\to$ 统一角度 $\to$ 合并同类项。
2. **角度不一** $\to$ 看到 $x, 2x, 3x \implies$ 优先考虑**倍角/三倍角** $\to$ 统一到单角 $\alpha$。
3. **和式 $\to$ 积式** $\to$ 看到 $\sin A + \sin B \implies$ 优先考虑**和差化积** $\to$ 寻找公因式。
4. **积式 $\to$ 和式** $\to$ 看到 $\sin A \cos B \implies$ 优先考虑**积化和差** $\to$ 抵消项。
5. **范围/最值** $\to$ 看到 $a \sin x + b \cos x \implies$ 必须调用**辅助角公式**。
6. **有理式 $\to$ 代数式** $\to$ 面对极复杂的三角分式 $\implies$ 尝试**万能公式** $t = \tan \frac{\alpha}{2}$。

**陷阱警示**：
- 在使用 $\sqrt{\sin^2 \theta} = \sin \theta$ 时，必须检查 $\theta$ 的象限，确保加上 $\pm$ 号。
- 在使用 $\tan \theta = \frac{\sin \theta}{\cos \theta}$ 时，必须注明 $\cos \theta \neq 0$。
- 在三角形中，$\sin A = \sin(\pi - A)$，很多题目通过这个性质将角 $A$ 转化为角 $B+C$。
