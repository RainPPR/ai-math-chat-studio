这是一道典型的**“结构陷阱题”**。在竞赛数学中，这类题目往往会给出一个极其复杂且具体的背景（如一个 100 次的多项式），但最终的结论却依赖于一个极其简单且普适的数学性质（对称性）。

### 【元解析与特征挖掘】

**1. 符号纠错（Symbol Correction）**
题干给定 $f(x)=\sum_{i=1}^{100}(x-i)$。若按照此定义，$f(x)$ 是一个一次函数 $f(x)=100x - 5050$，其导数 $f'(x)=100$ 永远不为 $0$，不可能有 $99$ 个根。
由此可断定，题干中的 $\sum$ 应当为 $\prod$（连乘符号）。
**正确的函数定义应为：**
$$f(x) = \prod_{i=1}^{100}(x-i) = (x-1)(x-2)\dots(x-100)$$
这是一个 $100$ 次多项式，其导数 $f'(x)$ 为 $99$ 次多项式，符合有 $99$ 个实根的描述。

**2. 特征识别（Feature Extraction）**
我们需要证明的表达式是：
$$S = \sum_{1\le i,j\le 99}^{i\neq j}\dfrac{1}{a_i-a_j}$$
观察求和项 $g(i, j) = \dfrac{1}{a_i-a_j}$。这是一个典型的**反对称函数（Antisymmetric Function）**，即：
$$g(i, j) = -g(j, i)$$
当我们在一个对称的索引集（所有 $i \neq j$ 的组合）上对一个反对称函数求和时，结果在逻辑上必然为 $0$，而与 $a_i$ 具体是多少毫无关系。

---

### 【基准推导】

**步骤 1：证明根的相异性（确保表达式有意义）**
要使 $\frac{1}{a_i-a_j}$ 有定义，必须证明 $a_i \neq a_j$（对于 $i \neq j$）。
- 根据 $f(x) = \prod_{k=1}^{100}(x-k)$，可知 $f(x)$ 在 $1, 2, \dots, 100$ 处有 $100$ 个互不相同的实根。
- 根据 **罗尔定理（Rolle's Theorem）**：在每一个相邻根 $(k, k+1)$ 之间，至少存在一个 $\xi \in (k, k+1)$ 使得 $f'(\xi)=0$。
- 因为共有 $99$ 个这样的区间，且 $f'(x)$ 是一个 $99$ 次多项式，所以 $f'(x)$ 恰好有 $99$ 个实根 $a_1, a_2, \dots, a_{99}$，且它们满足：
$$1 < a_1 < 2 < a_2 < 3 < \dots < 99 < a_{99} < 100$$
由此可见，所有 $a_i$ 互不相同，分母 $a_i - a_j \neq 0$ 成立。

**步骤 2：利用对称性证明求和结果**
我们要计算的和为：
$$S = \sum_{i=1}^{99} \left( \sum_{j=1, j \neq i}^{99} \frac{1}{a_i - a_j} \right)$$
我们将所有的项按对 $(i, j)$ 进行配对。对于任意一对索引 $i < j$，求和式中同时包含 $\frac{1}{a_i - a_j}$ 和 $\frac{1}{a_j - a_i}$。
我们将原式重写为：
$$S = \sum_{1 \le i < j \le 99} \left( \frac{1}{a_i - a_j} + \frac{1}{a_j - a_i} \right)$$
由于 $\frac{1}{a_j - a_i} = - \frac{1}{a_i - a_j}$，则：
$$\frac{1}{a_i - a_j} + \frac{1}{a_j - a_i} = 0$$
因此：
$$S = \sum_{1 \le i < j \le 99} 0 = 0$$
**证毕。** $\square$

### 【进阶视野：从“对称”到“本质”】

很多学生在做此题时，会被 $f(x)$ 的具体形式干扰，试图通过计算 $f'(x)$ 的系数或利用韦达定理来求解。但事实上，这道题在考察**“冗余信息的识别能力”**。

**1. 真正的“母题”是什么？**
此类问题的本质通常涉及 $f'(x)$ 的根 $a_i$ 与 $f(x)$ 的根 $x_k$ 之间的关系。一个极其重要的二级结论是：
若 $f(x) = \prod (x-x_k)$，则 $\frac{f'(x)}{f(x)} = \sum_{k=1}^n \frac{1}{x-x_k}$。
因为 $a_i$ 是 $f'(x)$ 的根，所以 $f'(a_i)=0$。这意味着：
$$\sum_{k=1}^{100} \frac{1}{a_i - k} = 0 \quad (\text{对于每一个 } a_i)$$
这是一个**非平凡（Non-trivial）**的恒等式。如果题目要求证明 $\sum_{i=1}^{99} \sum_{k=1}^{100} \frac{1}{a_i - k} = 0$，那么上述性质就是核心。而本题要求的 $\sum \frac{1}{a_i - a_j}$ 则是利用了更底层的**代数对称性**。

**2. 复杂度对比**
- **暴力路径**：求出 $f'(x)$ $\to$ 尝试用韦达定理表示 $\sum \frac{1}{a_i - a_j}$ $\to$ 陷入极其复杂的代数运算 $\to$ 失败。
- **直觉路径**：识别 $\sum_{i \neq j} \frac{1}{a_i - a_j}$ 的结构 $\to$ 发现它是反对称求和 $\to$ 直接秒杀。

### 【总结与反思】

**1. 认知 Schema 提炼**
当你在题目中看到 $\sum_{i \neq j} \text{Expression}(a_i, a_j)$ 且该表达式满足 $\text{Expression}(a_i, a_j) = -\text{Expression}(a_j, a_i)$ 时，**无需考虑 $a_i$ 的来源，结果直接为 $0$**。

**2. 陷阱点警示**
- **条件冗余**：本题中 $f(x)$ 的具体形式、根的数量 $100$ 等都是为了构建一个“看起来很像复杂导数题”的假象。
- **定义域检查**：在利用对称性之前，必须首先通过罗尔定理等手段证明根的**相异性**，否则分母为 $0$ 会导致证明失效。

**3. 迁移场景**
这种对称消去法在物理学（如电荷分布的相互作用能计算）和高级线性代数（如反对称矩阵的迹 $\text{tr}(A)=0$）中极为常见。在数学竞赛中，时刻保持对**“对称性”**的敏感度，是实现从“计算型选手”向“洞察型选手”转变的关键。 $\text{🚀}$
