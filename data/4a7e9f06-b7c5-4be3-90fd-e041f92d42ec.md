```text
设理想单摆的摆动幅度为 $\theta<5^\circ$，小球的重力为 $mg$，求单摆从一侧最高点到最低点的过程中拉力、重力的冲量 $p_F,p_G$。
```

## model

```text
model/2026-07-11T14:18:01.154Z

### **问题分析**
理想单摆在小角度摆幅 \((\theta < 5^\circ)\) 下可视为简谐振动。设摆长为 \(L\)，小球质量为 \(m\)，重力加速度为 \(g\)。单摆从一侧最高点（摆角 \(\theta_0\)）运动到最低点（摆角 \(0\)）的过程中，重力与绳子拉力均为变力，但通过动量定理可以简洁地求出二者的冲量。

### **符号定义与模型建立**
- 坐标系：取水平向右为 \(x\) 轴正方向，竖直向上为 \(y\) 轴正方向，悬点位于原点上方适当处。为直观，设从右侧释放（\(\theta_0 > 0\) 且很小），则最低点速度水平向左。
- 周期：小角近似下，简谐振动角频率 \(\omega = \sqrt{g/L}\)，周期 \(T = 2\pi/\omega = 2\pi\sqrt{L/g}\)。
- 时间间隔：从最高点到最低点历时 \(\Delta t = \frac{T}{4} = \frac{\pi}{2}\sqrt{\frac{L}{g}}\)。
- 速度：由机械能守恒（小角度近似 \(1-\cos\theta_0 \approx \theta_0^2/2\)），最低点速率  
  \[
  v = \sqrt{2gL(1-\cos\theta_0)} = \theta_0\sqrt{gL}.
  \]
- 动量变化：初动量零，末动量水平向左，大小为 \(mv\)，故  
  \[
  \Delta \boldsymbol{p} = (-mv,\,0).
  \]

### **冲量计算**
1. **重力的冲量**  
   重力恒定，大小为 \(mg\)，方向竖直向下（与 \(y\) 轴正向相反）。  
   \[
   \boldsymbol{I}_G = \int_0^{\Delta t} \boldsymbol{G}\,\mathrm{d}t = (0,\,-mg\Delta t) = \left(0,\, -\frac{\pi}{2}m\sqrt{gL}\right).
   \]  
   大小 \(I_G = mg\Delta t = \dfrac{\pi}{2}m\sqrt{gL}\)，方向竖直向下。

2. **拉力的冲量**  
   拉力是变力，但其冲量可由动量定理求得：  
   \[
   \boldsymbol{I}_F + \boldsymbol{I}_G = \Delta\boldsymbol{p}.
   \]  
   代入 \(\boldsymbol{I}_G\) 和 \(\Delta\boldsymbol{p}\)：  
   \[
   \boldsymbol{I}_F = \Delta\boldsymbol{p} - \boldsymbol{I}_G = (-mv,\,0) - (0,\,-mg\Delta t) = (-mv,\,mg\Delta t).
   \]  
   将 \(v = \theta_0\sqrt{gL}\) 及 \(\Delta t = \frac{\pi}{2}\sqrt{L/g}\) 代入得  
   \[
   \boxed{\boldsymbol{I}_F = \left(-\,m\theta_0\sqrt{gL},\; \frac{\pi}{2}m\sqrt{gL}\right)}.
   \]  
   其中 \(x\) 分量负号表示方向水平向左，\(y\) 分量正号表示竖直向上。  
   拉力的冲量大小：  
   \[
   I_F = \sqrt{(m\theta_0\sqrt{gL})^2 + \left(\frac{\pi}{2}m\sqrt{gL}\right)^2}
        = m\sqrt{gL}\,\sqrt{\theta_0^2 + \frac{\pi^2}{4}}.
   \]  
   设 \(\boldsymbol{I}_F\) 与竖直向上方向的夹角为 \(\alpha\)，则  
   \[
   \tan\alpha = \frac{m\theta_0\sqrt{gL}}{\frac{\pi}{2}m\sqrt{gL}} = \frac{2\theta_0}{\pi},
   \quad \alpha = \arctan\frac{2\theta_0}{\pi}.
   \]  
   故 \(\boldsymbol{I}_F\) 的方向为左偏上 \(\alpha\) 角。

### **结果汇总**
- **重力冲量**（矢量形式，\(y\) 轴向上为正）：  
  \[
  \boxed{\boldsymbol{I}_G = \left(0,\, -\frac{\pi}{2}m\sqrt{gL}\right)},
  \qquad I_G = \frac{\pi}{2}m\sqrt{gL}\;(\text{竖直向下}).
  \]
- **拉力冲量**：  
  \[
  \boxed{\boldsymbol{I}_F = \left(-\,m\theta_0\sqrt{gL},\; \frac{\pi}{2}m\sqrt{gL}\right)},
  \qquad I_F = m\sqrt{gL}\,\sqrt{\theta_0^2 + \frac{\pi^2}{4}} \;(\text{左偏上 } \alpha \text{ 角}).
  \]

若从左侧释放，所有水平分量的符号取反（方向向右），其余不变。

### **检验**
- **量纲**：\(m\sqrt{gL}\) 的量纲为 \(\mathrm{kg\cdot (m/s)}\)，与冲量（\(\mathrm{N\cdot s}\)）一致。
- **特例**：若 \(\theta_0 \to 0\)，则 \(v \to 0\)，拉力冲量竖直分量与重力冲量抵消，\(\boldsymbol{I}_F \to (0,\,\frac{\pi}{2}m\sqrt{gL})\) 而 \(\boldsymbol{I}_G \to (0,\,-\frac{\pi}{2}m\sqrt{gL})\)，合冲量为零，符合静止情况。
- **动量定理**：\(\boldsymbol{I}_F + \boldsymbol{I}_G = (-mv,\,0) = \Delta\boldsymbol{p}\)，无误。

以上推导严格基于小角度近似（\(\theta<5^\circ\)），所得结果适用于理想单摆在该条件下的运动。
```
